# .aimem/outbox

작업자 세션의 보고 위치입니다. **파일 하나에 세션 하나**가 원칙입니다.
이렇게 하면 여러 세션이 같은 폴더에서 동시에 보고해도 쓰기 충돌이 생기지 않습니다.

- 파일명: `<슬롯ID>.md` (예: `S1.md`, `S2.md`)
- 자기 슬롯 파일에만 씁니다. 다른 슬롯 파일은 읽기만 합니다
- 새 보고는 파일 **맨 위에** 추가합니다 (최신이 위)
- 양식과 STATUS 값은 `../../AIMEM.md` 의 `0.3 보고 방법` 참조

관리자(클로)는 여기를 읽어 `AIMEM.md` 의 작업 보드와 핸드오프 로그를 갱신합니다.
완료된 태스크의 보고는 `../archive/` 로 옮겨집니다.
