## 3. 이번 라운드 규칙 (태석님 지시) - `8.0` 에 한 줄씩 등재

### 3-A. 관리자 컨텍스트 관리 (R6 가 1시간·기록 ~690KB 로 커진 데 따른 조치)
1. **라운드 크기 상한.** 한 라운드에 그래프 최대 3개, 태스크 최대 10개. 넘치는 일은 큐에 남기고 보고 "다음 라운드 계획"에 적는다. 상한에 닿으면 새 그래프를 만들지 말고 마무리(전체 검증·REV·보고)로 간다.
2. **그래프마다 체크포인트.** 그래프 하나가 끝날 때마다 (a) 보드 상태를 실행 결과에 맞게 갱신(done 노드 → REVIEW/DONE), (b) `aimem_db.py event` 로 "G-xxx 완료: 노드별 결과, 남은 일" 한 줄, (c) 큐 갱신. 세션이 중간에 끊기거나 압축돼도 새 관리자가 DB 만 읽고 이어받을 수 있어야 한다.
3. **큰 출력은 직접 읽지 않는다.** 작업자 보고는 첫 줄(`DONE|BLOCKED|NEEDS-*`)과 요약만 읽고, 테스트·린터 출력은 `| tail -20` 또는 실패 줄만. 전체 파일 dump·전체 diff 를 컨텍스트에 올리지 않는다(필요하면 `git diff --stat` 후 해당 hunk 만).
