# T-048 교차검수 - Strata 재스킨 + 밝은 모드 (**읽기 전용. 저장소 파일을 고치지 마라.**)

`8.0-1`: **만든 슬롯은 자기 작업을 검수하지 않는다.** 이 화면은 S3 가 만들었고 너는 S4 다.
S3 의 보고를 믿지 말고 **직접 재현하라.** "보고가 그렇다고 한다" 는 검수가 아니다.

## 대상
- `tools/aimem_monitor/static/style.css` (S3 가 방금 `--st-*` 토큰으로 재스킨, run `20261109-174032-S3`)
- 같은 폴더의 `index.html` / `app.js` (밝은 모드·가독성 작업, run `20261109-172618-S3`)
- 참조 토큰 원본: `.aimem/briefs/strata-tokens.css`
- **주의: S3 작업자가 지금 같은 폴더에 상세 패널을 추가하고 있다.** 네가 읽는 중에 파일이 바뀔 수 있다.
  읽은 시점을 보고에 적고, 바뀐 것 같으면 다시 읽어라. **네가 고치지는 마라.**

서버는 `localhost:18799` 에 떠 있다. `curl` 로 실제 응답을 받아 검사하라.

## 확인할 것 (각 항목: 재현 명령 + 실제 출력 + 판정)
1. **토큰 1:1 대응.** `.aimem/briefs/strata-tokens.css` 의 `--st-*` 변수 이름과 값이 `style.css` `:root` 에
   그대로 있는가? **빠진 것·값이 다른 것·이름만 같고 값이 다른 것**을 표로 내라.
2. **하드코딩 hex 0.** 규칙 본문(`:root` 와 `[data-theme=dark]` 밖)에 `#rrggbb`/`rgb()`/색 이름이 남았는가?
   `grep -nE "#[0-9a-fA-F]{3,8}|rgb\(|rgba\("` 로 세고, 남은 것이 토큰 정의인지 규칙 본문인지 구분하라.
3. **대비비를 직접 계산하라.** S3 가 적은 숫자를 옮기지 말고 WCAG 상대휘도 공식을 파이썬으로 짜서
   밝은 모드·어두운 모드 각각에 대해 (본문/표면), (보조/표면), **배지 4종(accent/info/warn/danger)의
   텍스트색/틴트배경** 조합을 전부 계산하라. **4.5:1 미만을 전부 적어라.** 배지가 가장 잘 깨진다.
4. **DOM id 보존.** `index.html` 의 id 전부를 뽑아 `app.js` 가 찾는 id 전부와 양방향 대조하라
   (`getElementById`/`querySelector`). **한쪽에만 있는 것**을 목록으로 내라.
5. **외부 자원 0.** `@font-face`, `http://`, `https://`, `cdn`, `@import` 가 있는가?
   (외부 폰트 로드 금지 - 태석님 지시)
6. **열 정렬·말줄임(요청 ce9f).** `table-layout: fixed` / 숫자·시간 열 우측정렬 / `tabular-nums` /
   말줄임(`text-overflow: ellipsis` + `title` 툴팁) 이 실제 표에 걸려 있는가?
   `curl -s localhost:18799/static/index.html` 로 받은 실물에서 확인하라.
7. **어두운 모드 토글.** `data-theme="dark"` 가 `:root` 토큰만 바꾸는가, 아니면 규칙 본문도 중복 정의하는가?
   토글이 `prefers-color-scheme` 에 끌려가지 않는가(태석님: 밝은 모드가 **기본**, 어두운 모드는 **선택**)?
8. **키 유출.** `curl -s localhost:18799/api/state` 응답과 `static/` 세 파일에 KISTI API 키 문자열이
   섞여 있는가? (`$KISTI_API_KEY` 가 셸에 있으면 그 값으로 grep 하되 **값을 출력하지 마라**)
9. **접근성 최소선.** 클릭 가능한 것이 `<button>`/`tabindex` 인가 아니면 `div` 에 onclick 인가?
   포커스 링이 지워졌는가(`outline: none` 이 대체 없이 있는가)?
