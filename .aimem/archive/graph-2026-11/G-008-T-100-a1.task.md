# T-100 웹워들 통합 연기 테스트 + 적대적 검수

## 할 일 (둘 다)

### 1. 연기 테스트를 만듭니다 - `projects/웹워들/tests/smoke_integration.mjs` (이 파일만 씁니다)

앞 노드들이 만든 `web/js/game.js` 와 `web/js/words.js` 를 **실제로 불러** 맞물려 도는지 봅니다.
`node:test` + `node:assert/strict` 를 씁니다.

- `ANSWERS` 의 모든 낱말이 `ALLOWED` 안에 있다
- `ANSWERS` 와 `ALLOWED` 의 모든 낱말이 `/^[a-z]{5}$/`
- `answerForDate(new Date(), ANSWERS)` 가 `ANSWERS` 안의 낱말이다
- **독립 대조**: `scoreGuess` 와 비교할 **다른 방식의 구현을 이 테스트 파일 안에 직접 쓰고**
  (`game.js` 의 코드를 베끼지 말고 직접 생각해서 쓰십시오), `ANSWERS` 에서 뽑은 정답·추측 쌍
  1,000가지를 둘로 돌려 결과가 모두 같은지 봅니다. 뽑기는 **고정 시드**(예: 선형 합동 생성기)로
  해서 돌릴 때마다 같아야 합니다
- 진짜 한 판: `ANSWERS[0]` 을 정답으로 판을 만들어 틀린 추측 다섯 번 + 정답 한 번을 두고
  `status === "won"`, `shareText()` 의 마지막 줄이 `🟩🟩🟩🟩🟩`
- 저장·복원: 두 줄 둔 판을 `toJSON()` → `fromJSON()` 했을 때 이어서 둘 수 있다

### 2. 검수하고 보고합니다 (고치지 않습니다)

`web/index.html`, `web/css/style.css`, `web/js/ui.js`, `web/js/storage.js`, `web/js/game.js` 를 읽고
**적대적으로** 결함을 찾으십시오. 그 파일들은 다른 슬롯 소유이니 **절대 고치지 말고** 보고만 하십시오.

특히 볼 것:

- `ui.js` 가 `game.js`/`storage.js` 를 계약대로 부르는가 (없는 함수를 부르거나 이름이 다른 곳)
- `index.html` 이 가리키는 경로가 실제로 있는가 (`css/style.css`, `js/ui.js`)
- 겹치는 글자 판정이 위 계약표와 어긋나는 곳
- `localStorage` 가 막혔을 때 터지는 곳
- 보드나 키보드가 좁은 화면에서 잘리는 설정, 대비가 모자란 색
- 끝난 판에서 입력이 계속 먹는지, 날짜가 바뀌었을 때 옛 판이 되살아나는지
