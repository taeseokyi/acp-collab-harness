# T-159 시험 픽스처 한 군데를 고치십시오 (아주 작습니다)

**고칠 파일은 `tests/test_aimem_monitor_auth.py` 하나뿐입니다.**
`tools/` 아래는 **읽기만 하고 한 줄도 고치지 마십시오** - 제품은 이미 맞게 고쳐졌습니다.

## 무엇이 일어났나

T-156 이 `tools/aimem_monitor/server.py` 의 `_subject()` 를 고쳐,
**`gh:` 주체는 요청마다 GitHub 허용 목록(`GITHUB_ALLOW_FILE`)을 다시 보게** 했습니다.
허용 목록에서 지운 계정의 옛 쿠키를 끊기 위해서입니다(의도한 변경입니다).

그 바람에 **옛 시험 하나가 빨개졌습니다**:

```
FAIL: tests.test_aimem_monitor_auth.AuthHttpTests.test_github_subject_cookie_is_accepted
AssertionError: 401 != 200
```

그 시험(482행 근처)은 `gh:octocat` 쿠키를 서명해 `/api/health` 가 200 이기를 바랍니다.
그런데 `AuthHttpTests.setUpClass`(330행 근처)가 만드는 **임시 루트에는 허용 목록 파일이
없습니다.** 파일이 없으면 `github_allowed_logins` 는 빈 집합이라 아무도 못 들어옵니다 -
그래서 401 입니다. **제품이 아니라 픽스처가 낡은 것입니다.**

## 고치는 법 - 두 군데

**(1) 픽스처에 허용 목록을 만듭니다.** `AuthHttpTests.setUpClass` (330행 근처):

```python
    @classmethod
    def setUpClass(cls):
        cls._tmp = tempfile.TemporaryDirectory()
        cls.root = cls._tmp.name
        cls.srv = _Srv(cls.root)
```

를 아래로 바꿉니다(`_write` 와 `GITHUB_ALLOW_FILE` 은 이 파일에 이미 있습니다 -
`_write` 는 243행 근처에서 쓰이고 `GITHUB_ALLOW_FILE` 은 24행에서 import 합니다):

```python
    @classmethod
    def setUpClass(cls):
        cls._tmp = tempfile.TemporaryDirectory()
        cls.root = cls._tmp.name
        # `_subject()` 가 `gh:` 주체마다 허용 목록을 다시 봅니다 (R12 T-156).
        # 목록이 없으면 빈 집합이라 어떤 GitHub 주체도 못 들어옵니다.
        _write(cls.root, GITHUB_ALLOW_FILE, "octocat\n")
        cls.srv = _Srv(cls.root)
```

`_write` 의 인자 차례가 다르면 **243행 근처의 쓰임새를 그대로 따라 하십시오.**

**(2) 짝이 되는 시험을 하나 더합니다.** `test_github_subject_cookie_is_accepted`
바로 아래에:

```python
    def test_github_subject_outside_allowlist_is_401(self):
        """허용 목록에서 지운 계정의 쿠키는 서명이 멀쩡해도 끊깁니다 (R12 T-156)."""
        c = server.sign_session(TOKEN, "gh:someoneelse", FAR)
        s, _, _ = self.get("/api/health", {"Cookie": f"{SESSION_COOKIE}={c}"})
        self.assertEqual(s, 401)
```

**그 밖에는 한 줄도 바꾸지 마십시오.** 다른 시험 클래스(`setUpClass` 가 603행 근처에
또 있습니다)는 건드리지 마십시오 - 거기서 빨개지는 것이 없습니다.
