# T-208 회수 검사가 **엉뚱한 것**을 재고 있습니다 - iframe 안에서 재게 고치십시오 (큐 7 N3)

고칠 파일은 **`tests/browser_monitor_auth.py`** 하나입니다. 제품은 고치지 않습니다.

## 읽을 것 (이것만)

- `tests/browser_monitor_auth.py` 전체 (283줄)
- `tools/aimem_monitor/server.py` 의 `app_csp()`(2046행 근처)와 `/app/` 티켓 처리(2556~2600행) - **읽기만**

**읽지 마십시오:** `AIMEM.md` 본문, `tools/aimem_db.py`, `projects/**`, 다른 시험 파일.

## 무엇이 잘못됐나 (R15 재검수 N3)

`run_revocation_checks()` 의 두 검사가 **재려던 것을 재지 않습니다.**

1. **`회수가 듣는다`** - `page.evaluate` 로 fetch 하는데 그 `page` 는 **모니터 최상위 창**입니다.
   그래서 세션 쿠키가 같이 실립니다. 실제 결과물 앱은 CSP `sandbox` 때문에 **불투명 출처**라
   쿠키가 안 실립니다. 즉 **운영에서 실제로 일어나는 상황을 안 재고 있습니다**
2. **`지운 뒤 새로 고치면 못 들어간다`** - iframe 의 `src` 를 `base + "/app/웹워들/"`(티켓 **없는**
   발급 경로)로 바꿉니다. 그래서 재는 것은 "옛 티켓이 아직 드는가" 가 아니라 "발급이 막히는가" 입니다

## 고칠 것

`run_revocation_checks()` 를 이렇게 바꾸십시오. **검사를 지우지 말고 늘리십시오.**

1. 지금 있는 최상위 fetch 검사는 **이름을 `회수가 듣는다 (최상위)` 로 바꿔 그대로 두십시오**
2. **새 검사 `회수가 듣는다 (iframe 안)`** 를 더하십시오:
   - `fl = page.frame_locator("iframe.proj-app-frame")` 가 아니라 **프레임 객체**가 필요합니다.
     `frame = page.frame_locator(...)` 로는 `evaluate` 를 못 하니
     `page.frames` 에서 url 에 `/app/~` 가 든 프레임을 골라 쓰십시오
     (`frame = next(f for f in page.frames if "/app/~" in f.url)`)
   - 그 **프레임 안에서** 옛 티켓의 `.js` 하위 자원을 `fetch(u, {cache:'no-store'})` 로 부르고
     상태가 **403** 인지 보십시오. 프레임이 불투명 출처라 쿠키가 안 실리는 것이 핵심입니다
   - fetch 가 `TypeError` 로 막히면(CSP `connect-src`) 그 사실을 detail 에 적고
     **대신 `<script src=옛 티켓 js>` 를 프레임 document 에 붙여 `onerror` 가 뜨는지**로 재십시오.
     어느 쪽이든 "옛 티켓 하위 자원이 프레임 안에서 못 들어온다" 를 재면 됩니다
3. **새 검사 `옛 티켓은 지운 뒤에도 안 든다`** 를 더하십시오:
   - iframe 의 `src` 를 **옛 티켓 URL 그대로**(`base + 옛 티켓 경로 + "/"`) 다시 넣고
     1.5초 기다린 뒤 `#board .tile` 이 **0개**인지 보십시오
   - 지금의 `지운 뒤 새로 고치면 못 들어간다`(발급 경로)는 **이름을 `지운 뒤 발급도 막힌다` 로 바꿔
     그대로 두십시오** - 그것도 재야 할 것입니다

## 검증 (이대로 돌려 보십시오)

```
python3 tests/browser_monitor_auth.py
```

마지막 줄이 `통과 N / 전체 N` 이고 **N 이 14 이상**, rc 0 이어야 합니다 (지금은 12/12).
브라우저를 못 띄우면 rc 2 입니다 - 그때는 `BLOCKED` 로 보고하십시오.

**검사가 제품 결함을 찾으면** 제품도 검사도 고치지 말고 첫 줄을
`NEEDS-FIX: <무엇이 어디서>` 로 보고하십시오. 제품 파일은 쓰기 범위 밖입니다.

## 보고

첫 줄은 `DONE` / `PARTIAL` / `BLOCKED` / `NEEDS-FIX: …`.
그 뒤에 마지막 줄(`통과 N / 전체 N`)과 새로 더한 검사 이름들을 적으십시오.
