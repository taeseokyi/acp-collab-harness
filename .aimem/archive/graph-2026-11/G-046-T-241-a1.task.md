# T-241 `/api/state` 계약표에 `claude_usage` 를 올리십시오

쓸 파일은 **하나**입니다: `tools/aimem_monitor/__init__.py`. **`server.py` 와 `tests/**` 는 읽기만
하고 절대 고치지 마십시오.** 계획을 세우지 말고 바로 고치십시오.

## 무엇이 틀렸나

`server.collect_state()` 가 최상위 키 `claude_usage` 를 내보내는데(정상 분기와 실패 분기 모두),
계약표 `SERVER_KEYS` 에는 그 키가 없습니다. 그래서
`tests/test_aimem_monitor_detail.py:489 test_collect_state_failure_branch_keys_match_normal` 이
`'claude_usage' : 정상 분기 키 집합이 계약과 다릅니다` 로 **빨갛습니다**. 계약표는 공개면의 정본이라
(파일 머리말) 키가 늘면 여기에도 적어야 합니다.

## 할 일

`SERVER_KEYS` 의 `projects` 항목 뒤에 `claude_usage` 를 한 항목 더하십시오. 다른 항목들처럼
**주석 한두 줄 + 값 모양**을 적습니다. 값 모양은 이렇습니다 (`server.claude_usage()` 가 돌려주는 것):

```
"claude_usage": "{at, age_seconds, rows:[{key, label, percent, resets_at_iso}]} 또는 null"
```

주석에는 "Claude Code 상태줄이 적어 둔 `.aimem/claude-usage.json` 을 읽어 만든 사용 한도
(2026-11-12, R18). 파일이 없거나 읽을 수 없으면 `null`" 정도를 적으십시오.
`STATE_KEYS`·`PUBLIC_FORBIDDEN`·`REQUEST_ROW_KEYS` 는 건드리지 마십시오.

## 검증

```bash
python3 -m unittest tests.test_aimem_monitor_detail tests.test_aimem_monitor_app tests.test_aimem_monitor_projects
```

`OK` 여야 합니다 (지금은 실패 1건).
