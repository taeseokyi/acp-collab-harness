# T-277 낱말 목록

쓸 파일: `projects/자모맞히기/data/answers.txt`, `data/allowed.txt`, `data/README.md`, `tools/build_words.py`, `web/js/words.js`(생성물), `tests/test_words.py` (모두 `projects/자모맞히기/` 아래, 새 파일). 다른 파일은 읽기만. **바로 파일을 쓰십시오.**

먼저 `.aimem/graph/inputs/r24/CONTRACT.md` 의 '칸(unit) 규칙' 과 '`web/js/words.js`' 절을 읽으십시오. 본보기로 `projects/웹워들/tools/build_words.py`·`projects/웹워들/tests/test_words.py` 를 보면 됩니다(영어 사전에서 뽑는 부분은 버림).

## 할 일

1. `data/answers.txt` - 정답 후보. 한 줄에 낱말 하나, **일상에서 흔히 쓰는 한국어 낱말**(명사 위주)을 **당신이 직접 고릅니다**. 자모로 풀면 꼭 6칸인 것만 남으므로 이런 꼴이 잘 맞습니다: 받침 있는 두 음절(`한국`, `학생`, `낙엽`, `공책`), 받침 없는 세 음절(`코끼리`, `바나나`, `자두나무` 는 안 됨 - 8칸), 겹받침·겹모음 섞인 것(`까닭`, `과일`). 칸 세기는 CONTRACT 의 규칙(쌍자음·ㅐㅔㅒㅖ 한 칸, 겹모음·겹받침 두 칸). **고유명사·욕설·비하어·외래 상표·너무 드문 말은 넣지 않습니다.** 6칸이 아닌 줄이 섞여도 빌드가 걸러 내니 넉넉히 적으십시오 - 걸러진 뒤 **300개 이상**이어야 합니다.
2. `data/allowed.txt` - 정답은 아니어도 추측으로 받을 낱말(덜 흔한 말, 동사·형용사 기본형 `읽다`·`없다` 등 포함). 빌드 뒤 ALLOWED(= answers ∪ allowed) 가 **1000개 이상**.
3. `tools/build_words.py` (표준 라이브러리만): 두 파일을 읽어 앞뒤 공백·빈 줄·`#` 주석 줄을 버리고, 완성형 한글 음절만으로 되어 있고 칸으로 6칸인 것만 남기고, 중복 제거. `ANSWERS` 는 정답 후보를 정렬한 뒤 `random.Random(20261113).shuffle` 로 섞은 순서, `ALLOWED` 는 합집합을 정렬한 순서. `web/js/words.js` 를 **정확히 이 꼴로** 씁니다 (검증이 이 꼴을 읽습니다):
   ```
   // 생성물 - 손으로 고치지 말고 tools/build_words.py 로 다시 만드십시오
   export const ANSWERS = ["…", "…"];
   export const ALLOWED = ["…", "…"];
   ```
   배열은 `json.dumps(목록, ensure_ascii=False)`. 걸러 낸 수를 표준출력에 찍습니다. 같은 입력이면 매번 같은 파일(바이트 단위).
4. `data/README.md` - 고른 기준, 출처('함대 작업자가 직접 고름, 외부 게임·사전 목록 복사 없음'), 이용 조건(저장소와 같음), 다시 만드는 명령.
5. `tests/test_words.py` (unittest, 6개 이상): 모든 낱말 6칸, 중복 없음, ANSWERS ⊆ ALLOWED, 개수 하한, 다시 만들면 같은 파일, 칸 풀기 예시(`한국`→`ㅎㅏㄴㄱㅜㄱ`, `까닭`→`ㄲㅏㄷㅏㄹㄱ`, `과자`→`ㄱㅗㅏㅈㅏ`).

## 스스로 확인

`python3 projects/자모맞히기/tools/build_words.py` 뒤 `python3 .aimem/graph/inputs/r24/v_words.py` 가 `words: 모두 통과`, `python3 -m unittest discover -s projects/자모맞히기/tests -p 'test_words.py'` 가 OK. (v_words.py 는 관리자 것 - 고치지 마십시오.)
