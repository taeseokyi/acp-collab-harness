## 왜 (재검수가 찾은 것)

앞 노드 T-249 가 고친 길과, 아직 시험이 못 잡는 변이 셋입니다.

1. **P1** - `at` 에 짝 없는 서러게이트(`"\ud800"`)가 있으면 `/api/state` 가 응답 없이 끊겼습니다
2. **P5** - `collect_state`/`_empty_state` 의 바깥 `try`(곁다리 카드가 상태를 죽이지 않게)를 지워도
   시험이 전부 초록이었습니다
3. **M2** - `claude_usage` 를 **한쪽 갈래에서만** 빼도 초록이었습니다(지금 시험은 둘을 한꺼번에만 봅니다)

## 더할 시험 (적어도 넷)

1. **서러게이트 `at`** - 임시 저장소의 `.aimem/claude-usage.json` 에
   `'{"at": "\\ud800", "rate_limits": {"five_hour": {"used_percentage": 40}}}'` 를 **글자 그대로**
   써 두고(이스케이프가 파일에 남게), `server.claude_usage(root)` 가 예외 없이 돌아오는 것
2. **그 파일로 `/api/state` 가 200** - 임시 포트 서버(`require_auth=False`)로 정상 갈래와,
   `mock.patch.object(reader, "collect", side_effect=RuntimeError("boom"))` 로 만든 **실패 갈래**
   **둘 다** 200 이고 본문이 `json.loads` 되는 것. (서버 띄우는 꼴은 이 파일 안의 기존 시험이나
   `tests/browser_monitor_usage.py` 의 `monitor_server()` 를 베끼십시오. **운영 서버를 부르지 마십시오.**)
3. **곁다리 카드가 상태를 죽이지 않는다 (P5)** -
   `mock.patch.object(server, "claude_usage", side_effect=RuntimeError("boom"))` 인 채로
   `server.collect_state(root)` 가 예외 없이 돌아오고 `state["claude_usage"] is None` 인 것.
   실패 갈래(`reader.collect` 도 예외)에서도 같은 것
4. **갈래마다 따로 (M2)** - `claude_usage` 키가 **정상 갈래 결과에 있다**는 단언과
   **실패 갈래 결과에 있다**는 단언을 **서로 다른 시험 두 개**로 나누십시오(한 시험이 둘을 함께
   보면 한쪽만 지워도 안 빨개집니다)

이미 있는 23건은 그대로 두십시오. 임시 폴더는 `tearDown` 에서 `shutil.rmtree` 로 치우십시오.
