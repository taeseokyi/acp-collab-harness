# T-132 모니터에서 **'실행' 을 눌렀을 때** 격리된 칸에 결과물이 뜨는지 잽니다

## 쓸 파일 (이 하나뿐입니다)

`tests/browser_monitor_ui.py` (**새 파일**)

## 배경 (이미 다 만들어져 있습니다)

모니터 첫 화면(`함대` 탭)의 **프로젝트** 칸에 `웹워들` 항목이 있고, 거기 **`실행`** 단추가 달렸습니다.
누르면 오른쪽 상세 패널(`#detail-body`)이 열리고 그 안에 `iframe.proj-app-frame` 이 들어갑니다.
그 iframe 은 **`sandbox="allow-scripts allow-popups allow-modals"`** 입니다 - `allow-same-origin` 이
없다는 것이 격리의 전부입니다. 당신이 할 일은 **그것이 실제로 그렇게 그려지는지** 재는 것뿐입니다.

## 뼈대 - 이대로 쓰십시오 (그대로 복사해도 됩니다)

```python
#!/usr/bin/env python3
"""<여기에 무엇을 재는 스크립트인지 한 줄>"""
import http.server
import pathlib
import sys
import threading
from contextlib import contextmanager

from playwright.sync_api import sync_playwright

ROOT = pathlib.Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT / "tools"))

from aimem_monitor import server          # noqa: E402


class Checks:
    def __init__(self):
        self.results = []

    def ok(self, goal, cond, detail=""):
        self.results.append((bool(cond), goal, detail))
        return bool(cond)

    def finish(self):
        failures = 0
        for passed, goal, detail in self.results:
            line = f"[{'OK' if passed else 'FAIL'}] {goal}"
            if detail:
                line += f" - {detail}"
            print(line)
            if not passed:
                failures += 1
        print(f"통과 {len(self.results) - failures} / 전체 {len(self.results)}")
        return failures


@contextmanager
def monitor_server():
    """인증 끈 평문 http 모니터를 임시 포트에 띄웁니다."""
    handler = type("H", (server.Handler,), {"root": ROOT, "require_auth": False, "tls": False,
                                            "access_token": None, "guard": server.LoginGuard(),
                                            "timeout": 5, "log_message": lambda *a, **k: None})
    httpd = http.server.ThreadingHTTPServer(("127.0.0.1", 0), handler)
    httpd.daemon_threads = True
    thread = threading.Thread(target=httpd.serve_forever, daemon=True)
    thread.start()
    try:
        yield f"http://127.0.0.1:{httpd.server_address[1]}"
    finally:
        httpd.shutdown()
        httpd.server_close()
        thread.join(timeout=3)
```

그리고 맨 아래:

```python
def main():
    checks = Checks()
    try:
        with monitor_server() as base:
            with sync_playwright() as pw:
                browser = pw.chromium.launch()
                try:
                    scenario(browser, base, checks)     # 아래에서 당신이 쓰는 함수
                finally:
                    browser.close()
    except Exception as exc:
        checks.ok("검사 실행", False, f"{type(exc).__name__}: {exc}")
    return checks.finish()


if __name__ == "__main__":
    raise SystemExit(main())
```

## `scenario(browser, base, checks)` 안에서 잴 것 (6개)

```python
ctx = browser.new_context(viewport={"width": 1280, "height": 900})
page = ctx.new_page()
page.goto(base + "/", wait_until="load")
page.wait_for_selector("#projects-list .proj-item", timeout=15000)
```

(프로젝트 칸은 **첫 화면(함대 탭)** 에 있습니다 - 탭을 누를 필요가 없습니다.)

1. **'실행' 단추가 눈에 보인다** - `#projects-list` 안에서 글자가 `실행` 인 단추를 찾아
   `is_visible()` 이 참 (`page.get_by_role` 보다 `page.locator("#projects-list")` 안에서
   `.proj-run` 클래스로 찾는 쪽이 확실합니다)
2. **누르면 미리보기 칸이 보인다** - 누른 뒤 `iframe.proj-app-frame` 이 `is_visible()` 이고
   `bounding_box()` 의 `height` 가 **300 이상** (`detail` 에 상자 숫자를 적으십시오)
3. **격리가 살아 있다** - 그 iframe 의 `get_attribute("sandbox")` 에 `allow-scripts` 가 있고
   **`allow-same-origin` 이 없다.** (이 검사가 이 파일의 핵심입니다 - 절대 무르게 쓰지 마십시오)
4. **안쪽이 진짜로 그려졌다** - `page.frame_locator("iframe.proj-app-frame")` 로 들어가
   `#board .tile` 이 **30개**이고 첫 칸이 `is_visible()` (`wait_for` 를 넉넉히 주십시오)
5. **패널 밖으로 잘리지 않는다** - iframe 의 `bounding_box()` 가 `#detail-body` 의
   `bounding_box()` 안에 들어간다 (오른쪽·아래가 2px 안쪽까지 허용). 두 상자를 `detail` 에 적으십시오
6. **'새 탭에서 열기' 링크** - `#detail-body` 안의 `a[target=_blank]` 가 보이고,
   `href` 가 `/app/` 으로 시작하며 `rel` 에 `noopener` 가 들어 있다

끝에 `ctx.close()` 하십시오.

## 반드시 지킬 것 - 지난 시도가 여기서 두 번 죽었습니다

이 일을 맡았던 지난 두 시도는 **파일을 만들지 않고 패치를 글자로 찍고 끝났습니다**
(`<tool_call>`, `<function=...>`, `*** End Patch` 가 보고 본문에 그대로 들어왔습니다).
**그런 글자를 보고에 쓰지 마십시오. 실제 파일 쓰기 도구를 쓰십시오.**
파일이 디스크에 없으면 한 일이 없는 것이고, 엔진이 그 시도를 실패로 봅니다.

한 번에 다 쓰려 하지 말고 **파일을 먼저 만들고**(위 뼈대만이라도) 그다음 검사를 채우십시오.
