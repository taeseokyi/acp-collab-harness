# T-221 작업 요청 폼의 프로젝트: **있는 것은 고르고, 없으면 새로 입력** (태석님 요청 Q-261112-a8be)

태석님 요청 전문: "작업요청에 프로젝트 목록 나오지않음. / 있는건 선태가능 하게. 없는건 추가 입력."

고칠 파일은 넷뿐입니다.

- `tools/aimem_monitor/static/index.html`
- `tools/aimem_monitor/static/app.js`
- `tools/aimem_monitor/static/style.css`
- `tools/aimem_monitor/static/sw.js` (버전 한 줄만)

**서버(`tools/aimem_monitor/server.py`)와 시험(`tests/**`)은 절대 고치지 마십시오.**

## 읽을 곳 (이것만)

- `tools/aimem_monitor/static/index.html` 의 `#request-form` 블록 (`req-title` ~ `request-submit`)
- `tools/aimem_monitor/static/app.js` 의
  - `renderFleetControl` 안에서 `project-list` `<datalist>` 를 채우는 블록 (1573~1583행 근처)
  - 요청 폼을 보내는 자리 (`request-form` 의 `submit` 처리, `req-project` 를 읽는 곳)
  - `requestEditForm(req)` 의 프로젝트 입력칸 (2690행 근처, `pi.setAttribute('list', 'project-list')`)
  - `renderAll(data)` (3380행 근처 - 매 갱신마다 그리는 자리)

AIMEM.md 는 읽지 마십시오.

## 지금 모습과 왜 안 보이는가

폼의 프로젝트 칸은 `<input id="req-project" list="project-list">` + `<datalist id="project-list">` 입니다.
두 가지 문제가 겹쳐 태석님 화면에 목록이 안 나옵니다.

1. `<datalist>` 는 **글자를 치기 시작해야** 후보가 뜹니다. 빈 칸을 눌러서는 아무것도 안 보입니다
2. 목록을 채우는 코드가 **`renderFleetControl` 함수 깊숙이** 들어 있는데, 그 함수는 위에서
   `if (!box) return;` 와 `if (!md) return;` 로 **먼저 빠져나갈 수 있습니다**. 함대 제어 상태를 못 읽으면
   목록이 영영 안 채워집니다

## 할 일

### 1) `index.html` - 고르는 칸 + 새로 넣는 칸

`req-project` 입력 하나를 **고르는 `<select>` + 새 이름 입력** 두 칸으로 바꿉니다. `<datalist>` 는 지웁니다.

```html
<label for="req-project-pick">프로젝트 <span class="hint">결과물이 쌓일 곳 · 비우면 함대 자체의 일</span></label>
<select id="req-project-pick" name="project_pick">
  <option value="">(함대 자체의 일 - 프로젝트 없음)</option>
  <option value="__new__">+ 새 프로젝트…</option>
</select>
<input id="req-project" name="project" type="text" maxlength="40" placeholder="새 프로젝트 이름" hidden>
```

- 있는 프로젝트는 `(함대 자체의 일…)` 과 `+ 새 프로젝트…` **사이**에 `<option>` 으로 들어갑니다
- `req-project` 입력은 평소 `hidden` 이고, `+ 새 프로젝트…` 를 골랐을 때만 보입니다

### 2) `app.js` - 목록 채우기를 제 함수로 떼어 냅니다

- `renderFleetControl` 안의 `project-list` 블록을 **통째로 지우고**, 새 함수를 만듭니다.

  ```js
  // 작업 요청 폼의 프로젝트 고르기 - 있는 프로젝트는 고르고 없으면 새로 입력한다 (요청 Q-261112-a8be).
  // renderFleetControl 안에 있던 것을 떼어 냈다 - 그 함수는 함대 상태를 못 읽으면 먼저 return 해서
  // 목록이 영영 안 채워졌다.
  function renderProjectPicker(data) { … }
  ```

- `renderProjectPicker(data)` 가 하는 일
  - 이름 목록 = `(data.projects || []).map((x) => x && x.name).filter(Boolean)`
  - `#req-project-pick` 의 `<option>` 들을 다시 만듭니다. **맨 앞은 `(함대 자체의 일 - 프로젝트 없음)`
    (`value=''`), 맨 뒤는 `+ 새 프로젝트…` (`value='__new__'`)**, 그 사이에 이름들
  - **고르던 값을 잃지 않게** 합니다: 다시 그리기 전에 지금 `value` 를 기억했다가, 그 값이 새 목록에
    아직 있으면 그대로 돌려놓습니다. 이름 목록이 **바뀌지 않았으면 아예 다시 그리지 마십시오**
    (5초마다 갱신되므로, 고르는 중에 목록이 깜박이면 안 됩니다. 지금 코드가 `dl.dataset.names` 로 하던 것과
    같은 방식을 쓰십시오)
  - `#req-project-pick` 의 `change` 에서 `value === '__new__'` 면 `#req-project` 의 `hidden` 을 풀고
    `focus()`, 아니면 다시 `hidden` 으로 두고 값을 비웁니다. **이 리스너는 한 번만 달아야 합니다**
    (예: `el.dataset.bound` 로 표시)
- `renderAll(data)` 에서 `renderProjectPicker(data);` 를 부릅니다 (다른 render 들 옆에).
- **요청을 보낼 때 프로젝트 값**은 이렇게 고릅니다.

  ```js
  const pick = $('req-project-pick');
  const project = (pick && pick.value === '__new__')
    ? ($('req-project').value || '').trim()
    : ((pick && pick.value) || '').trim();
  ```

  지금 `req-project` 의 값을 읽어 `POST /api/requests` 에 싣는 자리를 위 값으로 바꾸십시오.
  **보낸 뒤 폼을 비울 때** 고르는 칸도 `''` 로 돌리고 새 이름 칸을 다시 `hidden` 으로 두십시오.
- `requestEditForm(req)` 의 프로젝트 칸도 같게 만듭니다. `pi.setAttribute('list', 'project-list')` 는 더
  쓸 수 없으니(`datalist` 를 지웠습니다), **같은 꼴의 `<select>` + 새 이름 입력** 한 쌍을 만들어 쓰고,
  저장할 때 위와 같은 규칙으로 값을 고르십시오. 이 폼에서는 **지금 요청의 프로젝트가 처음부터 골라져
  있어야** 합니다 (목록에 없는 이름이면 그 이름을 `<option>` 으로 하나 더 넣어 고른 상태로 두십시오).

### 3) `style.css`

- `select` 가 폼 안에서 다른 입력칸들과 **같은 너비·높이·테두리**로 보이게 규칙을 더하십시오.
  폰 폭(390px)에서 칸이 화면 밖으로 나가면 안 됩니다. 이미 있는 규칙을 지우지 말고 필요한 것만 더하십시오.

### 4) `sw.js`

- `const VERSION = 'aimem-shell-v30';` 을 `'aimem-shell-v31'` 로 올립니다.
  (`v30` 이 아니라 다른 값이면, 지금 적힌 값의 숫자에 1 을 더하십시오.)
