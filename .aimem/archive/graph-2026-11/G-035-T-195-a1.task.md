# T-195 **왜 못 들어오는지**가 감사 로그에 남게 하십시오

고칠 파일은 **`tools/aimem_monitor/server.py`** 와 **`tests/test_aimem_monitor_access.py`** 둘뿐입니다.

## 읽을 것 (이것만)

- `tools/aimem_monitor/server.py` 의 `audit()` (611행 근처) · `_subject()` (2271행 근처) ·
  `_audit()` 메서드 (2252행 근처) · `github_allowed_logins()` (480행 근처)
- `tests/test_aimem_monitor_access.py` 전체 (짧습니다)

**읽지 마십시오:** `AIMEM.md` 본문, `tools/aimem_db.py`, `projects/**`.

## 결함 (R12 T-157 검수 결함 3)

`_subject()` 는 GitHub 주체를 **요청마다** 허용 목록과 대조하고, 목록에 없으면 조용히 `None` 을
돌려줍니다. 그 뒤 게이트가 401/`/login` 을 내지만 **감사 로그(`.aimem/audit.log`)에는 한 줄도
안 남습니다.** `monitor.log` 의 401 뿐이라, 사람이 "왜 내가 못 들어가지" 를 물어도 아무도 못 봅니다.

## 고칠 것

1. `_subject()` 에서 허용 목록에 걸려 `None` 을 돌려주기 직전에
   `audit(self.root, "github-revoked", self._client_ip(), subject, "허용 목록 밖")` 을 남기십시오.
   **토큰·비밀은 절대 detail 에 넣지 마십시오.**
2. **홍수를 막으십시오.** 화면은 5초마다 폴링하므로 그대로 두면 분당 열 줄이 넘습니다.
   모듈 수준에 `_REVOKED_AUDIT_MIN_SEC = 60` 과 `_revoked_last = {}` + 잠금(`threading.Lock`)을 두고,
   **같은 `(주체, ip)` 는 60초에 한 줄만** 남기십시오. 사전은 무한히 자라면 안 됩니다 -
   항목이 256개를 넘으면 가장 오래된 것부터 버리십시오 (`collections.OrderedDict` 면 충분합니다).
3. 토큰 Bearer 가 틀린 경우는 **건드리지 마십시오** (이미 다른 길로 기록되고, 무작위 대입이 로그를 채웁니다).

## 시험 (`tests/test_aimem_monitor_access.py` 에 더합니다. 지금 22개 -> 최소 25개)

- 허용 목록에 있던 계정의 세션 쿠키로 부른 뒤, 목록에서 그 계정을 지우고 다시 부르면
  `.aimem/audit.log` 에 `github-revoked` 줄이 **정확히 하나** 생긴다 (주체 칸에 `gh:<login>`)
- 같은 주체·같은 ip 로 바로 연달아 두 번 더 불러도 **줄이 늘지 않는다** (60초 억제)
- `_REVOKED_AUDIT_MIN_SEC` 를 0 으로 바꿔 끼우면 다시 늘어난다 (억제가 '영영 한 줄' 이 아님을 보임)

시험이 쓰는 `root` 는 반드시 임시 폴더여야 합니다. **운영 `.aimem/audit.log` 에 쓰지 마십시오.**
