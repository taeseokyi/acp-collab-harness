# T-252 `tests/test_monitor_shutdown.py` (**새 파일**): 진짜 SIGTERM 종료 실측

쓸 파일은 **하나**, 새로 만드는 `tests/test_monitor_shutdown.py` 입니다.
**`tools/**` 와 다른 `tests/**` 는 읽기만 하고 절대 고치지 마십시오.** 바로 파일을 만드십시오.

## 왜

R19 재검수(P2)가 `tools/aimem_monitor/server.py` 에 변이 셋을 넣었는데 **모니터 시험 117건이
전부 초록**이었습니다 - 아무 시험도 진짜 SIGTERM 종료 경로를 밟지 않기 때문입니다.

- 변이 1: `serve()` 의 `signal.signal(signal.SIGTERM, _sigterm_interrupt)` 설치를 지움
- 변이 2: `finally` 의 처리기 되돌리기(`signal.signal(signal.SIGTERM, old_sigterm)`)를 지움
- 변이 3: `finally` 의 `flush_denied_audit(root)` 호출을 지움

**이 셋 중 어느 하나라도 지우면 새 시험이 빨개져야 합니다.**

## 알아야 할 것 (읽을 파일: `tools/aimem_monitor/server.py` 의 `serve`·`flush_denied_audit` 만)

- `server.AUDIT_LOG == ".aimem/access.log"` - 저장소 뿌리 기준 상대 경로
- `flush_denied_audit(root)` 는 모듈 전역 `server._denied_cap_skipped + server._denied_evicted_skipped`
  가 0 보다 크면 `audit(root, "audit-dropped", "-", None, f"상한 생략 {n}건")` 한 줄을 그 파일에 쓰고
  두 전역을 0 으로 되돌립니다. 0 이면 **아무것도 쓰지 않습니다**
- `serve(host, port, root, once=False, tls=False, auth=None)` - `auth=False` 로 부르면 인증이 꺼집니다
- `audit` 줄은 탭으로 나뉘고 둘째 칸이 event (`audit-dropped`) 입니다

## 만들 시험 셋 (`unittest`, 표준 라이브러리만)

**(1) `test_sigterm_flushes_denied_audit`** - 진짜 자식 프로세스 + 진짜 SIGTERM
- `tempfile.mkdtemp()` 로 임시 저장소 `d` 를 만들고 `d/.aimem` 을 만듭니다
- 자식을 `subprocess.Popen([sys.executable, "-c", code], ...)` 로 띄웁니다. `code` 는:
  `tools` 를 `sys.path` 에 넣고 `from aimem_monitor import server` 한 뒤
  `server._denied_cap_skipped = 5` 로 두고, 준비됐음을 **stdout 에 한 줄 찍고 flush** 한 다음
  `server.serve(host="127.0.0.1", port=0 이 아닌 빈 포트, root=d, auth=False)` 를 부릅니다
  (빈 포트는 부모가 `socket` 으로 잡았다 놓고 번호를 넘기십시오)
- 부모는 자식이 찍은 준비 줄을 읽고(또는 `/api/health` 가 200 이 될 때까지 최대 20초 폴링),
  `proc.send_signal(signal.SIGTERM)` 을 보낸 뒤 `proc.wait(timeout=20)` 합니다
- `d/.aimem/access.log` 를 읽어 **둘째 칸이 `audit-dropped` 인 줄이 있고 그 줄에 `5` 가 있는지**
  를 `assert` 합니다. 실패 메시지에 로그 전문과 자식 stdout/stderr 를 넣으십시오 (`msg=`)

**(2) `test_serve_restores_sigterm_handler`** - 처리기 되돌리기
- 자식 프로세스에서 `serve(..., once=True, auth=False)` 를 부르고, 부모가 `/api/health` 를
  한 번 때려 `handle_request()` 한 판을 끝낸 뒤, 자식이 `serve` 가 돌아온 **다음**
  `repr(signal.getsignal(signal.SIGTERM))` 을 stdout 에 찍게 합니다
- 부모는 그 글자가 `signal.SIG_DFL` 을 가리키는지(`"SIG_DFL"` 또는 `"Handlers.SIG_DFL"` 포함)
  확인하고 `_sigterm_interrupt` 가 **남아 있지 않은지** `assert` 합니다
- 자식 안에서 `serve` 호출 전 `signal.getsignal(signal.SIGTERM)` 도 함께 찍어 비교에 쓰십시오

**(3) `test_sigterm_handler_is_installed_right_before_the_serve_loop`** - 구조
- `inspect.getsource(server.serve)` 줄을 보고 `signal.signal(signal.SIGTERM` 줄이
  **마지막 `log_line(` 줄보다 뒤**, **`handle_request()`/`serve_forever()` 줄보다 앞**이며
  그 사이에 `log_line(` 이 **하나도 없음**을 `assert` 합니다 (재검수 R19-P6)

## 규칙

- 자식 프로세스·포트·임시 폴더는 `finally` 에서 반드시 거두십시오(`proc.kill()`, `shutil.rmtree`).
  **자기가 만든 `/tmp` 폴더를 지우는 것은 괜찮습니다**
- `tls` 는 쓰지 마십시오(인증서가 필요합니다). `auth=False` + http 로 띄웁니다
- 시간은 넉넉히(20초) 주되 무한정 기다리지 마십시오. 시험이 걸리면 안 됩니다
- 제품(`server.py`)이 틀려서 시험이 빨개지면 **고치지 말고** 보고 첫 줄을
  `NEEDS-FIX: <무엇이 어디서>` 로 쓰십시오

## 검증

검증 명령이 봅니다: `python3 -m unittest tests.test_monitor_shutdown` 이 **rc 0** 이고
그 모듈의 **시험이 3건 이상**인 것.
