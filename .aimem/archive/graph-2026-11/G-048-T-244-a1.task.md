# T-244 `server.py`: 사용 한도 카드가 `/api/state` 를 죽이는 것 둘과, SIGTERM 때 감사 비우기

쓸 파일은 **하나**입니다: `tools/aimem_monitor/server.py`. **`tests/**` 와 다른 `tools/**` 는 읽기만
하고 절대 고치지 마십시오.** 계획을 세우지 말고 바로 고치십시오. (적대적 검수 N1·N2·N4)

## N1 (높음) 깊은 중첩 JSON 이 `/api/state` 를 통째로 죽입니다

`.aimem/claude-usage.json` 이 `{"at": ..., "rate_limits": {...}, "pad": "["*1500 + "]"*1500}` 처럼
깊게 중첩돼 있으면(3 KB 면 충분, 64 KiB 상한 안) `claude_usage()` 의 `json.loads` 가
**`RecursionError`** 를 던집니다. `except (OSError, ValueError, UnicodeDecodeError)` 가 못 잡아
`/api/state` 가 응답 없이 연결을 끊습니다(실측 `RemoteDisconnected`). 실패 분기 `_empty_state()` 도
**같은 함수를 부르므로** 대체 화면도 못 뜹니다. 함수 설명문의 "로그도 예외도 없습니다" 도 거짓이 됩니다.

고치는 법 (둘 다 하십시오):
1. `claude_usage()` 안의 `except` 를 `except (OSError, ValueError, UnicodeDecodeError, RecursionError)` 로 넓히기
2. **부르는 자리 둘을 한 번 더 감싸기** - `collect_state()`(`:1135` 근처)와 `_empty_state()`(`:895` 근처)에서
   ```python
   try:
       state["claude_usage"] = claude_usage(root)
   except Exception:  # noqa: BLE001 - 곁다리 카드가 상태 전체를 죽이지 않게
       state["claude_usage"] = None
   ```
   (작은 도우미 하나로 묶어 두 자리에서 불러도 좋습니다.) **키는 두 갈래 모두 반드시 남아야 합니다.**

## N2 (높음) `at` 의 시간대 변환이 `OverflowError` 를 던집니다

`at="0001-01-01T00:00:00+05:00"` 이나 `"9999-12-31T23:59:59-05:00"` 이면 `:988` 근처
`parsed_at.astimezone()` 가 **`OverflowError: date value out of range`** 를 던지는데 `except (TypeError, ValueError)`
가 못 잡습니다. → `except (TypeError, ValueError, OverflowError)`. (같은 파일의 `_usage_resets_at` 은
이미 `OverflowError` 를 잡고 있습니다 - 그 꼴에 맞추는 것입니다.)

## N4 (중간) SIGTERM 으로 내리면 `flush_denied_audit` 이 안 돕니다

`serve()` 의 `finally:` 에 `flush_denied_audit(root)` 가 있지만, 운영은 `monitorctl.sh` 가
`kill "$pid"`(**SIGTERM**)로 내립니다. 서버에 SIGTERM 처리기가 없어 기본 동작으로 **즉사**하고
`finally` 가 돌지 않습니다. 그래서 거절 감사의 '상한 생략 N건' 이 영영 안 나갑니다.

고치는 법: `serve()` 안에서 `httpd` 를 만든 뒤 SIGTERM 처리기를 걸고, 끝날 때 **원래 처리기로
되돌리십시오**(`signal.signal` 의 반환값을 보관). 처리기는 `KeyboardInterrupt` 를 일으키거나
`httpd.shutdown()` 을 불러 `finally` 로 가게 하면 됩니다. `signal` 모듈이 이미 import 돼 있지
않으면 파일 맨 위 import 들에 더하십시오. **주 스레드가 아니면 `signal.signal` 이
`ValueError` 를 던지므로** 그 경우는 조용히 건너뛰십시오(시험이 스레드에서 서버를 띄웁니다).
`once=True` 갈래도 그대로 돌아야 합니다.

## 하지 말 것

- 감사 상한·티켓·인증 쪽 코드는 건드리지 마십시오
- `claude_usage()` 가 돌려주는 모양(`{at, age_seconds, rows:[...]}`)을 바꾸지 마십시오
- 시험 파일은 다음 노드(다른 슬롯)가 씁니다
