## 물을 것

1. **D1 이 정말 닫혔는가.** 무인증 요청 1,000번(경로 전부 다름 · `app-ticket-bad`·`token-bad`·
   `session-bad` 세 갈래 모두)으로 `.aimem/access.log` 가 얼마나 느는지 **직접 재십시오.**
   동시 요청(스레드 10개)으로도 재십시오 - 전역 상한에 **경쟁 조건**이 없는지
2. **감사 범위를 잃지 않았는가 (D5 회귀).** 억제가 지나치면 **진짜 공격이 안 남습니다.**
   - 허용 목록에서 지운 계정의 티켓 사용이 여전히 남는가
   - 서로 다른 주체의 거절이 서로를 가리지 않는가
   - 1분 창이 지난 뒤 다시 남는가, `생략 N건` 의 **숫자가 맞는가**(삼킨 수와 같은가)
3. **새 상한 자체가 공격면이 아닌가.** 무인증 홍수로 전역 상한을 채워 두면
   그 1분 동안 **진짜 거절(인증된 주체)이 묻히는가.** 묻힌다면 등급을 매기십시오
4. **D2 수정이 과하지 않은가.** 세션 쿠키가 있지만 만료된 창을 열어 둔 평범한 사용자가
   폴링으로 로그를 불리지 않는가
5. **T-214 의 새 시험이 거짓 초록이 아닌가.** 사본에서 M10·M12·M13·M15·M17 변이를 **다시 넣어**
   이번에는 빨개지는지 확인하고 표로 적으십시오
6. **브라우저가 여전히 멀쩡한가** - `python3 tests/browser_monitor_auth.py` (`통과 14 / 전체 14`)

## 변이 시험은 **사본에서**

```
cp -a . /tmp/r16rev2 && rm -rf /tmp/r16rev2/.aimem/tls /tmp/r16rev2/.git
```

끝나면 **`rm -rf /tmp/r16rev2`** 로 지우십시오 (자기가 만든 `/tmp` 폴더는 지워도 됩니다).
하네스가 `rm -rf` 를 막으면 **지우지 말고 그 사실을 "남은 것" 에 적으십시오.**
운영 서버를 `curl` 로 부르지 마십시오(401).
