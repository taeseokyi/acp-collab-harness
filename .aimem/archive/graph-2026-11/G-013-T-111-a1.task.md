# T-111 `browser_ui.py` 의 검사 두 군데를 제대로 고치기

## 고칠 파일 (이 하나뿐입니다)

`projects/웹워들/tests/browser_ui.py`

**앱(`web/` 아래)은 건드리지 마십시오.** 다른 테스트 파일도 남의 것입니다.

## 왜 고치나

지금 이 스크립트는 **59개 중 58개를 통과하지만, 통과한 것 중 하나가 거짓말입니다.**

### 1. "공유 단추가 hidden" 검사가 속고 있습니다 (중요)

`[OK] 통계 - 빈 상태에서는 공유 단추가 hidden` 이 통과하는데, **실제로는 그 단추가 화면에
멀쩡히 보입니다.** `hidden` **속성**은 붙어 있지만 CSS 가 그것을 이겨서 보이기 때문입니다
(관리자 실측: `hidden` 속성 있음, `is_visible() == True`, 상자 104×45).
속성만 보는 검사라 결함을 놓쳤습니다.

→ 이 검사를 **정말 안 보이는지**로 바꾸십시오. `get_attribute("hidden")` 이 아니라
   `page.locator("#btn-share").is_visible()` 가 `False` 인지(또는 `bounding_box()` 가 `None` 인지)를
   보십시오. 속성도 함께 보는 것은 좋지만, **보이는지 여부가 반드시 들어가야 합니다.**
   판이 끝난 뒤 "공유 단추가 보임" 쪽 검사도 같은 기준(`is_visible() == True`)으로 맞추십시오.

   이 결함은 T-110 이 CSS 에서 고치고 있습니다. 고쳐졌다면 이 검사는 통과할 것이고,
   아직이라면 **정직하게 실패해야 맞습니다** - 통과시키려고 무르게 만들지 마십시오.

### 2. 테마 검사가 아무것도 증명하지 못합니다

`[FAIL] 설정 - #board 배경색이 밝을 때와 실제로 다름 - 밝음=rgba(0, 0, 0, 0) 어둡=rgba(0, 0, 0, 0)`

`#board` 에는 배경색이 **아예 없습니다**(투명). 그래서 테마를 바꿔도 당연히 똑같습니다.
관리자가 재어 본 실제 값:

| 요소 | 밝은 테마 | 어두운 테마 |
| ---- | --------- | ----------- |
| `body` | `rgb(255, 255, 255)` | `rgb(18, 18, 19)` |
| `html` · `#app` · `#board` · `.tile` | `rgba(0, 0, 0, 0)` | `rgba(0, 0, 0, 0)` |

→ 비교 대상을 **`body`** 로 바꾸십시오. 두 값이 서로 다르고, 어두운 테마 쪽이 실제로 어두운지
   (예: 밝기 합이 더 작은지)까지 보면 더 좋습니다. `<html>` 의 `data-theme` 속성을 보는
   기존 검사는 그대로 두십시오 - 속성과 **실제로 칠해진 색**을 둘 다 봐야 합니다.

색약 모드의 `correct` 타일 배경색 비교는 지금 그대로 두십시오 (타일에는 상태별 배경색이 실제로
칠해집니다 - `rgb(245, 121, 58)` 주황 / 보통은 `rgb(106, 170, 100)` 초록).
