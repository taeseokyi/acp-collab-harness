# T-170 이번에 바뀐 화면을 **브라우저에서 실제로** 재십시오

고칠 파일은 **`tests/browser_monitor_ui.py` 하나**입니다(지금 224줄, 검사 10개).
덧붙이기만 하고 기존 검사는 지우지 마십시오. 다른 파일은 고치지 마십시오.

## 읽을 것 (이것만)

- `tests/browser_monitor_ui.py` **전부** (224줄) - `Checks`·`monitor_server()`·`main()` 꼴을 그대로 따릅니다

`app.js`(3,200줄)·`style.css`·`server.py` 는 **읽지 마십시오.** 아래 설명이면 충분합니다.

## 무엇이 바뀌었나

1. `KISTI LLM 서버` 카드(`#kisti-section`)가 **없어졌습니다**
2. 함대 현황의 `현재 목표` 항목이 **`이번 라운드`** 로 바뀌었습니다
3. 서브태스크가 없는 요청의 ETA 가 `ETA 지금시각 · 0초` 대신 **`ETA 미정`** 이고,
   빈 자리 문구가 상태마다 다릅니다(`NEW` → `관리자 분담 대기`, `DONE` → `서브태스크 없이 끝난 요청입니다` 등)
4. '작업자 실행 상태' 표의 프로젝트 칸에서 **프로젝트 이름만 굵습니다**
   (`.proj-tag .proj-name` 이 700, 함대 행의 이름과 `· R13` 꼬리표는 400)
5. 생략된 칸(`.elide`)을 **누르면 그 자리에서 전문이 펼쳐집니다**(`.elide-open` class 가 붙음)

## 더할 검사 다섯 개 (기존 `checks.ok(목표, 조건, 상세)` 꼴)

**상세에는 실제로 잰 값**(px, font-weight 숫자, 텍스트)을 적으십시오. 속성이 아니라
**그려진 것**을 재는 것이 규칙입니다.

1. **KISTI 카드가 화면에 없다** - `page.query_selector('#kisti-section')` 가 `None` 이고,
   `page.content()` 에 `KISTI` 가 없다
2. **'이번 라운드' 가 보이고 내용이 있다** - 함대 탭에서 `#aimem-meta` 안에 `현재 목표` 라는
   글자가 **없고** `이번 라운드` 가 **`is_visible()`** 이며, 그 값 칸의 텍스트가 `-` 도 빈 문자열도 아니다
3. **분담 전 요청의 ETA 가 '미정' 이다** - 요청 트리 탭을 열고, 서브태스크가 0건인 요청 항목에서
   `.eta` 의 텍스트가 `ETA 미정` 이거나 `종료` 이고, **`ETA ` 뒤에 오늘 날짜·시각이 붙은 것이 하나도
   없는지**를 `.eta` 전부를 모아 확인한다. 또 그 항목의 빈 자리 문구가 요청 상태에 맞는다
   (`DONE` 인데 `관리자 분담 대기` 라고 적혀 있으면 실패)
4. **프로젝트 칸의 볼드 기준** - '작업자 실행 상태' 표에서 `getComputedStyle` 로
   `.proj-tag .proj-name` 의 `fontWeight` 가 **700 이상**(프로젝트가 있는 행)이고,
   `.proj-tag.none .proj-name` 과 `.proj-round` 는 **500 이하**다.
   해당 행이 없으면 그 조건은 `checks.ok(..., True, '해당 행 없음')` 으로 넘기지 말고
   **없다는 사실 자체를 실패로** 두십시오 - 빈 검사를 만들지 않기 위해서입니다
5. **생략된 제목을 눌러 펼칠 수 있다 (폰 폭 390px)** - `page.set_viewport_size({'width':390,'height':780})`
   로 바꾸고 보드·큐·그래프 중 `.elide[role="button"]` 하나를 고른 뒤
   - 누르기 **전**: `scrollWidth > clientWidth` (실제로 잘려 있다)
   - 누른 **뒤**: `.elide-open` class 가 붙고 `bounding_box()['height']` 가 커지며
     `scrollWidth <= clientWidth + 1` (전문이 보인다)
   - 누른 뒤에도 **상세 오버레이(`#detail-overlay`)가 열리지 않았다**(`stopPropagation` 확인)
   - 가로 스크롤이 생기지 않았다(`document.scrollWidth - innerWidth === 0`)

## 규칙

- **`sleep` 으로 버티지 마십시오.** `page.wait_for_selector` / `wait_for_function` 을 쓰고,
  꼭 필요하면 `page.wait_for_timeout(300)` 한 번까지만
- 포트·날짜를 숫자로 박지 마십시오
- **검사가 제품 결함을 드러내면 제품을 고치지 말고** 첫 줄을 `NEEDS-FIX: <무엇이 어디서>` 로 보고하십시오
- 덧붙이는 부분은 **150줄 안쪽**. 한 응답에 다 못 쓰겠으면 뼈대(함수 정의와 `main()` 등록)를
  먼저 쓰고 이어서 본문을 채우십시오

## 검증

```bash
python3 tests/browser_monitor_ui.py
```

마지막 줄 `통과 n / 전체 m` 의 **`m` 이 15 이상**이어야 합니다(지금 10).

## 보고

첫 줄은 `DONE` / `PARTIAL` / `BLOCKED` / `NEEDS-FIX: …` 중 하나만. 그 아래 여섯 줄 안쪽으로
검사 다섯 개가 무엇을 재는지 한 줄씩과 `통과 n / 전체 m` 줄을 그대로 옮기고,
**실패한 검사가 있으면 어느 것이 왜 실패했는지** 적으십시오.
