앞 태스크가 서버에서 `state.kisti` 와 `state.aimem.goal` 을 **이미 없앴습니다.** 화면이 그 둘을
읽고 있으니 지금은 빈 카드와 `-` 가 뜹니다. 그것을 치웁니다.

고칠 파일은 셋뿐입니다. 다른 파일은 고치지 마십시오.

- `tools/aimem_monitor/static/app.js`
- `tools/aimem_monitor/static/index.html`
- `tools/aimem_monitor/static/style.css`

`app.js` 는 3,279줄입니다. **아래에 적은 곳만** 보십시오.

## 1. KISTI 카드 제거 (요청 `Q-261111-2665`)

- `app.js`
  - **2173~2186행** `function kistiItem(label, value)` 통째로
  - **2187~2232행 근처** `function renderKisti(data)` 통째로
  - **2992행 근처** `renderKisti(data);` 호출 한 줄
  - **74~95행 근처** 데모 데이터(`DEMO` 상태 객체) 안의 `kisti: { … }` 항목
- `style.css`
  - **718~755행 근처** `.kisti-line` · `.kisti-item` · `.kisti-label` · `.kisti-value` ·
    `.kisti-age` · `.kisti-error` · `.kisti-warn` 규칙
  - **1154~1155행** 과 **1227행** 의 `.kisti-*` 규칙

끝나고 세 파일에 `kisti` 라는 글자가 **하나도 남지 않아야 합니다**(`kistillm` 이라는 모델 이름이
데모 슬롯 데이터 39·61행에 있는데, 그것은 **남깁니다** - 모델 이름이지 감시가 아닙니다).

## 2. '현재 목표' → '이번 라운드' (요청 `Q-261111-e099`)

태석님: "현재 목표는 항상 고정으로 제공하는 정보가 없습니다." 맞습니다 - `AIMEM.md` 1절의 고정
문구를 그대로 읽어 왔습니다. 그 자리에 **라운드마다 바뀌는 것**을 넣습니다.

`app.js` 의 `renderMeta(data)` (**1062~1090행**)에서:

- `const goal = aimem.goal || {};` 와 `goalWrap`·`goalText`·`goalStatus`·`goalItem` 을 만들어
  `box` 에 붙이던 부분(**1076~1088행**)을 **전부 지웁니다**
- 그 자리에 `이번 라운드` 항목을 넣습니다. 쓸 자료는 이미 화면이 받고 있는 `data.fleet` 입니다.

  ```js
  const fl = data.fleet || {};
  const lr = fl.last_round || null;
  const roundWrap = document.createElement('div');
  roundWrap.className = 'goal-value';
  const roundText = document.createElement('span');
  roundText.textContent = lr && lr.round
    ? 'R' + lr.round + (lr.at ? ' · ' + fmtDateTime(lr.at) : '')
    : '띄운 라운드 없음';
  roundWrap.appendChild(roundText);
  const roundStatus = document.createElement('span');
  roundStatus.className = 'goal-status';
  roundStatus.textContent = lr && lr.report_status ? '보고 ' + lr.report_status
                                                   : (fl.label || show(fl.mode, '-'));
  roundWrap.appendChild(roundStatus);
  const roundItem = metaItem('이번 라운드', roundWrap);
  roundItem.classList.add('meta-goal');
  box.appendChild(roundItem);
  ```

- `style.css` 의 `.goal-value` · `.goal-status` · `.meta-goal` 규칙은 **그대로 씁니다**(이름만
  옛날 것이지 자리는 같습니다). 지우지 마십시오
- `fmtDateTime` 과 `show` 와 `metaItem` 은 이 파일에 이미 있습니다. 새로 만들지 마십시오
