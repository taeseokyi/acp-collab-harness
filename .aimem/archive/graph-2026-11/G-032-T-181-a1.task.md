## 할 것 A - 요청 트리 탭에서도 정리할 수 있게 (요청 `Q-261111-731b` 1번)

`index.html` 의 `#requests-section` 안, `<h2>` 와 `<div id="requests-list">` **사이**에 한 줄을 더하십시오.

```html

```

`app.js` 의 `renderRequests` 가 그 칸을 채웁니다.

- 글: `끝난 요청 N건 · 끝난 그래프 M개`
  - N = `data.requests` 중 `status` 가 `DONE`·`REJECTED` 인 것
  - M = `data.graphs` 중 **노드가 하나 이상 있고 모든 노드의 `status` 가 `done`·`failed`·`blocked` 중 하나**인 것
- 그 옆에 `끝난 것 정리…` 단추를 `linkButton('끝난 것 정리…', openArchivePanel)` 로 두십시오
  (보드 탭의 것과 **같은 함수**를 부릅니다 - 새 패널을 만들지 마십시오)
- 끝난 것이 0건이면 단추는 두되 글은 `끝난 요청 없음` 으로 둡니다

`openArchivePanel` 의 설명 목록(2076~2079행)에 **새 종류 다섯 줄**을 더하십시오:

```
['작업자 실행 기록',     '함대 탭 작업자 실행 상태에서 사라지고 archive/runs-<월>/ 로 옮겨집니다']
['이벤트',              '보드·큐 탭의 이벤트 목록에서 사라지고 archive/events-<월>.md 로 옮겨집니다']
['핸드오프 (최신 12건 제외)', 'archive/handoff-<월>.md 로 옮겨집니다 - 최신 12건은 무엇이든 남습니다']
['전달 기록',           '그 라운드의 그래프가 모두 정리되면 archive/relay-<월>/ 로 함께 옮겨집니다']
['오래된 로그 줄',      'monitor.log·fleet-mode.log 의 기준 시각보다 오래된 줄만. 접속 기록(access.log)은 건드리지 않습니다']
```

그리고 미리보기·결과 줄(2107행)에 **종류별 건수**를 보이십시오. 서버가 이제 이렇게 줍니다:

- 미리보기: `body.plan.records = {runs, events, handoff, relay, log_lines}`, `body.plan.total_records`
- 실행 뒤: `body.moved_counts = {tasks, requests, graphs, runs, events, handoff, relay, log_lines, …}`

둘째 줄에 `실행 기록 N건 · 이벤트 N건 · 핸드오프 N건 · 전달 N개 · 로그 N줄` 을 적으십시오
(없는 키는 `0` 으로. `records` 가 아예 없으면 그 줄을 그리지 마십시오 - 옛 서버와도 돌아야 합니다).

## 할 것 B - 끝난 것은 아래로 모아 접기 (요청 `Q-261111-731b` 3번)

`renderRequests` 와 `renderGraphs` 에서, **끝난 것**(요청은 `DONE`·`REJECTED`, 그래프는 위의 M 조건)은
지금처럼 하나씩 줄줄이 그리지 말고 **맨 아래 한 줄로 접으십시오**.

- 접힌 줄: `<button class="closed-fold fold-btn">끝난 것 N건 보기</button>`, 펼치면 `끝난 것 N건 숨기기`
- 펼친 상태는 `state.showClosedRequests` / `state.showClosedGraphs`(기본 `false`)에 두십시오.
  **`state` 에 두어야 5초 폴링이 다시 그려도 펼친 채로 남습니다** - 지역 변수에 두면 5초마다 접힙니다
- 펼치면 지금 그리던 그대로(`req-block` / 그래프 블록)를 그 아래에 그립니다
- 끝난 것이 0건이면 그 줄 자체를 그리지 마십시오
- 열린 것의 차례·모양은 바꾸지 마십시오

## 할 것 C - 진행 표시 현실화 (요청 `Q-261111-fa37`)

태석님 글 그대로: *"요청별 분담트리 PLANNED 에서 0초 0%만 보입니다. … DONE 에서 펼쳤을때 EST, 100% 표시
무의미. DONE에서 '100% 서브태스크없이 끝난 요청입니다.' 제거"*

**`reader.py` 는 고치지 마십시오.** 화면에서만 고칩니다 - 화면은 `req.subtasks` 를 이미 들고 있습니다.

1. `progressOf(req)` 를 **서브태스크가 없으면 `null`** 로 바꾸십시오.
   지금은 서버가 준 `progress_pct`(분담 전 `0.0`, 닫힌 요청 `100.0`)를 그대로 써서 **아무도 안 한 일이
   0%**, **아무 일도 아니었던 것이 100%** 로 보입니다. 서브태스크 배열이 비었으면 그 숫자를 쓰지 마십시오
2. **닫힌 요청(`DONE`·`REJECTED`)을 펼쳤을 때**는 진행 막대 줄(`.req-progress`)도
   ETA 근거 줄(`.req-basis`)도 **그리지 마십시오.** 대신 한 줄만:
   `<div class="req-done-line">끝남 · <갱신 시각>` (거절이면 `거절됨 · <갱신 시각>`).
   시각은 `fmtDateTime(req.updated || req.created)` 로 만듭니다
3. **열려 있고 서브태스크가 없는 요청**(`NEW`·`PLANNED`·`IN-PROGRESS`)도 막대·`%`·ETA 대신 한 줄:
   `<div class="req-wait-line">아직 분담 전 - 관리자가 서브태스크로 나누면 진행률과 ETA 가 나옵니다`
   (`IN-PROGRESS` 면 `관리자가 서브태스크 없이 직접 하는 일입니다`)
4. `subtaskEmptyText` 에서 **`DONE`·`REJECTED` 는 빈 문자열**을 돌려주고, 빈 문자열이면
   그 자리에 아무것도 그리지 마십시오 (접힌 줄에서도 마찬가지 - 지금은 `100% · 서브태스크 없이 끝난 요청입니다`
   가 보입니다. `%` 도 함께 사라져야 합니다)
5. 접힌 줄의 `fmtPct(pct)` 도 `pct === null` 이면 찍지 마십시오
