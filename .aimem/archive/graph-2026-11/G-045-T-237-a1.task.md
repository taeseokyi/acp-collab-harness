# T-237 엔진: 사용 한도로 끊긴 시도를 **한도 실패**로 구분하십시오

쓸 파일은 **넷**입니다:
`tools/fleet_graph.py` · `tools/fleet_ctl.py` · `tests/test_fleet_graph.py` · `tests/test_fleet_ctl.py`.
**다른 파일은 건드리지 마십시오** - 특히 `tools/aimem_monitor/**` 와 `tools/fleet.py` 는 다른 노드가
쓰고 있습니다.

## 왜

R16 라운드가 **Claude 5시간 사용 한도**에 걸려 관리자와 S1 이 보고 없이 끊겼습니다. 지금 엔진은 그것을
평범한 실패와 똑같이 보고 **재시도**해서, 한도를 더 씁니다. 한도로 끊긴 시도는 재시도하면 같은 벽에
부딪힙니다 - 사람이 봐야 하는 일입니다.

## 할 일 1 - `tools/fleet_graph.py`

1. 모듈 수준에 판정 함수를 하나 만듭니다:

```python
_LIMIT_PATTERNS = (
    "hit your 5-hour limit", "5-hour limit reached", "weekly limit",
    "usage limit reached", "rate limit", "사용 한도", "5시간 한도", "주간 한도",
)

def report_limit_hit(text):
    # 보고/출력이 사용 한도로 끊긴 것으로 보이면 True
```
   - `text` 의 **마지막 2000자만** 소문자로 보고 위 조각 중 하나라도 들어 있으면 `True`
   - `text` 가 비었거나 문자열이 아니면 `False`
   - 영문 조각은 소문자로 맞춰 비교하고, 한글 조각은 그대로 비교하십시오

2. 시도를 거두는 자리(`_verify` 를 부르는 790~815행 근처)에서, **`report_block_reason` 바로 다음**,
   `report_ended_in_tool_call` 보다 **먼저** 봅니다:
   - `att["report"]` 또는 그 시도의 표준오류(`fleet.run_stderr(att["run_id"])` 가 있으면 그것도,
     없으면 보고만)에 `report_limit_hit` 이 걸리면
   - `att["limit"] = True`, `att["verify_rc"], att["verify_tail"] = -4, "사용 한도로 끊겼다 - 재시도하지 않는다"`
   - `n["status"] = "blocked"` (**재시도하지 않습니다** - `_retry_or_fail` 을 부르지 않습니다)
   - `_log(g, f"limit {n['id']} ({att['run_id']}) - 사용 한도로 끊김")`
   - `fleet.run_stderr` 같은 함수가 `fleet.py` 에 없으면 **만들지 말고 보고만 보십시오.**
     `fleet.py` 는 이 노드가 쓸 수 있는 파일이 아닙니다

3. 그래프 JSON 의 노드에 `"limit": True` 가 남으므로 관리자가 `fleet_graph.py status` 에서 알아볼 수
   있게, `status` 출력의 그 노드 줄에 `(사용 한도)` 를 덧붙입니다

## 할 일 2 - `tools/fleet_ctl.py`

이어 달리기가 멈출 때의 까닭(**949~951행 근처**, `f"R{round_n} 보고가 {status or '없음'} 입니다"`)에,
그 라운드의 그래프 로그에 `limit ` 줄이 있으면 **`- 사용 한도로 끊긴 시도가 있습니다`** 를 덧붙입니다.
- 그 라운드의 그래프는 `.aimem/graph/G-*.json` 중 `round` 가 그 번호인 것입니다. 같은 폴더의
  `G-*.log` 에서 `limit ` 으로 시작하는 줄을 찾으면 됩니다
- 읽기에 실패하면 **조용히 덧붙이지 않습니다** (까닭 문자열은 그대로)
- 작은 도우미 함수 하나로 빼고 (`_round_hit_limit(round_n)`), 예외를 밖으로 내보내지 마십시오

## 할 일 3 - 시험

`tests/test_fleet_graph.py` 에 최소 5건, `tests/test_fleet_ctl.py` 에 최소 2건을 **더합니다**
(지금 셋을 합쳐 83건 → **90건 이상**):
- `report_limit_hit` 이 영문 두 꼴과 한글 한 꼴을 잡고, 평범한 보고에는 `False`
- 한도로 끊긴 시도가 **blocked 가 되고 시도가 2로 늘지 않는다** (`max_attempts: 2` 인 노드로)
- `att["limit"] is True` 가 그래프 JSON 에 남는다
- 한도 말이 **보고 한가운데**(마지막 2000자 밖)에만 있으면 잡지 않는다
- `_round_hit_limit` 이 로그에 `limit ` 줄이 있을 때만 True
- 까닭 문자열에 `사용 한도` 가 덧붙는다 / 없으면 안 덧붙는다
