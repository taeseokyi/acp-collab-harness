# T-135 **인증을 켠 채로** 미리보기가 뜨는지 브라우저로 잽니다

## 왜 필요한가

지금 있는 브라우저 검사 둘은 모두 **인증을 끈** 서버에 대고 돕니다. 그런데 운영 모니터는
인증을 켜고 돌고, **인증을 켜면 다른 길로 깨집니다** - 불투명 출처(sandbox)가 보내는 하위 요청에는
`SameSite=Strict` 세션 쿠키가 실리지 않아 CSS 까지 `302 /login` 으로 튕깁니다(S1 검수 실측).
앞 태스크(T-134)가 **경로 티켓**(`/app/~<티켓>/<이름>/…`)으로 그것을 고쳤습니다.
**이 검사는 그 고침이 진짜인지 인증을 켠 채로 재는 것입니다.**

## 쓸 파일 (이 하나뿐입니다)

`tests/browser_monitor_auth.py` (**새 파일**)

## 뼈대 - 이대로 쓰십시오

`tests/browser_monitor_app.py` 가 이미 있습니다. 그 파일의 `Checks` 와 `monitor_server()` 를
**그대로 복사해 오되**, 서버를 띄우는 곳만 인증을 켜십시오:

```python
TOKEN = "a" * 64                      # 접근 토큰 (64자 16진수 꼴이어야 합니다)

handler = type("H", (server.Handler,), {"root": ROOT, "require_auth": True, "tls": False,
                                        "access_token": TOKEN, "guard": server.LoginGuard(),
                                        "timeout": 5, "log_message": lambda *a, **k: None})
```

(`import` 는 `browser_monitor_app.py` 와 같습니다. 그 파일을 `import` 하지 말고 **복사**하십시오 -
남의 소유 파일이라 고칠 수 없고, 서로 묶이면 둘 다 못 고칩니다.)

로그인은 **브라우저 컨텍스트의 요청**으로 합니다. 그래야 쿠키가 그 컨텍스트에 남습니다:

```python
ctx = browser.new_context(viewport={"width": 1280, "height": 900})
r = ctx.request.post(base + "/api/login", data={"token": TOKEN},
                     headers={"Content-Type": "application/json"})
```

## 잴 것 (6개)

1. **로그인 전에는 막힌다** - 새 컨텍스트에서 `ctx2.request.get(base + "/app/웹워들/")` 이
   200 으로 **게임 HTML 을 주지 않는다** (302/401 이거나 로그인 화면). 본문에 `id="board"` 가 없음
2. **로그인이 된다** - 위 `ctx.request.post` 가 200 이고, 이어서 `page.goto(base + "/")` 가
   `#projects-list .proj-item` 을 보여 준다
3. **'실행' 을 누르면 미리보기가 보인다** - `.proj-run` 을 눌러 `iframe.proj-app-frame` 이
   `is_visible()` 이고 `bounding_box()` 의 `height` 가 300 이상
4. **안쪽이 진짜로 그려졌다 (이 파일의 핵심)** -
   `page.frame_locator("iframe.proj-app-frame")` 안에서 `#board .tile` 이 **30개**이고
   첫 칸이 `is_visible()`. (지금까지 **여기가 빨갰습니다** - 모듈 스크립트가 CORS 로 막혀서)
5. **CSS 도 실제로 입혀졌다** - 그 첫 칸의 `getComputedStyle(el).borderWidth` 가 `"0px"` 가 아니다
   (스타일시트가 못 왔으면 테두리가 없습니다). 실제 값을 `detail` 에 적으십시오
6. **그래도 격리는 살아 있다** - iframe 문서 안에서
   `page.frame_locator(...)` 말고 **프레임 객체**(`page.frame(url=...)` 또는
   `page.frames` 에서 골라)로 `frame.evaluate("window.origin")` 이 `"null"` 이다

마지막 줄은 반드시 `통과 N / 전체 M` 입니다. 예외가 나도 요약 줄은 찍고 끝내십시오
(`except` 에서 `checks.ok("검사 실행", False, ...)` 하고 `checks.finish()`).
