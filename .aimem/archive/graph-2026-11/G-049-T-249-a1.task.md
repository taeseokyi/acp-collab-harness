# T-249 `server.py`: 짝 없는 서러게이트 한 글자가 `/api/state` 를 죽이는 것 (재검수 P1, 높음)

쓸 파일은 **하나**입니다: `tools/aimem_monitor/server.py`. **`tests/**` 와 다른 `tools/**` 는 읽기만
하고 절대 고치지 마십시오.** 계획을 세우지 말고 바로 고치십시오.

## 무엇이

`.aimem/claude-usage.json` 이 `{"at": "\ud800", "rate_limits": {"five_hour": {"used_percentage": 40}}}`
(71 바이트, JSON 이스케이프 그대로) 이면 `claude_usage()` 는 **정상으로** `at='\ud800'` 을 돌려줍니다.
그 글자가 `/api/state` 응답에 그대로 실려 `_send()` 의 `body.encode("utf-8")`(`:2489` 근처)에서
**`UnicodeEncodeError: surrogates not allowed`** 가 터지고, 연결이 **응답 없이** 끊깁니다(실측
`RemoteDisconnected`). 정상 갈래·실패 갈래(`_empty_state`) **둘 다** 죽습니다 - 바깥 `try` 는
직렬화 단계를 감싸지 못합니다.

## 고칠 것 둘 (둘 다 하십시오)

1. **`_send()`** (`:2487` 근처): `body = body.encode("utf-8")` 를 **`body.encode("utf-8", "replace")`**
   로. 이러면 상태 어디에 그런 글자가 들어와도(파일 이름, 요청 제목 등) 응답이 죽지 않습니다.
   주석 한 줄로 까닭을 적으십시오 (재검수 P1)
2. **`claude_utils` 쪽 근원도**: `claude_usage()` 가 `at` 을 담기 전에
   **내보낼 수 없는 글자면 `None` 으로** 떨어뜨리십시오. 예:
   ```python
   if isinstance(at, str):
       try:
           at.encode("utf-8")
       except UnicodeEncodeError:
           at = None
   ```
   (`at` 이 `str` 이 아닐 때 `None` 으로 두는 지금 동작은 그대로.)

`rows`·`age_seconds` 계산과 돌려주는 모양(`{at, age_seconds, rows}`)은 **바꾸지 마십시오.**

## 검증

검증 명령이 봅니다: 시험 묶음 넷이 초록이고, 서러게이트 `at` 파일을 둔 임시 저장소로 띄운
임시 포트 서버의 `/api/state` 가 **정상 갈래·`reader.collect` 예외 갈래 둘 다 200** 이며
본문이 JSON 으로 읽히는 것.
