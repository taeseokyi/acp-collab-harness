**공유 문구 형식** (`shareText()`):

```
웹워들 123 4/6

⬛🟨⬛⬛⬛
🟩⬛⬛🟨⬛
🟩🟩⬛⬛🟩
🟩🟩🟩🟩🟩
```

- 첫 줄 `웹워들 <puzzleNumber> <맞힌 횟수 또는 X>/<maxGuesses>`, 하드 모드면 끝에 `*`
- 둘째 줄은 빈 줄, 그 뒤에 줄마다 이모지 다섯 개
- correct `🟩` / present `🟨` / absent `⬛`

**겹치는 글자 판정** - 반드시 이 순서로 (워들의 핵심이고 틀리기 쉬운 곳입니다):

1. 먼저 자리가 같은 글자를 `correct` 로 하고, **정답에서 그 글자를 하나 뺍니다**
2. 그다음 남은 칸을 왼쪽부터 보며, 남은 정답 글자 중에 있으면 `present` 로 하고 **하나 뺍니다**.
   없으면 `absent`

| 정답 | 추측 | 결과 |
| ---- | ---- | ---- |
| crane | nanny | absent present absent correct absent |
| abbey | bebop | present present correct absent absent |
| abide | eerie | absent absent absent present correct |
| sassy | stars | correct absent present absent present |
| crane | crane | correct correct correct correct correct |

## 품질 기준

- 입력을 믿지 마십시오: `scoreGuess` 는 길이가 다르거나 대문자가 섞여 들어와도 터지지 않게 하십시오
  (소문자로 맞추고, 길이가 다르면 예외를 던지는 쪽이 낫습니다 - 어느 쪽이든 주석으로 밝히십시오)
- `rows` 를 밖에서 고쳐도 판이 깨지지 않도록 돌려줄 때 복사하십시오
- 주석은 한국어로, 왜 그렇게 했는지만. 300줄을 넘기지 마십시오
