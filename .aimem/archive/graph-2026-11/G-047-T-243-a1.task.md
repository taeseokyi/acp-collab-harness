# T-243 `tests/test_fleet_graph.py` 에 '한도 오인' 회귀 시험을 넣으십시오

쓸 파일은 **하나**입니다: `tests/test_fleet_graph.py`. **`tools/**` 는 읽기만 하고 절대 고치지
마십시오.** 계획을 세우지 말고 바로 고치십시오.

## 제품이 바뀌었습니다 (앞 노드 T-242, 의도된 변경)

`tools/fleet_graph.py` 의 한도 판정이 둘 바뀌었습니다.

1. `report_limit_hit` 의 걸림말이 **'한도에 부딪혔다'는 꼴**로 좁아졌습니다. 맨낱말
   `"사용 한도"`·`"rate limit"`·`"주간 한도"` 만으로는 더 이상 참이 아닙니다. 실제로 멀쩡한
   보고(일 자체가 '사용 한도 표시' 였던 작업자의 `DONE` 보고)가 한도로 오인돼 노드가 막혔습니다
2. `step()` 은 보고가 한도처럼 보여도 **노드에 `verify` 명령이 있고 `rc == 0`이면 먼저 검증을
   돌립니다.** 검증이 통과하면 한도로 보지 않고 `done` 으로 갑니다. 검증이 실패하면 예전처럼
   `limit`·`verify_rc=-4`·`blocked` 입니다. `verify` 가 없는 노드는 예전 그대로입니다

## 할 일

### (1) 이미 있는 시험 하나 고치기

`test_step_limit_flag_remains_in_saved_graph_json` 의 보고 본문
`"상태: DONE\n사용 한도"` 를 **진짜 한도 문구**로 바꾸십시오 (예: `"상태: DONE\n사용 한도에 도달했습니다"`).
단언(저장된 json 에 `limit: true`)은 그대로 둡니다.

### (2) 계약표에 거짓 양성 줄 더하기

`test_report_limit_hit_contract_table` 의 `cases` 에 **False** 로 셋을 더하십시오:
- `"DONE\n- 함대 탭에 Claude 사용 한도 카드를 넣었습니다"`
- `"DONE\n- rate limit 글자를 설명에 적었습니다"`
- `"상태: DONE\n- 주간 한도 표시를 style.css 에 넣었습니다"`
이미 있는 True 다섯 줄은 **손대지 마십시오**.

### (3) `step()` 의 새 갈래 시험 둘 (새로 쓰기)

고정 노드 만들개(`self._node(...)`)에 `verify="true"` 처럼 `verify` 키를 넘길 수 있습니다
(`**extra` 로 들어갑니다). `fleet_graph._verify` 를 `mock.patch.object` 로 바꿔 쓰십시오.

- **검증이 통과하면 한도로 보지 않는다**: `verify` 가 있는 노드 + 보고가
  `"상태: DONE\n5-hour limit reached"` + `_verify` 가 `(0, "ok")` →
  노드 `status == "done"`, `attempt.get("limit")` 이 참이 아님, `attempt["verify_rc"] == 0`
- **검증이 실패하면 예전처럼 한도로 막는다**: 같은 상황인데 `_verify` 가 `(1, "빨강")` →
  `status == "blocked"`, `attempt["limit"] is True`, `attempt["verify_rc"] == -4`,
  `attempt["verify_tail"]` 에 `"사용 한도"` 가 들어 있음

이미 있는 `test_step_limit_hit_blocks_without_retry`(`verify` 없는 노드 - `_verify` 를 부르지 않음)는
**그대로 두십시오**. 시험을 지우지 마십시오 - 지금 45건이고 **48건 이상**이어야 합니다.
