# T-128 `/app/` 실행 경로가 **진짜로 그려지는지** 재는 브라우저 스크립트

## 무엇을 하는 일인가

T-126(뒷단)·T-127(화면)이 한 일을 **브라우저로 실측**하는 검사를 만듭니다.
속성이 아니라 **실제로 그려진 것**을 봅니다(`is_visible()`·`bounding_box()`·`getComputedStyle`).

## 쓸 파일 (이 하나뿐입니다)

`tests/browser_monitor_app.py` (**새 파일**)

## 틀

`projects/웹워들/tests/browser_harness.py` 의 `Checks` 클래스와 `browser_core.py` 의 `main()` 짜임새를
**그대로 본떠** 쓰십시오(그 파일들은 **고치지 말고 읽기만**). 마지막 줄이 반드시

```
통과 N / 전체 M
```

이어야 하고, 실패 수를 `return` 합니다. 중간에 예외가 나도 **그때까지의 요약 줄은 찍고** 끝내십시오
(마지막 줄들에 원인이 보여야 재시도 때 고칠 수 있습니다).

## 서버 띄우기

`playwright` 는 설치돼 있습니다(`from playwright.sync_api import sync_playwright`).
모니터는 **인증을 끈 평문 http** 로 임시 포트에 직접 띄우십시오 - `tests/test_aimem_monitor_access.py`
의 `setUpClass` 를 본뜨되 TLS 는 빼십시오:

```python
handler = type("H", (server.Handler,), {"root": ROOT, "require_auth": False, "tls": False,
                                        "access_token": None, "guard": server.LoginGuard(),
                                        "timeout": 5, "log_message": lambda *a, **k: None})
httpd = http.server.ThreadingHTTPServer(("127.0.0.1", 0), handler)
```

`ROOT` 는 **진짜 저장소 루트**입니다(`projects/웹워들/` 이 있어야 합니다). 끝날 때 `shutdown()` ·
`server_close()` 로 꼭 내리십시오. `monitorctl.sh` 나 운영 서버(18799)는 **건드리지 마십시오** -
인증이 걸려 있어 401 입니다.

## 재야 할 것 (14개 이상)

### A. 결과물을 바로 연 화면 - `http://127.0.0.1:<port>/app/웹워들/`

1. 응답이 200 이고 보드 `#board .tile` 이 **30칸** 그려진다 (`page.wait_for_selector`)
2. 보드가 **눈에 보인다**: `is_visible()` 참이고 `bounding_box()` 의 너비·높이가 둘 다 0보다 크다
3. 화면 키보드가 보이고, 보드와 **겹치지 않는다** (두 `bounding_box()` 가 교차하지 않음)
4. 아무 요소도 **뷰포트 밖으로 나가지 않는다**: `document.documentElement.scrollWidth <= innerWidth + 1`
5. 글자 다섯 자(예: `crane`)를 치면 첫 줄 다섯 칸에 글자가 보인다
6. `Enter` 를 치면 첫 줄 칸의 **계산된 배경색**(`getComputedStyle(...).backgroundColor`)이
   입력 전과 달라진다 (판정색이 실제로 칠해짐)
7. `pageerror` · `console.error` 가 **한 건도 없다** (하네스처럼 모아서 재십시오)
8. CSP 헤더가 실제로 내려온다: `response.header_value("content-security-policy")` 에
   `frame-ancestors 'self'` 가 있고 `'none'` 이 없다
9. `/app/웹워들` (끝 슬래시 없이) 이 **302** 로 `/app/웹워들/` 로 보낸다
10. `/app/웹워들/../../AIMEM.md` 류 경로가 200 으로 저장소 파일을 주지 않는다 (404/400)

### B. 모니터 안에서 '실행' 누르기 - `http://127.0.0.1:<port>/`

11. 프로젝트 칸에 `실행` 단추가 **보인다** (`is_visible()`)
12. 누르면 패널이 열리고 `iframe.proj-app-frame` 이 **보이고** `bounding_box()` 높이가 **300px 이상**이다
13. 그 iframe 의 `sandbox` 속성에 `allow-scripts` 가 있고 **`allow-same-origin` 이 없다**
    (이것이 격리의 전부입니다 - 반드시 재십시오)
14. iframe **안쪽**이 실제로 그려졌다: `page.frame_locator('iframe.proj-app-frame')` 로 들어가
    `#board .tile` 이 30칸이고 첫 칸이 `is_visible()`
15. iframe 이 패널 밖으로 **잘리지 않는다**: iframe 의 `bounding_box()` 가 패널 본문의 상자 안에 들어간다
16. `새 탭에서 열기` 링크가 보이고 `href` 가 `/app/웹워들/`, `rel` 에 `noopener` 가 있다

`shot()` 같은 그림 저장은 **하지 마십시오**(남의 소유 폴더입니다). 실패했을 때 무엇이 틀렸는지는
`detail` 문자열에 숫자로 적으십시오 (예: `box=(x,y,w,h) 패널=(...)`).

## 제품에 결함이 보이면

**제품도 검사도 고치지 마십시오.** 보고 **첫 줄**을 다음 꼴로 쓰십시오:

```
NEEDS-FIX: <무엇이> <어디서>
```

예: `NEEDS-FIX: iframe 이 sandbox 없이 붙는다 - app.js openProjectApp`.
엔진이 재시도 없이 바로 막아 두고, 관리자가 고치는 노드를 붙입니다. 이 검사가 빨간 것은 당신 책임이 아닙니다.
