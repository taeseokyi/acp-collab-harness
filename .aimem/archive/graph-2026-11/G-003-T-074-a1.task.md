## 할 일 (작은 수정 하나입니다)
`tools/aimem_monitor/static/app.js` 의 **슬롯 표에서 `확인토큰` 열을 없애십시오.** 서버가 곧 `/api/state` 에서 `slots[].token` 을 빼기 때문에 그대로 두면 빈 칸만 남습니다.

## 현물
526~551행 근처 `renderSlots()`:
```js
    return [
      mono(s.slot),
      show(s.harness),
      modelCell,
      show(s.role),
      mono(s.token),      // <- 이 줄을 지웁니다
      show(s.note),
    ];
  });
  wrap.appendChild(newTable(['슬롯', '하네스', '모델', '역할', '확인토큰', '비고'], rows, null, {
    widths: ['60px', '90px', '240px', '180px', '90px', '260px'],
    ellipsis: [2, 3, 5],
  }));
```

## 기대 동작
1. `mono(s.token)` 행을 지우고, 머리글 배열에서 `'확인토큰'` 을 지우고, `widths` 에서 그 자리의 `'90px'` 을 지우십시오.
2. **`ellipsis` 의 인덱스를 다시 세십시오.** 열이 6개에서 5개로 줄어 뒤 열의 번호가 하나씩 당겨집니다 - 지금 `[2, 3, 5]` 는 (모델, 역할, 비고) 를 가리키므로 새 번호는 **`[2, 3, 4]`** 입니다.
3. 파일 위쪽 `DEMO` 더미 데이터(38~41행)에도 `token:` 필드가 있습니다. **그 줄들의 `token:` 키만 지우십시오** - 더미는 화면 확인용이고 실제 토큰 값이 소스에 박혀 있는 것 자체가 유출면입니다.
4. 그 밖에는 아무것도 바꾸지 마십시오. `kisti.url` 이나 `data.root` 는 `app.js` 가 이미 쓰지 않습니다 - **쓰는지 확인만 하고 보고에 한 줄 적으십시오** (`grep -n "\.root\|kisti.url" tools/aimem_monitor/static/app.js`).

## 하지 말 것
- `index.html` / `style.css` 는 이번에 건드리지 마십시오
- 표 틀(`newTable`)이나 다른 렌더 함수를 고치지 마십시오
