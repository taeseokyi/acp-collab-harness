## 빨강 1 - `test_serve_restores_sigterm_handler`

```
AssertionError: False is not true : health 200 이 되지 않았습니다. stderr=
```

**까닭 (관리자가 재현해 확인했습니다):** 이 시험은 자식에서 `serve(..., once=True)` 를 부르고
부모가 `/api/health` 가 200 이 될 때까지 폴링합니다. 그런데 `once=True` 는
`httpd.handle_request()` 를 **한 번만** 부르고, `ThreadingHTTPServer` 의 `handle_request` 는
연결을 **받아 스레드에 넘기고 바로 돌아옵니다**. 그래서 `serve()` 가 끝나고
`httpd.server_close()` 가 소켓을 닫아 버려 **응답이 영영 안 옵니다** - 20초를 꽉 채우고 빨강입니다.
`health` 200 을 기다리는 방식으로는 이 시험을 세울 수 없습니다.

**고칠 방향 (이렇게 하십시오):**

- `_wait_health` 를 이 시험에서 **쓰지 마십시오.**
- 자식이 `serve()` 를 부르기 **전에** `BEFORE\t<repr(signal.getsignal(SIGTERM))>` 을 찍고
  `flush=True` 하는 것은 지금 그대로 둡니다
- 부모는 자식 stdout 에서 **`BEFORE` 줄을 읽어** 서버가 곧 뜬다는 것만 확인하고,
  그 뒤 `/api/health` 에 **한 번만** 요청을 보냅니다. **응답이 오든 끊기든 상관없습니다** -
  `try: urllib.request.urlopen(...) except Exception: pass` 로 감싸고, 그 한 번의 연결이
  `handle_request()` 를 풀어 주는 **방아쇠**일 뿐입니다
  - 연결이 바로 거부되면(아직 bind 전) 몇 번 더 시도하십시오 - 다만 **200 을 요구하지는 마십시오**.
    `ConnectionRefusedError` 가 아닌 어떤 결과든(`200`·`RemoteDisconnected`·타임아웃) 방아쇠는
    당겨진 것입니다
- 그다음 `proc.communicate(timeout=20)` 으로 자식이 **스스로 끝나기를** 기다리고,
  stdout 에서 **`AFTER` 줄**을 찾아 단언합니다:
  - `AFTER` 줄이 **있어야** 합니다 (= `serve()` 가 정상으로 돌아왔다)
  - `AFTER` 줄에 `SIG_DFL` 이 들어 있어야 합니다 (처리기가 되돌려졌다)
  - `AFTER` 줄에 `_sigterm_interrupt` 가 **없어야** 합니다
  - 참고로 `BEFORE` 줄과 비교해 같은 값인지도 보십시오
- 실패 메시지(`msg=`)에 **자식의 stdout 과 stderr 전문**을 넣으십시오

## 빨강 2 - `test_sigterm_handler_is_installed_right_before_the_serve_loop`

```
AssertionError: 2 != 1 : SIGTERM 설치 줄이 정확히 하나가 아닙니다: [42, 53]
```

**까닭:** `signal.signal(signal.SIGTERM` 이 `serve()` 안에 **두 번** 나옵니다 -
42번째 줄은 **설치**(`signal.signal(signal.SIGTERM, _sigterm_interrupt)`),
53번째 줄은 `finally` 안의 **되돌리기**(`signal.signal(signal.SIGTERM, old_sigterm)`) 입니다.
시험이 둘을 구별하지 않습니다.

**고칠 방향:** 설치 줄만 고르십시오 - 줄에 `signal.signal(signal.SIGTERM` **과**
`_sigterm_interrupt` **가 함께 있는 줄**이 설치 줄입니다. 그 줄이 **정확히 하나**여야 하고,

- 서버 루프 줄(`handle_request()` 또는 `serve_forever()`)보다 **앞**
- 서버 루프보다 앞에 있는 `log_line(` 들 **모두보다 뒤**
  (**주의:** `except KeyboardInterrupt:` 안의 `log_line("\n내립니다.")` 는 루프보다 **뒤**이니
  세면 안 됩니다. `log_line` 을 셀 때 **서버 루프 줄보다 앞의 것만** 세십시오 -
  앞 작업자가 여기서 걸렸습니다)
- 설치 줄과 서버 루프 사이에 `log_line(` 이 **하나도 없어야** 합니다
