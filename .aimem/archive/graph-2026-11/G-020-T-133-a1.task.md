## 반드시 깨뜨려 볼 것

### 1. 저장소가 새는가 (가장 중요)

`/app/<이름>/<경로>` 로 **앱 폴더 밖 파일**을 받아낼 길이 하나라도 있는지 **직접 돌려** 보십시오.
임시 저장소에 함수를 직접 불러도 되고, 인증 끈 서버를 임시 포트에 띄워 `urllib` 로 때려도 됩니다
(띄우는 법은 `tests/browser_monitor_app.py` 의 `monitor_server()` 에 있습니다).

- `..%2f..%2fAIMEM.md`, 이중 인코딩(`..%252f..`), `%2e%2e/`, `....//`, 백슬래시, 널바이트
- 절대 경로(`/etc/passwd`), `//etc/passwd`
- `app.json` 의 `root` 를 `"../.."` · 절대 경로 · 저장소 밖 심볼릭 링크로 바꿔 두고 다시
- 앱 폴더 **안에 심볼릭 링크**를 만들어 `.aimem/tls/access-token` 을 가리키게 하고 받아지는지
- 프로젝트 이름 자리에 `..`, `%2e%2e`, 아주 긴 이름
- `PROJECT_APP_FILE_MAX_BYTES` 를 넘는 파일이 **잘려서** 나가지는 않는가

### 2. 인증

- 로그인 없이 `/app/웹워들/`, `/app/웹워들/js/words.js` 가 **내용을 주는가** (주면 중대 결함)
- `/app/` 이 `AUTH_EXEMPT_PATHS` 에 들어가지 않았는가. 인증 없을 때 `/login` 으로 보내는가

### 3. 격리가 말뿐이 아닌가

- `app.js` 가 만드는 iframe 에 `allow-same-origin` 이 **정말 없는가**. 있으면 결과물 코드가
  인증된 세션 쿠키로 `/api/requests` 를 POST 할 수 있습니다
- `/app/` 응답에 **CSP 헤더가 둘** 내려가지는 않는가. 둘이면 브라우저가 교집합을 적용해
  기본 헤더의 `frame-ancestors 'none'` 이 살아나고 iframe 이 통째로 안 보입니다. **실제 응답 헤더를 뜯어보십시오**
- `app_csp()` 가 `Host` 헤더를 그대로 믿는가. `Host: evil.com` 으로 요청을 보내 CSP 에 그 말이
  들어가는지 보고, 들어간다면 그것으로 **무엇을 할 수 있는지** 판단해 적으십시오 (못 하면 못 한다고 적으십시오)
- 새 탭(`새 탭에서 열기`)은 **같은 출처**입니다 - 그 길로 무엇이 가능한지도 한 줄 적으십시오

### 4. 검사가 진짜 빨개지는가 (거짓 초록 사냥) - **결과와 무관하게 반드시 하십시오**

**R9 의 교훈:** 속성만 보는 검사 31개가 초록인 채 화면 결함 다섯이 숨어 있었습니다.
일부러 제품을 깨 보고, 해당 검사가 **정말 빨개지는지** 확인한 뒤 **반드시 되돌리십시오.**

- `style.css` 의 `.proj-app-frame` 높이를 `0` 으로 → `browser_monitor_ui.py` 2번이 빨개지는가
- `app.js` 의 `fr.setAttribute('sandbox', ...)` 줄을 지우면 → 3번이 빨개지는가
- `app.js` 의 `fr.src` 를 `'about:blank'` 로 → 4번(안쪽 보드)이 빨개지는가
- `server.py` 의 `app_csp()` 에서 `frame-ancestors 'self'` 를 `'none'` 으로 →
  `browser_monitor_app.py` 7번이 빨개지는가

되돌린 것은 `git diff --stat` 으로 확인하고 그 출력을 보고에 적으십시오.
