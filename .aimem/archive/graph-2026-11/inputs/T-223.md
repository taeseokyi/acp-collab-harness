# T-223 새 브라우저 검사: 프로젝트 탭 · 전역 정리 단추 · 프로젝트 고르기

**새 파일 하나**를 만드십시오: `tests/browser_monitor_tabs.py`.
제품 코드(`tools/aimem_monitor/**`)와 다른 시험 파일은 **읽기만 하고 절대 고치지 마십시오**.

## 배경 - 이번 라운드에 바뀐 세 가지

1. **프로젝트가 별도 탭이 됐습니다.** 탭이 넷입니다: `함대`(`#tab-fleet`) · `프로젝트`(`#tab-projects`) ·
   `보드·큐`(`#tab-board`) · `요청 트리`(`#tab-requests`). 프로젝트 카드(`#projects-section`)는
   **함대 탭에서 빠져 `#panel-projects` 안으로** 옮겨졌습니다. 탭 단추에는 아직 안 끝난 프로젝트 수가
   `#tab-count-projects` 로 붙습니다
2. **`끝난 것 정리…` 단추가 상단 전역 바로 갔습니다.** `<header class="topbar">` 안의 `#archive-open`
   하나뿐이고, 보드 필터줄과 `#requests-tools` 에는 **없습니다**
3. **작업 요청 폼의 프로젝트 칸**이 `<select id="req-project-pick">` + `<input id="req-project" hidden>`
   한 쌍이 됐습니다. 고르는 칸에는 `(함대 자체의 일…)`(`value=''`), 있는 프로젝트 이름들,
   `+ 새 프로젝트…`(`value='__new__'`) 가 들어 있고, `__new__` 를 고르면 새 이름 입력칸이 보입니다

## 읽을 곳 (이것만)

- `tests/browser_monitor_ui.py` 의 **맨 위 60줄** - `Checks` 클래스와 `monitor_server` 컨텍스트 매니저,
  그리고 `main()` 의 모양. **그 본을 그대로 베껴 쓰십시오** (같은 `Checks`, 같은 `monitor_server`,
  마지막에 `통과 N / 전체 M` 을 찍고 실패 수를 종료 코드로 돌려주는 꼴)
- `tools/aimem_monitor/static/index.html` - **읽기만**
- `tools/aimem_monitor/static/app.js` 의 `TABS` / `selectTab` / `renderProjectPicker` - **읽기만**

AIMEM.md 는 읽지 마십시오. `browser_monitor_ui.py` 를 **고치지는** 마십시오(읽기만).

## 만들 검사 (열 개, 두 시나리오)

### 시나리오 A `tabs_scenario` - 데스크톱 `{"width": 1280, "height": 900}`

1. **탭이 넷이고 차례가 맞다** - `.tabs [role=tab]` 네 개가 모두 `is_visible()` 이고, 글자 차례가
   `함대 · 프로젝트 · 보드·큐 · 요청 트리` 다
2. **처음에는 프로젝트 카드가 함대 탭에 안 보인다** - 첫 화면(`함대` 탭)에서 `#projects-section` 이
   `is_visible()` 가 **아니다**
3. **프로젝트 탭을 누르면 보인다** - `#tab-projects` 클릭 뒤 `#projects-section` 이 `is_visible()` 이고
   `#projects-list .proj-item` 이 **하나 이상** 보인다. 그때 `#panel-fleet` 은 안 보인다
4. **보이는 패널은 늘 정확히 하나다** - 네 탭을 차례로 눌러 가며, 매번 `[role=tabpanel]` 중
   `is_visible()` 인 것이 **정확히 1개**다
5. **주소로 바로 열린다** - `?…#tab=projects` 로 다시 `goto` 하면 프로젝트 탭이 열려 있다
   (`#tab-projects` 의 `aria-selected == 'true'`)
6. **전역 정리 단추가 어느 탭에서나 보인다** - 네 탭 모두에서 `#archive-open` 이 `is_visible()` 이다.
   그리고 `#board-filter` 안에 `끝난 것 정리` 글자를 가진 단추가 **0개**다
7. **누르면 정리 패널이 열린다** - `#archive-open` 클릭 뒤 `#detail-overlay` 의 `h2` 가 보이고 그 글에
   `정리` 가 들어 있다. `#detail-close` 로 닫으면 다시 숨는다

### 시나리오 B `project_picker_scenario` - 폰 `{"width": 390, "height": 844}`

8. **고를 거리가 보인다** - `#req-project-pick` 이 `is_visible()` 이고 `<option>` 이 **3개 이상**
   (빈 값 + 프로젝트 하나 이상 + `__new__`). 있는 프로젝트 이름 중 적어도 하나가 option 값에 있다
   (`#projects-list .proj-item` 에서 읽은 이름과 맞춰 보십시오)
9. **`+ 새 프로젝트…` 를 고르면 입력칸이 나타난다** - `select_option('__new__')` 뒤 `#req-project` 가
   `is_visible()` 이고, 다시 빈 값으로 되돌리면 안 보인다
10. **글자를 넣어도 칸이 화면 밖으로 안 나간다** - `__new__` 를 고르고 `#req-project` 에
    `아주-긴-프로젝트-이름-테스트-12345` 를 친 뒤, `#req-project` 와 `#req-project-pick` 의
    `bounding_box()` 가 둘 다 `x >= -1` 이고 `x + width <= 390 + 1` 이며, **서로 겹치지 않는다**
    (한쪽의 아래가 다른 쪽의 위보다 작거나 같다)

## 지킬 것

- 서버는 `monitor_server()` 로 **임시 포트에 인증을 끄고** 띄웁니다. 운영 모니터(HTTPS)는 **절대 부르지
  마십시오** - 401 이 납니다
- 화면 검사는 **실제로 그려진 것**을 물어야 합니다: 보임/숨김은 `is_visible()`, 자리·겹침·잘림은
  `bounding_box()`. 속성만 보고 통과시키지 마십시오
- 요청을 **실제로 보내지 마십시오** (`요청 보내기` 를 누르지 마십시오). 고르는 동작까지만 잽니다
- 제품이 틀려서 못 통과하면 제품도 검사도 고치지 말고, 보고 첫 줄을 `NEEDS-FIX: <무엇이 어디서>` 로
  쓰고 멈추십시오
- 파일은 `python3 tests/browser_monitor_tabs.py` 로 바로 돌아가야 하고, 실패 수를 **종료 코드**로
  돌려줘야 합니다 (`sys.exit(checks.finish())`)
