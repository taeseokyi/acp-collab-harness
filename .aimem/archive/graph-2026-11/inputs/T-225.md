# T-225 '끝난 것 정리' 를 **상단 전역 바**로 옮기십시오 (태석님 요청 Q-261112-edfe)

태석님 요청 전문: "보드 큐와 요청트리에 있는 끝난것 정리 상단 글러벌 바 에 위치"
→ 지금 **두 군데**에 흩어져 있는 '끝난 것 정리…' 단추를 **맨 위 전역 바에 하나만** 두라는 뜻입니다.

고칠 파일은 셋뿐입니다.

- `tools/aimem_monitor/static/index.html`
- `tools/aimem_monitor/static/app.js`
- `tools/aimem_monitor/static/style.css`
- (`tools/aimem_monitor/static/sw.js` 의 버전 한 줄)

**서버(`tools/aimem_monitor/server.py`)와 시험(`tests/**`)은 절대 고치지 마십시오.**

## 읽을 곳 (이것만)

- `tools/aimem_monitor/static/index.html` 의 `<header class="topbar">` 블록 (맨 위 20줄쯤)
- `tools/aimem_monitor/static/app.js` 의
  - `openArchivePanel` (2249행 근처) 과 `linkButton`
  - `renderBoard` 안에서 `filterBox` 에 `끝난 것 정리…` 를 붙이는 자리 (2349행 근처)
  - `renderRequests` 안에서 `#requests-tools` 에 붙이는 자리 (2743~2757행 근처)
  - `init()` / `refresh()` 가 단추를 거는 방식 (`refresh-now`, `theme-toggle` 처럼 `index.html` 에 이미
    있는 단추에 `addEventListener` 를 거는 자리)
- `tools/aimem_monitor/static/style.css` 의 `.topbar`, `.controls` 규칙

AIMEM.md 는 읽지 마십시오.

## 지금 모습

`끝난 것 정리…` 단추가 **두 군데**에 있습니다.

1. `보드·큐` 탭 - `renderBoard` 가 `#board-filter` 안에 `linkButton('끝난 것 정리…', openArchivePanel)` 을 붙임
2. `요청 트리` 탭 - `renderRequests` 가 `#requests-tools` 안에 붙임. 그 옆에 `끝난 요청 N건 · 끝난 그래프 M개`
   라는 글도 같이 그림

둘 다 같은 `openArchivePanel()` 을 엽니다.

## 할 일

### 1) `index.html` - 전역 바에 단추 하나

`<header class="topbar">` 의 `<div class="controls">` 안, **`지금 갱신` 단추와 `어두운 모드` 단추 사이**에
넣습니다.

```html
<button type="button" id="archive-open" title="끝난 태스크·닫힌 요청·끝난 그래프를 한꺼번에 아카이브로 옮깁니다 (지우지 않음)">끝난 것 정리… <span id="archive-count" class="tab-count"></span></button>
```

### 2) `app.js`

- **보드 탭에서 지웁니다.** `renderBoard` 의 `const arch = linkButton('끝난 것 정리…', openArchivePanel);` 과
  `arch.title = …`, `filterBox.appendChild(arch);` 세 줄을 지우십시오. 필터 칩은 그대로 둡니다.
- **요청 트리에서 단추만 지웁니다.** `renderRequests` 의 `tools.appendChild(linkButton('끝난 것 정리…', openArchivePanel));`
  한 줄을 지우십시오. **`끝난 요청 N건 · 끝난 그래프 M개` 라는 글(`label`)은 그대로 둡니다** - 그 탭에서
  무엇이 쌓였는지는 계속 보여야 합니다.
- **전역 단추에 겁니다.** 다른 상단 단추들(`refresh-now`, `theme-toggle`)을 거는 자리 옆에 한 줄을 더합니다.

  ```js
  const archBtn = $('archive-open');
  if (archBtn) archBtn.addEventListener('click', openArchivePanel);
  ```

- **숫자를 채웁니다.** `renderTabCounts(data)` 안(또는 그 바로 뒤에 부르는 곳)에서 `#archive-count` 에
  **정리할 수 있는 것의 수**를 넣습니다. `renderRequests` 가 이미 쓰는 식을 그대로 가져다 쓰십시오:
  `requests.filter((r) => REQ_CLOSED.has(String(r.status || '').toUpperCase())).length`
  더하기 `(data.graphs || []).filter(graphArchivable).length`.
  0 이면 빈 문자열로 두고(`setTabCount` 가 그렇게 합니다), 전역 단추의 `title` 에
  `끝난 요청 N건 · 끝난 그래프 M개` 를 적어 주십시오.

### 3) `style.css`

- 상단 바에 단추가 하나 늘어 **폰 폭(390px)에서 상단 바의 요소들이 겹치거나 화면 밖으로 나가지 않도록**
  `.topbar` / `.controls` 규칙을 손보십시오(줄바꿈 허용, 좁은 폭에서 글자·여백 줄이기 등).
  이미 있는 규칙을 지우지 말고 필요한 것만 더하십시오.

### 4) `sw.js`

- `const VERSION = 'aimem-shell-v29';` 를 `'aimem-shell-v30'` 으로 올립니다.
  (`v29` 가 아니라 다른 값이면, 지금 적힌 값의 숫자에 1 을 더하십시오.)

## 하지 말 것

- `openArchivePanel` 의 내용(설명 목록, 미리보기, 실행)은 **한 글자도 고치지 마십시오**
- `/api/archive` 쪽 서버 코드는 건드리지 마십시오
- 단추를 세 번째 자리에 더 만들지 마십시오 - **전역 바에 딱 하나**입니다
