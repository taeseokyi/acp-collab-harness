# T-222 그래프 제목 펼치기를 폰 폭에서 실측하고, 옮겨 간 '끝난 것 정리' 에 맞춰 고치십시오

고칠 파일은 **`tests/browser_monitor_ui.py` 하나**입니다. 제품 코드
(`tools/aimem_monitor/**`)는 **읽기만 하고 절대 고치지 마십시오**.

## 배경

### (가) 그래프 제목 펼치기 - 검사가 없습니다

`요청 트리` 탭의 `태스크 그래프` 머리줄에 그래프 제목이 `...` 로 줄여 적힙니다. 폰에는 호버가 없어
`title` 을 볼 길이 없으므로, **제목을 누르면 그 자리에서 전문이 펼쳐지도록** 되어 있습니다
(`app.js` 의 `makeElidable`, `style.css` 끝의 `.graph-title.elide-open` 규칙). 표의 칸에는 같은 장치가
오래전부터 있었지만 **그래프 제목에는 빠져 있었고, 최근에 더했는데 이 자리를 재는 브라우저 검사가
하나도 없습니다.**

화면은 **5초마다 다시 그려집니다.** 다시 그려도 펼친 제목이 접히지 않도록 `state.graphTitleOpen` 에
기억해 둡니다 - **그것까지 재야 합니다.**

### (나) '끝난 것 정리' 단추가 상단 전역 바로 갔습니다

앞 태스크가 `끝난 것 정리…` 단추를 **`#requests-tools` 와 보드 필터줄에서 빼서 상단 전역 바
(`<header class="topbar">` 안, `id="archive-open"`)** 로 옮겼습니다. 지금 이 파일의
`request_tree_scenario` 는 `#requests-tools` 안에서 그 단추를 찾으므로 **그대로 두면 깨집니다.**

## 할 일

### 1) 깨진 자리를 고칩니다 (`request_tree_scenario`)

- `끝난 것 정리…` 단추를 **`#archive-open`** 에서 찾습니다. 그 단추는 **어느 탭에 있든 늘 보여야**
  하므로, `함대` 탭에서 한 번 · `요청 트리` 탭에서 한 번 **`is_visible()` 로** 확인하십시오.
- `#requests-tools` 쪽 확인은 **글(`끝난 요청 N건 · 끝난 그래프 M개`)만** 남기고 단추 확인은 빼십시오.
- 패널을 여는 클릭을 `#archive-open` 클릭으로 바꾸십시오. 뒤의 확인(설명 목록, 미리보기 줄)은 그대로 둡니다.
- **보드 필터줄에는 그 단추가 없어야** 합니다: `보드·큐` 탭에서 `#board-filter` 안에
  `끝난 것 정리` 글자를 가진 단추가 **0개**임을 확인하는 검사를 하나 더하십시오.

### 2) 그래프 제목 펼치기 시나리오를 더합니다 (새 함수 `graph_title_expand_scenario`)

**뷰포트 `{"width": 390, "height": 844}`** 로 새 컨텍스트를 엽니다. `요청 트리` 탭으로 가서
`#graphs-list` 의 첫 `.graph-title` 을 잡고, 아래 **다섯**을 `checks.ok(...)` 로 재십시오.

1. **처음에는 줄여져 있다** - `.graph-title` 이 `is_visible()` 이고 `elide-open` 클래스가 없고,
   `scroll_width > client_width + 1` 이거나 `aria-expanded == 'false'` 다
2. **누르면 펼쳐진다** - 클릭 뒤 `elide-open` 클래스가 붙고 `aria-expanded == 'true'` 이며,
   `bounding_box()` 의 `height` 가 클릭 전보다 **크다**
3. **펼친 글이 화면 밖으로 안 나간다** - `bounding_box()` 의 `x >= -1` 이고
   `x + width <= 390 + 1` 이다
4. **5초 뒤 다시 그려도 펼친 채다** - `page.wait_for_timeout(6000)` 뒤에도
   (요소를 **다시 잡아서**) `elide-open` 이 그대로 붙어 있다
5. **다시 누르면 접힌다** - 클릭 뒤 `elide-open` 이 없고 `aria-expanded == 'false'` 다

그리고 이 함수를 `main()`(또는 시나리오들을 차례로 부르는 자리)에 다른 시나리오들과 같은 방식으로
**등록**하십시오.

## 지킬 것

- 화면 검사는 **실제로 그려진 것**을 물어야 합니다: 보임/숨김은 `is_visible()`, 색은
  `getComputedStyle`, 자리·겹침·잘림은 `bounding_box()` 로 재십시오. 속성만 보고 통과시키지 마십시오
- 이미 있는 검사를 **지우지 마십시오**. (1)은 선택자만 바꾸는 것입니다
- `#graphs-list` 에 그래프가 없으면 그 시나리오는 **`checks.ok(..., False, '그래프 없음')`** 로 빨갛게
  남기십시오. 조용히 건너뛰지 마십시오
- 제품이 틀려서 못 통과하면 제품도 검사도 고치지 말고, 보고 첫 줄을 `NEEDS-FIX: <무엇이 어디서>` 로
  쓰고 멈추십시오
