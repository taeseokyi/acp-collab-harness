## 목표 - 3차 검수 (읽기 전용)

너는 `tools/fleet_graph.py` 를 두 번 검수해 결함 **10건**을 찾았다(1차 6건, 2차 새로 4건).
S1 이 2차 결함 중 **7·8 을 고쳤다**고 한다(9·10 도 손댔을 수 있다).
**고쳤다는 말을 믿지 말고 같은 시나리오를 다시 돌려라.**

이번에는 **테스트가 생겼다** - `tests/test_fleet_graph.py` (21건 이상). 그 테스트가
네가 찾은 것을 실제로 막는지도 봐야 한다. **테스트가 통과한다는 것과 계약이 맞다는 것은
다른 말이다.**

## 쓰기 없음

**파일을 하나도 만들거나 고치지 마라.** `fleet_graph.GRAPHS` 와 `fleet.RUNS` 를
`tempfile` 디렉터리로 바꿔 놓고만 재현하라.

> **2차 검수에서 네 재현이 실제 작업자를 하나 띄웠다.** `step()` 재현이 타임아웃 →
> `retry-queued` → `_spawn_node` → **진짜 `fleet.cmd_spawn`** 으로 이어졌다.
> **이번에는 `fleet.cmd_spawn` 을 반드시 patch 해서 막아라.** 띄웠다면 보고에 적고
> pgid 로 거두어라(`pkill -f` 금지).

## S1 이 고쳤다고 주장하는 것

1. **(결함 7)** `_kill_run` 의 결과가 `refused` 면 `.lost` 를 만들지 않고 재시도도 하지
   않는다. 노드를 **`blocked`** 로 두고 사람에게 넘긴다. attempt 에 `"kill_outcome"` 을 남긴다.
   `killed`·`foreign` 은 지금까지와 같다(`.lost` + 재시도).
2. **(결함 8)** tz 가 붙은 `started` 를 `d.astimezone().replace(tzinfo=None)` 으로
   **로컬로 변환한 뒤** naive 로 만든다. `'…Z'` 접미도 처리한다.
3. **(결함 9)** 낱말 뒤가 `:`/`：`/`-`/줄 끝일 때는 소문자·혼합 대소문자도 받는다.
   `보고 상태:` 처럼 앞에 낱말이 붙은 라벨과 선행 BOM 도 벗긴다.
   **평문 `Blocked 링크 3개 수정` 은 계속 거부해야 한다.**
4. **(결함 10)** `/proc/<pgid>/stat` 이 `Z` 면 죽은 것으로 본다.

## 반드시 다시 돌려라

- **결함 7:** `refused` 상황에서 노드가 `blocked` 이고 `.lost` 가 **없고** 재스폰이 **없는지**.
  그리고 `killed` 일 때는 여전히 `.lost` + 재시도가 되는지. `foreign` 은 어느 쪽인지.
- **결함 8:** `TZ=Asia/Seoul` 에서 `_elapsed_since('<지금 UTC aware>')` 가 **0 에 가까운지**.
  `'2026-11-10T00:00:00Z'` 가 naive 로컬 값과 **같은 경과**를 주는지.
  `started` 가 지금(UTC aware)인 running 노드가 `step()` 뒤 **살아 있는지**.
  **다른 tz 도 보라** - `+09:00`, `-05:00`, `+00:00`, `Z`, naive.
- **결함 9:** 잡아야 할 것(`'blocked'`, `'Blocked: x'`, `'보고 상태: BLOCKED'`,
  `'﻿BLOCKED'`, `'BLOCKED:'`, `'NEEDS-LOCK:'`)과
  **절대 잡으면 안 될 것**(`'Blocked 링크 3개를 풀었다'`, `'Rejected 된 항목 없음'`,
  `'BLOCKED-FREE 빌드 성공'`, `'REJECTED_FIX 적용 완료'`, `'상태: DONE'`,
  `'DONE (이전 시도는 NEEDS-LOCK)'`, `'PARTIAL'`) 전부.
- **결함 10:** 좀비 래퍼에서 `_kill_run` 이 유예 시간을 다 쓰지 않는지(경과 초).
- **1차 결함 1~6 회귀:** killpg 가 자식까지 죽이는지 / 안전 검사 8입력 전부 거부 /
  `_node_timeout` 불량값 거부 / `done` + 명부 밖 슬롯에서 `cmd_step` rc 0 /
  `cmd_validate` 는 여전히 rc 2 / 잠금 배타성·예외 중 해제·unlink 없음·`.lost` 덮어쓰지 않음.

## 새 구멍을 노려라

- **결함 7 의 되치기:** `refused` 로 `blocked` 가 되면 **살아 있는 작업자를 아무도 안 거둔다.**
  그 작업자가 나중에 `.rc` 를 쓰면 어떻게 되나? 그래프는 `blocked` 인데 실행은 `done` 인
  상태가 영구히 남나? `_busy_slots` 는 그 슬롯을 계속 바쁘다고 보나(그래서 다른 노드가
  영영 못 뜨나)?
- **결함 8 의 되치기:** `astimezone()` 은 시스템 tz 를 본다. `TZ` 가 바뀌는 환경이나
  **DST 경계**에서 어긋나나? naive 값에 `astimezone()` 을 부르면 어떻게 되나?
- **결함 9 의 되치기:** 소문자를 받기 시작하면서 **평문 영어 보고**가 상태로 읽히는 길이
  다시 열렸나? `'blocked by upstream, but DONE'`, `'rejected: none'`,
  `'needs-review: 없음'` 같은 것을 돌려 보라.
- **`tests/test_fleet_graph.py` 자체를 의심하라.** 테스트가 **구현을 베껴 쓴 곳**이 있나
  (= 틀린 동작을 고정한 곳)? 네가 찾은 결함 10건 중 **테스트가 실제로 막는 것은 몇 개**인가?
  막지 못하는 것은 어느 것인가? 이것을 **표로** 적어라.

## 검증 명령 (돌려서 출력을 붙여라)

```
python3 -m py_compile tools/fleet_graph.py
python3 -m unittest tests.test_fleet_graph -q
python3 -m unittest discover -s tests -q
grep -n "pkill" tools/fleet_graph.py
```

## 보고 형식

첫 줄 `상태: DONE`(검수 완료) 또는 `상태: BLOCKED`.

**(1) 결함 7·8·9·10 의 현재 상태** - 각각 `고쳐짐` / `부분` / `안 고쳐짐` / `끈 것` +
**재현 출력**.

**(2) 1차 결함 1~6 회귀 여부** - 한 줄씩.

**(3) 테스트 커버리지 표** - 결함 1~10 각각에 대해
`tests/test_fleet_graph.py` 가 **막는다 / 못 막는다 / 틀린 동작을 고정했다** 중 하나 +
해당 테스트 메서드 이름.

**(4) 새 결함** - 아래 꼴로, 심각도 높은 것부터:

```
### 결함 N - <한 줄 제목>  [높음|중간|낮음]
- 어디: tools/fleet_graph.py <함수/행>
- 무엇이 틀렸나: (한 문단)
- 재현: (실제로 돌린 명령과 출력 그대로)
- 고치는 방향: (한두 줄. 네가 고치지는 마라)
```

없으면 없다고 적고, 돌린 적대적 시나리오를 명령과 출력으로 보여라.
