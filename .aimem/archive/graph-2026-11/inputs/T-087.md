## (A) 결함 1 [높음] - 타임아웃이 `bash` 래퍼만 죽이고 실제 작업자는 고아로 남는다

**재현된 사실.** `fleet.py` 는 작업자를 `bash -c "<CLI>; echo $? > rc"` 로 `start_new_session=True`
와 함께 띄운다. `meta["pid"]` 는 그 **래퍼**의 pid 다. 래퍼는 `;` 복합 명령이라 `exec` 하지 않고
자식(claude/codex/opencode)을 따로 띄운다. 래퍼에 SIGTERM 을 보내면 **래퍼만 죽고 자식은 산다.**

S4 실측:
```
wrapper dead rc: -15 | surviving worker child:
567350 sleep 777            <- 자식이 살아 있음
R1 state after kill: ('lost', None)   <- 슬롯 한가함으로 보임
```

그 뒤 `.rc` 는 영영 안 써지고 `_run_state` 가 `lost` 를 돌려주므로 `_busy_slots` 가 그 슬롯을
**한가하다고 본다.** 재시도가 같은 슬롯에 두 번째 작업자를 띄우는데 **첫 번째가 살아서 같은
소유 경로에 쓰고 있다.** 타임아웃의 목적이 거꾸로 된다.

**고칠 모양.** `start_new_session=True` 이므로 **pgid == 래퍼 pid** 다.

- `_kill_run` 이 `os.kill(pid, …)` 대신 **`os.killpg(pgid, SIGTERM)` → 유예 → `os.killpg(pgid, SIGKILL)`** 를 쓴다.
- 보내기 전 안전 검사를 **반드시** 한다. 하나라도 어긋나면 **아무도 죽이지 않는다**:
  - `isinstance(pid, int) and not isinstance(pid, bool) and pid > 1`
  - `os.getpgid(pid) == pid` (정말 자기 세션의 리더인가. 아니면 래퍼가 아니라 남의 pid 다)
  - `pgid != os.getpgid(0)` (**내 프로세스 그룹이면 절대 안 된다** - 관리자가 자기를 죽인다)
  - `pgid != 0` (`killpg(0, …)` 은 내 그룹 전체다)
- `os.getpgid(pid)` 가 `ProcessLookupError` 면 이미 죽은 것이다 - 조용히 넘어간다.
- 지금 통과시키고 있는 방어(`None`/`0`/`-1`/`1`/문자열/`True`/`float`/자기 pid)를 **그대로 유지**하라.

## (B) 결함 2 [중간] - pid 재사용 - **이번에는 "죽이지 않는 쪽"만 더하라**

작업자가 `.rc` 없이 사라지고 그 pid 를 **다른 프로세스가 물려받으면** 무관한 프로세스에
SIGTERM 이 간다(S4 실측: `unrelated process killed, rc -15`).

완전한 신원 확인은 이번 범위가 아니다. **값싼 확인 하나만** 더하라:

- 죽이기 전에 `/proc/<pid>/cmdline` 을 읽어(없으면 이 검사를 **건너뛴다** - 리눅스가 아닐 수 있다)
  그 안에 **run id** 또는 **그 run 의 brief 경로**(`.aimem/runs/<run_id>.brief.md`) 또는
  문자열 `fleet` 중 **아무것도 없으면 죽이지 않는다.**
- 죽이지 않았으면 `.lost` 마커만 남기고 로그에
  `timeout <node> - pid <p> 가 그 실행의 것이 아닙니다 (죽이지 않음)` 를 쓴다.
  노드 판정(재시도/실패)은 죽인 경우와 **똑같이** 간다.

## (C) 결함 3 [중간] - `report_block_reason` 에 단어 경계가 없다

S4 실측 **거짓 양성**(전부 `blocked` 가 됐다 - 재시도가 없으므로 복구가 사람 손이다):
```
'Rejected 된 항목 없음, 모두 통과'  -> REJECT
'REJECTED_FIX 적용 완료'           -> REJECT
'rejection 없음 - DONE'            -> REJECT
'Blocked 링크 3개를 풀었다'         -> BLOCKED
'BLOCKED-FREE 빌드 성공'            -> BLOCKED
'NEEDS-'                           -> NEEDS-
```

**고칠 모양.**

- 상태 낱말 뒤에 **`(?![A-Za-z0-9_-])`** 를 붙인다(하이픈까지 막아야 `BLOCKED-FREE` 가 빠진다).
- `NEEDS-` 는 **뒤에 최소 한 글자**(`NEEDS-[A-Z]+`)를 요구한다. 맨 `NEEDS-` 는 `None` 이다.
- `IGNORECASE` 를 **좁힌다**: 앞에 `상태:`(또는 `Status:`) 접두가 있을 때만 대소문자를 무시하고,
  접두 없이 줄이 시작할 때는 **대문자만** 받는다. (`Rejected …`·`Blocked 링크 …` 같은 평문
  영어 문장이 상태로 읽히는 길을 막는 것이 목적이다.)

**거짓 음성도 같이 줄여라.** 아래는 지금 `None` 인데 전부 상태 줄로 봐야 한다:
```
'> BLOCKED'   '1. BLOCKED'   '- BLOCKED'   '`BLOCKED`'   '[BLOCKED]'   '상태: `BLOCKED`'
```
벗겨 내는 접두(`_BLOCK_PREFIX`)에 `>`, `-`, `*`, `` ` ``, `[`, `]`, `숫자.` 를 더하라.
`'Status: BLOCKED'` 도 받아라. `'## 보고\n상태: BLOCKED'`(상태가 **둘째 줄**)은 **지금처럼
`None` 으로 두어라** - 첫 줄만 본다는 `0.3` 규칙을 바꾸는 일은 이번 범위가 아니다.

**깨면 안 되는 것** (지금 올바르게 `None` 이다):
`'상태: DONE - BLOCKED 되었던 것을 풀었다'`, `'DONE (이전 시도는 NEEDS-LOCK)'`,
`''`, `None`, 공백만, `'PARTIAL'`, `'상태: DONE\nBLOCKED'`.

## (D) 결함 4·5 [낮음] - `timeout_sec` 범위 검사 + `started` 파싱

**D-1.** `_node_timeout` 에 **값 범위 검사가 없다.** S4 실측에서 `nan`/`0`/`-1`/`True` 가
갓 띄운 작업자를 **첫 틱에 죽였다**(`float("nan")` 은 변환에 성공하고 `elapsed <= nan` 이
항상 거짓이다).

- `math.isfinite(x) and x > 0` 이 아니면 그 후보를 **버리고 다음 후보**로 간다
  (`n["timeout_sec"]` → `g["node_timeout_sec"]` → `1800`).
- `bool` 은 숫자로 받지 마라(`isinstance(x, bool)` 이면 거부).
- 버릴 때 `_log` 로 한 줄 남겨라 - 조용히 무시하면 오타를 영영 모른다.

**D-2.** `_check_timeout` 이 `fromisoformat` 의 예외는 잡지만 **뺄셈은 `try` 밖**이다.
tz 가 붙은 `started`(`'2026-11-10T09:00:00+09:00'`)면 **`step()` 자체가 `TypeError` 로 죽는다.**
그리고 `progress()`(228행)는 보호가 아예 없어 `cmd_step`/`status`/`list` 가 같이 죽는다.

- **파싱과 뺄셈을 한 `try` 로 묶어라.** tz 가 붙은 값은 `.replace(tzinfo=None)` 으로
  naive 로 떨어뜨려 비교하라(이 저장소의 시각은 전부 로컬 naive 다).
- 판정을 건너뛸 때 `_log` 한 줄을 남겨라(지금은 조용하다 - 그 노드는 영영 타임아웃이 안 난다).
- **같은 파서를 `progress()` 의 `running` 노드 경과 계산에도 써라.** 거기서 터지면
  `status`/`list`/`step` 의 출력이 통째로 죽는다.

## (E) 결함 6 [낮음] - 시작 전 `validate` 가 끝난 그래프의 수확까지 막는다

`_validate_or_report` 가 `done`/`running` 노드까지 명부·소유권을 다시 검사한다. 슬롯이
명부에서 빠지거나 `6절` 소유 경로가 바뀌면 **이미 `done` 인 노드 때문에 `step` 이 rc 2** 로
끝나고, 돌고 있는 작업자를 **거두지도 타임아웃으로 죽이지도 못해 고아가 된다**(S4 실측).

- **스폰 전 검사는 `todo` 노드에만** 슬롯·소유권을 적용하라. DAG 모양(사이클·모르는 dep)과
  `task` 본문 비어 있음은 **전체**에 그대로 적용한다.
- `validate_graph(g)` 의 기존 동작은 **바꾸지 마라**(`cmd_validate` 와 `cmd_new` 가 그대로 쓴다).
  `cmd_step`/`cmd_run` 이 쓰는 쪽에만 필터를 주라 - 예: `validate_graph(g, spawnable_only=True)`
  처럼 **기본값이 지금 동작인** 선택 인자를 더하라.
