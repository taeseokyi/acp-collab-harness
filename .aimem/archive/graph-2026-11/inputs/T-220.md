# T-220 프로젝트를 **별도 탭**으로 분리하십시오 (태석님 요청 Q-261112-7a8e)

태석님 요청 전문: "함대에서 프로젝트는 별도 탭으로 분리해주세요."

고칠 파일은 넷뿐입니다.

- `tools/aimem_monitor/static/index.html`
- `tools/aimem_monitor/static/app.js`
- `tools/aimem_monitor/static/style.css`
- `tools/aimem_monitor/static/sw.js` (버전 한 줄만)

**서버(`tools/aimem_monitor/server.py`)와 시험(`tests/**`)은 절대 고치지 마십시오.**

## 읽을 곳 (이것만)

- `tools/aimem_monitor/static/index.html` 전체 (130줄쯤)
- `tools/aimem_monitor/static/app.js` 의 `TABS` 배열 · `selectTab` · `initTabs` (파일 끝 3620~3665행 근처),
  `setTabCount` · `renderTabCounts` (3044~3070행 근처), `renderProjects` (3265행 근처)
- `tools/aimem_monitor/static/style.css` 의 `.tabs` 관련 규칙

AIMEM.md 는 읽지 마십시오.

## 지금 모습

탭이 셋입니다: `함대`(`#panel-fleet`) · `보드·큐`(`#panel-board`) · `요청 트리`(`#panel-requests`).
**프로젝트 카드(`<section class="card" id="projects-section">`)는 함대 탭 안**에, 함대 현황과 작업자 실행
상태 사이에 끼어 있습니다.

## 할 일

### 1) `index.html`

- 탭 단추를 하나 더합니다. **자리는 `함대` 바로 뒤, `보드·큐` 앞**입니다.

  ```html
  <button type="button" role="tab" id="tab-projects" aria-controls="panel-projects" aria-selected="false" tabindex="-1">프로젝트 <span class="tab-count" id="tab-count-projects"></span></button>
  ```

- `<div id="panel-projects" role="tabpanel" aria-labelledby="tab-projects" hidden>` 패널을 새로 만들고,
  **`projects-section` 을 함대 패널에서 잘라 그 안으로 옮깁니다**(복사가 아니라 이동 - 함대 탭에는
  남기지 않습니다). 패널 자리는 `panel-fleet` 바로 뒤입니다.
- 옮긴 카드의 제목줄 힌트는 그대로 둡니다.

### 2) `app.js`

- `TABS` 배열에 `{ tab: 'tab-projects', panel: 'panel-projects', key: 'projects' }` 를 **`fleet` 바로 뒤**에
  넣습니다. `selectTab` · `initTabs` 는 배열을 돌기 때문에 그 밖에 고칠 것이 없습니다
  (좌우 화살표·Home·End 도 자동으로 따라옵니다).
- `renderTabCounts(data)` 에 프로젝트 탭의 숫자를 더합니다. 숫자는 **`data.projects` 중 아직 안 끝난 것의 수**
  입니다. 프로젝트 하나는 `percent` 와 `goals`(있으면 `{done, total}`) 를 가집니다 -
  `goals && goals.total` 이면 `goals.done < goals.total` 인 것, 아니면 `Number(percent) < 100` 인 것을
  셉니다. `setTabCount('tab-count-projects', n, true)` 로 넣고, 다른 탭들처럼
  `$('tab-count-projects').title = '아직 끝나지 않은 프로젝트';` 를 달아 주십시오.
  `renderProjects` 자체는 **고치지 마십시오**(패널만 옮겼을 뿐 그리는 코드는 그대로입니다).

### 3) `style.css`

- 탭이 넷이 되어 **폰 폭(390px)에서 탭 줄이 넘치거나 글자가 잘리지 않도록** `.tabs` 규칙을 손봅니다.
  `flex-wrap: wrap` 을 허용하거나 좁은 폭에서 글자 크기·좌우 여백을 줄이는 식으로, **탭 넷이 모두 보이고
  서로 겹치지 않아야** 합니다. 이미 있는 규칙을 지우지 말고 필요한 것만 더하십시오.

### 4) `sw.js`

- 맨 위 `const VERSION = 'aimem-shell-v28';` 을 `'aimem-shell-v29'` 로 올립니다 (정적 파일이 바뀌었으니
  설치된 폰이 옛 껍데기를 쓰지 않게).

## 하지 말 것

- `renderProjects`, 프로젝트 결과물 보기, `/api/projects/...` 쪽 코드는 건드리지 마십시오
- 다른 탭의 내용·순서를 바꾸지 마십시오
- 탭 키(`projects`)를 다른 이름으로 바꾸지 마십시오 - 주소의 `#tab=projects` 로 열립니다

```bash
python3 -m unittest tests.test_aimem_monitor tests.test_aimem_monitor_state > /tmp/t220.txt 2>&1 && python3 -c "

ok = ('FAILED' not in t and re.search(r'^OK', t, re.M)
      and 'tab-projects' in h and 'panel-projects' in h and 'tab-count-projects' in h
      and h.rindex('panel-projects') < h.index('projects-section') < h.rindex('panel-board')
      and 'projects-section' not in h[h.rindex('panel-fleet'):h.rindex('panel-projects')]
      and 'panel-projects' in j and 'tab-count-projects' in j
      and 'aimem-shell-v29' in w)
print(ok); sys.exit(0 if ok else 1)"
```
