# T-179 `/api/archive` 가 **새 종류의 건수**도 돌려주게 하십시오

고칠 파일은 **`tools/aimem_monitor/server.py` 하나**입니다. 다른 파일은 고치지 마십시오.

## 읽을 것 (이것만)

- `tools/aimem_monitor/server.py` 의 `archive_action`(1179~1206행)
- 같은 파일 2586~2594행의 `/api/archive` 처리와 `self._audit("archive", …)` 줄
- `tools/aimem_db.py` 의 `archive_plan` 이 돌려주는 키 목록 **이름만** (앞 노드가 `runs`·`events`·
  `handoff`·`relay`·`logs`·`total_records` 를 더했습니다)

**읽지 마십시오:** `AIMEM.md`, `tests/**`, `static/**`, `projects/**`

## 할 것

### 1. `summary` 에 종류별 건수

지금 `summary` 는 `tasks`·`requests`·`graphs` 의 목록만 싣습니다. 여기에 **건수만** 더하십시오
(목록 전체를 실으면 응답이 커집니다 - 실행 기록이 수백 건입니다).

```python
summary["records"] = {
    "runs":      len(plan.get("runs") or []),
    "events":    len(plan.get("events") or []),
    "handoff":   len(plan.get("handoff") or []),
    "relay":     len(plan.get("relay") or []),
    "log_lines": sum(int(l.get("lines") or 0) for l in (plan.get("logs") or [])),
}
summary["total_records"] = plan.get("total_records") or 0
```

**모든 접근을 `plan.get(...) or []` 로 하십시오** - 키가 없는 옛 DB 에서도 500 이 나면 안 됩니다.

### 2. 실행한 뒤 `moved` 에도 같은 종류가 보이게

`archive_apply` 가 돌려주는 `out` 을 그대로 `moved` 로 싣고 있으니 그대로 둡니다. 다만
`out` 의 `runs`·`events` 가 **목록**이면 응답이 길어지므로, `moved_counts` 를 따로 실으십시오:

```python
moved_counts = {k: (len(v) if isinstance(v, (list, tuple)) else v)
                for k, v in out.items() if k != "files"}
```

그리고 `{"ok": True, "dry_run": False, "plan": summary, "moved": out, "moved_counts": moved_counts}` 로 돌려줍니다.

### 3. audit 줄

2593행 근처의 `self._audit("archive", …)` 에서 지금 `moved` 를 200자로 잘라 적습니다.
**`moved_counts` 를 적도록** 바꾸십시오 - 목록이 아니라 종류별 숫자라 잘리지 않습니다:

```python
self._audit("archive", f"{code} days={result.get('plan', {}).get('days')} "
                       f"moved={json.dumps(result.get('moved_counts', {}), ensure_ascii=False)[:300]}")
```
