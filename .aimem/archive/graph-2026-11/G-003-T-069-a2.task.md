## 할 일
`tools/aimem_monitor/reader.py` 의 `collect()` 가 **운영 상태를 `AIMEM.md` 표에서 파싱하던 것을 `.aimem/aimem.db` 에서 읽도록** 바꾸십시오. 키 이름·값 모양은 **하나도 바꾸지 마십시오** - 프런트엔드(`static/app.js`)와 계약 테스트가 그대로 돌아야 합니다.

## 지금 동작 (현물)
`collect()` (411행 근처)가 `AIMEM.md` 를 읽어 `_section()`/`_table_rows()` 로 네 덩어리를 만듭니다:
- `slots`  <- 2절 명부 표 6칸  -> `{slot, token, harness, role, note, model, model_source}`
- `board`  <- 3절 보드 표 6칸  -> `{id, task, slot, status, handoff, artifact}`
- `queue`  <- 4.5 큐 표 5칸    -> `{order, task, slots, handoff, note}`
- `log`    <- `_parse_log()` 4절 -> `{when, text}`  (최신 먼저)
그리고 `aimem` <- `_parse_aimem()` -> `{rev, lines, updated, goal:{text,status}}`.

## 기대 동작
1. `tools/` 를 `sys.path` 에 넣고 `import aimem_db` 한 뒤 **`aimem_db.state_dict()`** 를 한 번 호출해 거기서 위 네 덩어리를 만드십시오. `reader.py` 는 `tools/aimem_monitor/` 안이므로 `pathlib.Path(__file__).resolve().parent.parent` 가 `tools/` 입니다. import 는 **함수 안에서 지연**으로 하고 실패를 삼켜 `errors` 로 낮추십시오 (서버가 죽으면 안 됩니다).
2. 매핑 (DB 컬럼 -> 기존 키). **빠진 값은 빈 문자열** 로 채우십시오:
   - `slots`: DB `slots` 행 `{slot, token, harness, model, role, note}` -> `{slot, token, harness, role, note}`. **`model`/`model_source` 는 지금 코드 그대로** `_load_slot_models()` + `harness_model()` 로 계산하십시오 (DB 의 `model` 컬럼을 쓰지 마십시오 - 하네스 설정이 정본이고 `model_source` 문자열이 필요합니다).
   - `board`: DB `tasks` 행 -> `{id: id, task: title, slot: slot or '-', status: status, handoff: inherited or '-', artifact: artifacts}`
   - `queue`: DB `queue` 행 -> `{order: str(pos), task: task, slots: slot_hint, handoff: inherited, note: note}`  (`order` 는 **문자열** 입니다 - 표에서 왔을 때 문자열이었습니다)
   - `log`: DB `events` 중 **`kind == 'handoff'` 인 것만**, `seq` 내림차순(= `state_dict()` 가 주는 순서) -> `{when: at, text: body}`. `body` 는 마크다운 원문(`- \`2026-11-09 19:45\` 관리자(R4): ...`)이 통째로 들어 있으니 **앞머리 `- \`<시각>\` ` 를 떼어** `when`/`text` 로 나누십시오. 지금 `_parse_log()` 와 같은 모양이 나와야 합니다. `text` 는 기존대로 `LOG_MAX` 로 자르고 줄바꿈은 공백으로 접으십시오.
   - `aimem.rev`: DB `rev` 를 **우선**하고 없으면 지금처럼 서문에서 읽으십시오.
3. **마크다운 폴백을 남기십시오.** DB 가 없거나 `state_dict()` 가 실패하면 지금의 표 파싱으로 내려가고 `errors` 에 한 줄 남기십시오. 반대로 **표가 없어도(= 곧 AIMEM.md 에서 표를 내립니다) `errors` 가 늘지 않아야 합니다** - 지금 `_table_rows()` 는 표가 없으면 `errors` 에 적습니다. DB 경로로 읽었으면 표 파싱을 아예 하지 마십시오.
4. `aimem.lines` 는 지금처럼 `AIMEM.md` 줄 수입니다. `AIMEM.md` 가 없으면 0.
5. `_parse_aimem()` 의 `1절 목표` 파싱은 **그대로 둡니다** - 1절은 규약 본문이라 마크다운에 남습니다.
