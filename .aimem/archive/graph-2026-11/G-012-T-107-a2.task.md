## 쓸 하네스 - `tests/browser_harness.py` (T-105 가 만든 것, 고치지 마십시오)

```python
from browser_harness import server, new_page, shot, Checks   # 같은 폴더
```

- `server()` - 컨텍스트 매니저. `with server() as base:` 하면 `base` 가
  `http://127.0.0.1:<빈 포트>`. `web/` 를 내려주는 서버가 스레드로 뜹니다
- `new_page(browser, base, viewport=None, clipboard=False)` - 새 컨텍스트(저장소가 비어 있음)를
  만들고 `index.html` 을 열어 `#board .tile` 이 나올 때까지 기다린 **`page` 하나**를 줍니다
  (튜플이 아닙니다). 그 `page` 에 `page._errors`(콘솔 오류와 `pageerror` 가 쌓이는 리스트)와
  `page._context` · `page._close_context()` 가 붙어 있습니다. **오류는 저절로 예외가 되지 않으니**
  시나리오 끝마다 `c.ok("<목표>", not page._errors, str(page._errors))` 로 직접 확인하십시오.
  `set_group("<그룹>")` 으로 스크린샷 폴더를 정합니다
- `shot(page, "<파일이름>")` - `tests/screenshots/<그룹>/<파일이름>.png` 로 저장
- `Checks()` - `c.ok("목표 이름", 조건, "설명")` 으로 쌓고 `c.finish()` 가 표를 찍은 뒤
  실패가 있으면 0 이 아닌 값을 돌려줍니다

## 화면 계약 (관리자가 실제 브라우저로 확인한 사실입니다 - 믿고 쓰십시오)

서버를 띄우고 `index.html` 을 열면: `#board .row` 6개, 각 줄에 `.tile` 5개(모두 30개),
`#keyboard .key` 28개, 콘솔 오류 0건. **첫 방문이면 도움말 창이 저절로 열립니다.**

- **타일** `#board .row:nth(r) .tile:nth(c)` - `data-state` 가 `empty|filled|correct|present|absent`,
  `textContent` 는 대문자 한 글자, `aria-label` 은 "`1번째 줄 2번째 칸, C, 맞음`" 꼴
- **키** `#keyboard .key[data-key="a"]` ... `[data-key="z"]`, `[data-key="enter"]`, `[data-key="back"]`.
  제출한 뒤에만 `data-state` 가 붙습니다(안 눌린 글자에는 **속성이 아예 없습니다**)
- **없는 단어** → 그 줄에 `.shake` 클래스가 600ms 동안 붙고 `#toasts .toast` 가 생깁니다
- **이김** → 맞은 줄 타일에 `.bounce`, 칭찬 토스트, **2000ms 뒤 통계 창이 저절로 열립니다**
- **짐** → `정답: XXXXX` 토스트(사라지지 않음), **1500ms 뒤 통계 창**
- **창** `#modal-help` · `#modal-stats` · `#modal-settings` - 열리면 `hidden` 속성이 빠지고
  `#app` 에 `inert` 가 붙습니다. `.modal-close` 클릭 또는 `Escape` 로 닫힙니다.
  **창이 열려 있는 동안 보드 입력은 전부 무시됩니다**
- **통계** `#stat-row .stat b` 4개 = 판수·승률%·연승·최대연승 (이 순서).
  `#dist .dist-row .bar` 6개. `#btn-share` 는 판이 끝나야 `hidden` 이 빠집니다
- **설정** `#set-hard` · `#set-dark` · `#set-cb` (체크박스).
  켜면 `<html>` 의 `data-theme="dark"` · `data-colorblind="on"` 이 바뀝니다
- **저장** `localStorage` 키 `webwordle.daily.<YYYY-MM-DD>` · `webwordle.stats` ·
  `webwordle.settings` · `webwordle.seenHelp`
- **애니메이션** 칸 하나가 500ms, 칸 사이 100ms → 제출 뒤 보드가 멎기까지 약 950ms.
  `time.sleep` 말고 `page.wait_for_function` 으로 `data-state` 가 바뀌기를 기다리십시오

**오늘의 정답과 허용 단어는 쪽 안에서 물어봅니다** (하드코딩 금지 - 날마다 바뀝니다):

```python
answer = page.evaluate("async () => { const g = await import('/js/game.js');"

                       " return g.answerForDate(new Date(), w.ANSWERS); }")
```

## 증명할 목표 다섯 개

`set_group("ui")` 로 시작합니다. 시나리오마다 **새 컨텍스트**를 쓰고, 첫 방문이면 도움말 창이
저절로 열리니 닫고 나서 입력하십시오.

### 목표 "도움말" - 처음 열면 규칙 안내, 다시 볼 수 있음
- 새 컨텍스트에서 열자마자 `#modal-help` 가 **열려 있음**(`hidden` 속성이 없음). `shot(page, "help-first")`
- 그때 `#app` 에 `inert` 가 붙어 있고, 창이 열린 동안 글자를 쳐도 보드가 **안 바뀜**
- 닫은 뒤 `page.reload()` → 이번에는 **안 열림** (`webwordle.seenHelp`)
- `#btn-help` 를 누르면 **다시 열림**. 안에 `.example .tile[data-state="correct"]` 같은
  보기 타일이 있고 설명 글이 비어 있지 않음

### 목표 "통계" - 판수·승률·연승·최대연승·추측 분포, 새로 고쳐도 진행 중인 판 유지
- **빈 상태:** 새 컨텍스트에서 `#btn-stats` → `#stat-row .stat b` 네 개가 모두 `0`,
  `#dist .dist-row` 여섯 줄, `#btn-share` 는 `hidden`
- **이긴 뒤:** 정답을 한 번에 맞히고 통계를 열면 판수 1 · 승률 100 · 연승 1 · 최대연승 1 이고
  분포의 1번째 줄이 1. `#btn-share` 의 `hidden` 이 빠짐. `shot(page, "stats-after-win")`
- **새로 고쳐도 진행 중인 판이 남음:** 또 다른 새 컨텍스트에서 틀린 단어 두 개를 제출한 뒤
  `page.reload()` → **두 줄이 그대로 글자와 판정 색까지 남아 있고** 세 번째 줄부터 비어 있음.
  키보드 색도 그대로. `shot(page, "restored")`
  (`#modal-help` 가 다시 안 뜨는 것도 함께 확인)

### 목표 "결과 공유" - 이모지 격자 복사
- `new_page(..., clipboard=True)` 로 열고 이긴 판을 만든 뒤 `#btn-share` 클릭
- `page.evaluate("navigator.clipboard.readText()")` 로 읽어서:
  - 첫 줄이 `웹워들 <오늘의 puzzle 번호> <맞힌 줄수>/6` 과 **정확히 같음** (번호는 쪽에서 물어본 값)
  - 그 아래 **맞힌 줄수만큼의 이모지 줄**이 있고, 줄마다 네모 이모지 다섯 개
  - 마지막 줄은 다섯 개가 모두 맞음을 뜻하는 네모여야 함
- 복사했다는 토스트가 뜸. `shot(page, "share")`

### 목표 "보기 설정" - 어두운 테마, 색약 모드, 설정이 저장됨
- `#btn-settings` → `#set-dark` 를 켜면 `<html data-theme="dark">` 로 바뀌고
  `#board` 의 배경색(`getComputedStyle`)이 밝을 때와 **실제로 다름**. `shot(page, "theme-dark")`
- `#set-cb` 를 켜면 `<html data-colorblind="on">` 이 되고, `correct` 타일의 배경색이
  색약 모드가 아닐 때와 **실제로 다름**(주황 계열). 켠 채로 한 줄 제출해서 색을 보고
  `shot(page, "theme-colorblind")`
- `page.reload()` 해도 두 설정이 **그대로 켜져 있음**(`<html>` 속성과 체크박스 둘 다)
- 밝은 테마로 돌린 뒤 `shot(page, "theme-light")`
- **하드 모드 잠금:** 판을 시작한 뒤(한 줄 제출) 설정에서 `#set-hard` 를 켜려고 하면
  체크가 도로 풀리고 안내 토스트가 뜸

### 목표 "접근성" - 키보드만으로 완주, `aria-live` 로 결과 읽힘, 대비 4.5:1
- **키보드만으로:** 마우스 클릭 없이 `page.keyboard` 로만 도움말을 닫고(`Escape`)
  정답을 쳐서 이기는 데까지 갑니다
- **`Tab` 으로 화면 키를 눌러 글자가 들어감:** `Tab` 을 눌러 `#keyboard` 안의 버튼에 포커스가
  갈 때까지 간 뒤 `Enter` 를 누르면 **제출이 아니라 그 글자가 입력**되어야 합니다
  (R7 에서 고친 곳입니다 - 되돌아가지 않았는지 봅니다).
  `page.evaluate("document.activeElement.dataset.key")` 로 어느 키에 있는지 확인하십시오
- **읽힘:** `#toasts` 에 `aria-live="polite"` 가 있고, 판이 끝났을 때 그 안에 글이 들어감.
  판정된 타일의 `aria-label` 에 `맞음` / `자리 틀림` / `없음` 이 들어 있음
- **대비 4.5:1:** `correct` · `present` · `absent` 타일 **각각에 대해**
  `getComputedStyle` 로 `background-color` 와 `color` 를 읽어 WCAG 상대 휘도로 대비를 직접 계산하고
  **4.5 이상**인지 봅니다. 밝은 테마 · 어두운 테마 · 색약 모드 **세 경우 모두**.
  계산식(이대로 쓰십시오):

  ```python
  def _lin(c):            # c 는 0~255
      s = c / 255
      return s / 12.92 if s <= 0.04045 else ((s + 0.055) / 1.055) ** 2.4
  def luminance(rgb):
      r, g, b = (_lin(v) for v in rgb)
      return 0.2126 * r + 0.7152 * g + 0.0722 * b
  def contrast(fg, bg):
      a, b = luminance(fg), luminance(bg)
      hi, lo = max(a, b), min(a, b)
      return (hi + 0.05) / (lo + 0.05)
  ```

  `getComputedStyle` 은 `rgb(83, 141, 78)` 꼴로 주니 숫자 세 개를 뽑아 쓰십시오.
  **실패하면 수치를 그대로 찍으십시오** (`correct 밝은테마 3.9:1` 처럼) - 다음 태스크가 그것으로 고칩니다

끝에 `raise SystemExit(c.finish())`.
