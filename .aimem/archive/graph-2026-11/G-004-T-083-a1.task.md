## (1) 큐 20번 - KISTI 카드가 `pending` 과 `stale` 을 구분해 보여 준다

**지금 무엇이 틀렸나.** `renderKisti(data)` 는 뱃지를 `오류` / `바쁨` / `대기` 셋으로만
가른다. 서버는 그 밖에 두 가지를 더 말하는데 화면이 둘 다 **삼킨다**:

- `k.pending === true` → **아직 값이 없다.** 첫 폴링이고 상류 응답이 도착하지 않았다.
  이때 `queued`·`phase`·`prompt_tokens` 는 **값이 아니라 빈칸**이다.
- `k.stale === true` → **지난 값이다.** 갱신이 도는 동안 캐시된 옛 값을 보여 주고 있다.
  `age_sec` 가 그 값이 몇 초 전 것인지 말한다.

지금은 둘 다 그냥 `대기` 로 찍혀서, **값이 없는 것과 옛 값인 것이 같아 보인다.**

**고칠 모양.**

- 뱃지 우선순위를 이렇게 한다:
  1. `k.ok === false` → `오류` (`error` 종류, 지금 그대로)
  2. `k.pending === true` → `조회 중` (`pending` 종류)
  3. `k.busy === true` → `바쁨` (`busy` 종류, 지금 그대로)
  4. 그 밖 → `대기` (`idle` 종류, 지금 그대로)
- `k.stale === true` 이면 위 뱃지 **옆에 뱃지를 하나 더** 붙인다: `지난 값` (`stale` 종류).
  `pending` 과 `stale` 은 **같이 참일 수 있다** - 갱신 중에 아직 새 값이 없는 경우다.
  그때는 뱃지 두 개가 다 보여야 한다.
- `k.pending === true` 일 때 `대기열`·`단계`·`프롬프트`·`생성` 항목의 값은
  `show(...)` 대신 **`'-'`** 로 찍는다. 없는 값을 `0` 으로 보여 주면 "대기열이 비었다" 로 읽힌다.
- `age_sec` 줄은 `stale` 일 때 `<n>초 전 값` 으로, 아닐 때 지금처럼 `<n>초 전 읽음` 으로 쓴다.
- `badge(text, kind)` 는 이미 있다. **새로 만들지 말고 그대로 써라.** `kind` 문자열만
  `'pending'`·`'stale'` 로 넘기면 된다(해당 CSS 클래스가 없으면 기본 뱃지 모양으로 보인다 -
  그래도 괜찮다. `style.css` 는 이번에 고치지 않는다).

**(1-b) 같이 고칠 것 - 경고 문구가 사실과 다르다.**

지금 `renderKisti` 끝에 이 문장이 있다:

```
'지금 kistillm 슬롯을 추가로 띄우면 서버 안에서 직렬화됩니다'
```

**이것은 틀렸다.** `AIMEM.md` `8.0-3` 이 REV 111 실측으로 종결했다 - kistillm 은
**직렬화가 아니라 동시 처리**이고(`busy:true, queued:0` 인 시간이 긴 것이 그 증거다),
느린 원인은 경합이 아니라 턴마다 5~6만 토큰 프롬프트를 다시 읽는 것이다.
문구를 아래로 **그대로** 바꿔라:

```
'kistillm 이 바쁩니다 - 대기열이 아니라 긴 프롬프트를 읽는 중일 수 있습니다 (AIMEM 8.0-3)'
```

## (2) 큐 22번 - 상세 다이얼로그의 포커스 이동·가둠·복귀

**지금 무엇이 틀렸나.** `ensureDetailPanel()` 이 만드는 패널은 `role="dialog"`
`aria-modal` 로 되어 있는데, 열어도 **포커스가 뒤 화면에 남는다.** Tab 을 누르면
포커스가 패널 밖 표로 빠져나가고, 닫아도 **원래 누른 행으로 돌아오지 않는다.**
키보드만 쓰는 사람에게는 패널이 안 열린 것과 같다.

**고칠 모양.** `openDetail()` / `closeDetail()` 쪽에 넣는다.

- **열 때:** 열기 직전의 `document.activeElement` 를 `state.detailReturnFocus` 에 저장하고,
  패널이 보이게 된 뒤 **닫기 버튼(`detail-close`)에 `focus()`** 를 준다.
- **가둠:** 오버레이에 `keydown` 리스너를 걸어 `Tab` 을 가로챈다.
  패널 안의 포커스 가능한 요소 목록을 그때그때 구한다:
  `panel.querySelectorAll('a[href], button, textarea, input, select, [tabindex]:not([tabindex="-1"])')`
  중 `disabled` 가 아니고 `offsetParent !== null` 인 것.
  - `Tab` 이 마지막 요소에서 눌리면 `preventDefault()` 하고 첫 요소로.
  - `Shift+Tab` 이 첫 요소에서 눌리면 `preventDefault()` 하고 마지막 요소로.
  - 포커스 가능한 요소가 **하나도 없으면** 아무것도 하지 않는다(무한 루프 금지).
  - 리스너는 `state.detailBound` 가드 안에서 **한 번만** 건다. 열 때마다 또 걸지 마라.
- **닫을 때:** `state.detailReturnFocus` 가 아직 문서 안에 있으면
  (`document.contains(el)`) 거기에 `focus()` 하고, 아니면 아무것도 하지 않는다.
  저장값은 쓴 뒤 `null` 로 비운다.
- `Escape` 로 닫는 기존 처리도 **같은 복귀 경로**를 타야 한다
  (`closeDetail()` 하나를 거치게 하라 - 복귀 코드를 두 군데에 복사하지 마라).
