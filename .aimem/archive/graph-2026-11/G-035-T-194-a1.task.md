# T-194 실행 티켓이 **주체를 안 묶는 것**을 고치십시오

고칠 파일은 **`tools/aimem_monitor/server.py`** 와 **`tests/test_aimem_monitor_app.py`** 둘뿐입니다.

## 읽을 것 (이것만)

- `tools/aimem_monitor/server.py` 의 `app_ticket()` · `app_ticket_ok()` · `_app_ticket_key()` (213~250행 근처)
- 같은 파일의 `_subject()` (2271행 근처) 와 `/app/` 처리 (`_APP_RE` 가 맞는 자리, 2496~2520행 근처)
- `tests/test_aimem_monitor_app.py` 의 티켓 시험들 (`app_ticket` 이 나오는 줄)

**읽지 마십시오:** `AIMEM.md` 본문, `tools/aimem_db.py`, `projects/**`, 다른 `tests/**`.

## 결함 (R12 T-157 검수 결함 2)

티켓은 `app.v1.<만료>.<프로젝트 이름>` 만 서명합니다. **누가 받았는지가 서명에 없습니다.**
그래서 GitHub 허용 목록에서 계정을 지워도, 그 전에 받아 둔 12시간 티켓으로 `/app/~<티켓>/…` 이
그대로 열립니다. 쿠키와 API 는 `_subject()` 가 요청마다 허용 목록을 다시 보기 때문에 즉시 끊기는데,
**`/app/` 만 구멍**입니다. `/app/~<티켓>/` 길은 지금 `_subject()` 를 아예 부르지 않습니다.

## 고칠 것

1. **서명 payload 에 주체를 넣으십시오.**
   `app_ticket(name, exp, key, subject)` -> `app.v1.<exp>.<subject>.<name>` 을 서명합니다.
   `app_ticket_ok(ticket, name, key, subject, now=None)` 도 같은 주체로 다시 계산해 대조합니다.
   **티켓 문자열의 꼴(`<exp>.<mac 32자>`)과 80자 상한은 그대로 두십시오** - 주체는 서명 안에만 들어가고
   URL 에는 안 보입니다(주소가 로그·기록에 남아도 계정 이름이 새지 않습니다). 두 함수의 인자는
   **주체를 필수로** 받게 하십시오 - 기본값을 주면 부르는 쪽이 빠뜨려도 조용히 옛 동작이 됩니다.
2. **발급할 때**(티켓 없이 `/app/<이름>` 으로 들어와 넘겨주는 자리) 그 자리에서 이미 확인한
   `self._subject()` 값을 그대로 서명에 넣으십시오.
3. **쓸 때**(`/app/~<티켓>/…`) 지금은 세션을 전혀 안 봅니다. 이렇게 고치십시오:
   - `self.require_auth` 가 참이면 `subject = self._subject()` 를 부르고, `None` 이면
     **403 + 지금의 '실행 티켓이 만료됐습니다…' 본문**으로 돌려보냅니다 (iframe 안에서 열리므로
     `/login` 으로 넘기지 않습니다)
   - `app_ticket_ok(ticket, app_name, key, subject)` 가 거짓이면 똑같이 403
   - `require_auth` 가 거짓(지역 검증)이면 주체가 `None` 입니다. **발급·검사 양쪽에서 같은 자리표**
     (예: 문자열 `"-"`)를 쓰도록 한 군데에서 변환하십시오. `None` 을 그대로 서명 문자열에 끼워
     `"None"` 이 되게 두지 마십시오
4. 옛 티켓은 전부 무효가 됩니다. **그것이 맞습니다** - 사람은 모니터에서 '실행' 을 다시 누르면 됩니다.
   되돌림(옛 꼴도 받아 주기)을 만들지 마십시오.

  허용 목록 파일에서 그 계정을 지우고 **같은 티켓으로 다시 불러 403** 이 되는 시험을 하나 쓰십시오
