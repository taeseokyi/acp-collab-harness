## 수정 1 - `Host: [::1].evil.com` 이 허용 목록을 지나갑니다

지금 `_app_origin()` 은 Host 가 `[` 로 시작하면 `]` 까지만 떼어 이름으로 보고, **`]` 뒤에 무엇이
붙어 있는지 보지 않습니다.** 그래서 `[::1].evil.com` 은 이름이 `::1`(IP 리터럴)이라 허용되고,
CSP 문자열에는 `https://[::1].evil.com` 이 통째로 들어갑니다. (크로미엄은 이 값을 잘못된 출처로
버려 실제 허용은 생기지 않았지만, 다른 브라우저는 확인하지 않았습니다.)

`tools/aimem_monitor/server.py` 의 `_app_origin()` (2417행 근처)에서 **호스트를 쪼개는 부분만**
바꿉니다. 바꾼 뒤 함수 전체는 이렇습니다.

```python
    def _app_origin(self):
        """요청 Host 로 만든 출처. 꼴 검사에 더해 **이름까지** 봅니다 (R11 검수 B 결함 1).

        허용하지 않는 이름이면 빈 문자열입니다 - CSP 는 `'self'` 만 남습니다. `]` 뒤에 아무것이나
        붙는 `[::1].evil.com` 이 IP 리터럴로 통과하던 것을 막습니다 (R11 재검수 남은 결함 2).
        """
        host = (self.headers.get("Host") or "").strip() if self.headers else ""
        if not re.match(r"\A[A-Za-z0-9._:\[\]-]{1,100}\Z", host):
            return ""
        m = re.fullmatch(r"(?:\[(?P<v6>[0-9A-Fa-f:.]{2,45})\]|(?P<name>[A-Za-z0-9._-]{1,100}))"
                         r"(?::(?P<port>\d{1,5}))?", host)
        if not m:
            return ""
        if not _app_host_allowed(m.group("v6") or m.group("name")):
            return ""
        return ("https" if self.tls else "http") + "://" + host
```

통해야 하는 것(운영이 쓰는 꼴): `localhost:18799`, `192.168.0.5:18800`, `127.0.0.1`, `[::1]:18799`.
막혀야 하는 것: `evil.com`, `[::1].evil.com`, `[::1]evil.com`, `127.0.0.1:abc`, `a b`.
`_app_host_allowed` 는 **고치지 마십시오.**

## 수정 2 - 짧은 화면에서 결과물 키가 20px 로 쪼그라듭니다

`tools/aimem_monitor/static/style.css` 의 `.proj-app-frame` 규칙에서 **`min-height: 380px` 을
`min-height: 428px` 로** 바꾸고, 그 위 주석 두 줄을 다음으로 바꿉니다.

```css
/* min-height 는 428px 이상이어야 합니다 - 안쪽 높이가 그보다 낮으면 결과물(웹워들)의 키 높이
   계산이 하한 20px 로 떨어집니다. 380px→키 20px, 428px→키 32px (R11 재검수, 844×390 실측).
   짧은 화면에서 패널이 스크롤되는 것은 380px 에서도 이미 그랬습니다 - 이 값이 만든 것이 아닙니다. */
```

`height: min(78vh, 900px)` 과 `@media (max-width: 720px)` 규칙은 **건드리지 마십시오.**
