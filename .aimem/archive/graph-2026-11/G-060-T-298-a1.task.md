# T-298 빌드가 갈래 파일을 읽게 + 시험 기준 올리기

쓸 파일: `projects/자모맞히기/tools/build_words.py`, `tests/test_words.py`, `data/allowed.txt`, `data/answers.txt`, `data/README.md`, `web/js/words.js`(생성물). **`data/words/*.txt` 는 읽기만**(앞 노드들 몫). 약속: `.aimem/graph/inputs/r25/CONTRACT.md`. **바로 파일을 고치십시오.**

## 할 일

1. `tools/build_words.py`: `data/answers.txt`·`data/allowed.txt` 에 더해 **`data/words/*.txt` 전부**(이름 순)를 읽어 `ALLOWED = 정렬(answers ∪ allowed ∪ words/*)` 로 만듭니다. ANSWERS 는 지금처럼 `answers.txt` 만, 같은 씨앗으로 섞음. 걸러 내기(6칸·완성형·중복·주석)는 같은 `load_words` 를 씁니다. 출력 줄에 갈래 파일별 수를 한 줄씩 더하십시오. `--out` 은 그대로.
2. 빼기(`rounds/R24/REVIEW-r24-3.md` N3): `희한 민망 괴악 희식 화성 국전` 을 `allowed.txt`·`answers.txt` 에서 빼고 `test_words.py` `BANNED` 에 여섯을 더합니다(빌드는 금칙어를 모릅니다 - 시험이 지킵니다). 갈래 파일에 금칙어가 있으면 시험이 빨개지니 그때는 `NEEDS-FIX: <파일> <낱말>` 로 보고하십시오(갈래 파일은 고치지 마십시오).
3. 넣기(N2): `까닭` 을 `allowed.txt` 에.
4. `tests/test_words.py`: `test_counts` 의 ALLOWED 하한 1000 → **2000**. `test_first_syllable_not_mass_generated` 는 목록이 커졌으니 상한을 **`max(40, ALLOWED 수의 4%)`** 로. 새 시험 하나: 갈래 파일마다 한 첫 음절 15개 이하(파일을 직접 읽음). `MUST` 는 늘리지 마십시오(검수가 새 표본으로 잽니다).
5. `data/README.md`: '고른 기준'·개수를 새 구조에 맞게 - `data/words/` 갈래 파일 넷(이름과 갈래), ALLOWED 2000 이상, 첫 음절 상한, 금칙어 여섯 추가. '출처' 절은 "함대 작업자가 직접 고름, 내려받은 목록 없음" 을 지킵니다.
6. `python3 projects/자모맞히기/tools/build_words.py` 로 `words.js` 를 다시 만듭니다.
