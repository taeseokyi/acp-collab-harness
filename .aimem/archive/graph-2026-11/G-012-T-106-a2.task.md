## 쓸 하네스 - `tests/browser_harness.py` (T-105 가 만든 것, 고치지 마십시오)

```python
from browser_harness import server, new_page, shot, Checks   # 같은 폴더
```

- `server()` - 컨텍스트 매니저. `with server() as base:` 하면 `base` 가
  `http://127.0.0.1:<빈 포트>`. `web/` 를 내려주는 서버가 스레드로 뜹니다
- `new_page(browser, base, viewport=None, clipboard=False)` - 새 컨텍스트(저장소가 비어 있음)를
  만들고 `index.html` 을 열어 `#board .tile` 이 나올 때까지 기다린 **`page` 하나**를 줍니다
  (튜플이 아닙니다). 그 `page` 에 `page._errors`(콘솔 오류와 `pageerror` 가 쌓이는 리스트)와
  `page._context` · `page._close_context()` 가 붙어 있습니다. **오류는 저절로 예외가 되지 않으니**
  시나리오 끝마다 `c.ok("<목표>", not page._errors, str(page._errors))` 로 직접 확인하십시오.
  `set_group("<그룹>")` 으로 스크린샷 폴더를 정합니다
- `shot(page, "<파일이름>")` - `tests/screenshots/<그룹>/<파일이름>.png` 로 저장
- `Checks()` - `c.ok("목표 이름", 조건, "설명")` 으로 쌓고 `c.finish()` 가 표를 찍은 뒤
  실패가 있으면 0 이 아닌 값을 돌려줍니다

## 쓸 내용

```python
from browser_harness import server, new_page, shot, set_group, Checks
set_group("layout")
```

두 가지 크기로 각각 새 페이지를 엽니다 (`new_page(browser, base, viewport={"width": W, "height": H})`).

| 이름 | 크기 |
| ---- | ---- |
| `narrow` | 360 × 640 |
| `short`  | 900 × 420 |

**첫 방문이면 도움말 창이 저절로 열립니다.** `#modal-help .modal-close` 를 눌러 닫고 나서 재십시오.

크기마다 이것을 확인하고 `Checks` 에 쌓으십시오 (목표 이름은 둘 다 `"접근성/레이아웃"`):

1. **가로로 넘치지 않음** - `page.evaluate("document.documentElement.scrollWidth")` 가
   창 너비보다 **크지 않음** (1px 오차는 봐줍니다)
2. **보드가 다 보임** - `#board` 의 `bounding_box()` 가 `None` 이 아니고,
   `box["x"] >= -1` 이고 `box["x"] + box["width"] <= 창너비 + 1`
3. **키보드가 다 보임** - `#keyboard` 에 대해 2번과 같은 검사. 그리고 세로로도:
   `box["y"] + box["height"] <= 창높이 + 1` (키보드가 화면 아래로 잘려 나가면 칠 수가 없습니다)
4. **타일이 찌그러지지 않음** - 첫 줄 타일 다섯 개의 `bounding_box()` 너비가 모두 **8px 보다 크고**,
   너비와 높이의 비가 0.7 ~ 1.4 사이 (워들 타일은 네모여야 합니다)
5. **키가 누를 만함** - `#keyboard .key` 의 `bounding_box()` 높이가 모두 **20px 이상**
6. **정말 쳐진다** - 글자 다섯 개를 쳐서(`page.keyboard.type("crane")`) 첫 줄 다섯 칸의
   `data-state` 가 `filled` 가 되는지. 작은 화면에서 입력이 막히면 안 됩니다
7. **창도 넘치지 않음** - `#btn-stats` 를 눌러 통계 창을 연 뒤 `.modal-box` 의 `bounding_box()` 가
   창 높이를 넘지 않음 (`box["y"] + box["height"] <= 창높이 + 1`). 확인하고 `Escape` 로 닫습니다

크기마다 `shot(page, "narrow")` / `shot(page, "short")` 로 **전체 쪽 스크린샷**
(`full_page=True` 말고 보이는 화면 그대로)을 남기고, 통계 창을 연 상태로도 한 장씩
(`shot(page, "narrow-modal")` / `shot(page, "short-modal")`) 남기십시오. 사람이 눈으로 볼 것입니다.

끝에 `raise SystemExit(c.finish())`.

## 브라우저가 샌드박스에서 안 뜨면

`python3 -c "from playwright.sync_api import sync_playwright"` 가 되고 이 기계에는 chromium 145 가
깔려 있습니다(관리자가 확인). 그래도 **당신의 샌드박스에서 브라우저가 못 뜨면** 거기서 멈추지 말고,
스크립트를 끝까지 **정확하게 써 놓고** 보고 첫 줄을 `PARTIAL` 로, 둘째 줄에 정확한 오류 메시지를
적으십시오. 검증은 관리자 환경에서 다시 돌립니다. 브라우저가 안 뜬다고 `assert` 를 지우거나
조건을 느슨하게 만들지 마십시오 - **통과시키려고 검사를 무르게 하는 것이 이 태스크의 유일한 실패입니다.**
