## 보탤 시험 (여섯 건 이상)

### A. `fleet_graph.run_limit_signal(run_id)` - **이번에 새로 생긴 함수**

`.aimem/runs/` 자리는 `fleet.RUNS` 로 갑니다. 시험에서는 임시 폴더를 만들고
`fleet.RUNS` 를 그리로 바꿔 쓰십시오(`unittest.mock.patch.object(fleet, "RUNS", tmp)` 또는
`setUp`/`tearDown` 에서 되돌리기). `<run>.json` 에 `{"harness": ...}`, `<run>.out` 에 본문입니다.

1. claude + `{"is_error": true, "api_error_status": 429, "terminal_reason": "api_error"}` → **`True`**
2. claude + `{"is_error": true, "api_error": "usage_limit_reached"}` → **`True`**
3. claude + `{"is_error": false, "result": "DONE - 사용 한도 표시 기능을 만들었습니다"}` → **`False`**
   (보고 글자에 한도 말이 있어도 구조 신호가 아니면 False 여야 합니다)
4. codex 하네스 + 글자 `.out` → **`None`**, opencode + 글자 `.out` → **`None`**
5. 깨진 자료 넷에 **예외가 안 나고 전부 `None`**: JSON 이 아닌 글자 / JSON 이지만 `dict` 가 아닌
   `[1,2,3]` / `.out` 파일 자체가 없음 / 메타(`.json`)가 없음

### B. `step()` 의 `rc != 0` 분기 (변이 R18-G7 이 살아남은 자리)

이 파일의 기존 시험들이 그래프·실행 기록을 어떻게 흉내 내는지 **먼저 읽고 같은 꼴을 쓰십시오**
(`rc` 파일·`report` 를 꾸미는 도우미가 이미 있습니다).

6. **`verify` 가 걸려 있는 노드**인데 실행 `rc != 0` 이면 → `verify` 를 **돌리지 않고**
   `verify_rc == -1`, `verify_tail` 에 `"실행 rc != 0"`. `verify` 로는 **반드시 성공하는 명령**
   (`true` 등)을 걸어 두십시오 - 그래야 "면제가 안 되면 초록" 이 아니라 "면제가 되면 빨강" 을
   구별합니다. 노드 상태는 `done` 이 **아니어야** 합니다
7. `rc != 0` + 구조 신호 `True` → 노드가 `blocked` 이고 `n["limit"] is True`,
   `verify_rc == -4`, 그래프 로그에 `limit` 줄
8. `rc != 0` + 구조 신호 `False`(claude JSON) + 보고 본문에 한도 글자가 **있어도**
   → `limit` 이 **서지 않고** 보통 실패 경로(재시도/실패)로 가는 것
9. `rc == 0` + 보고에 한도 글자 → `limit` 이 서지 않는 것 (이미 있으면 보태지 마십시오)
