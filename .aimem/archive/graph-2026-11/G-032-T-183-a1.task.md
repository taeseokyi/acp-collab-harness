# T-183 바뀐 요청 트리를 **브라우저에서 그려진 대로** 재십시오

고칠 파일은 **`tests/browser_monitor_ui.py` 하나**입니다. 다른 파일은 고치지 마십시오
(`tools/**` 금지 - 화면은 다른 슬롯이 고쳤습니다).

## 읽을 것 (이것만)

- `tests/browser_monitor_ui.py` 전부 (지금 검사 15개, `monitor_server()` 틀과 `changed_ui_scenario`)
- `tools/aimem_monitor/static/app.js` 의 `renderRequests` · `renderGraphs` · `openArchivePanel` **만**

**읽지 마십시오:** `AIMEM.md`, `tools/aimem_monitor/*.py`, `projects/**`

## 규칙 - 화면 검사는 **실제로 그려진 것**을 묻습니다

`hidden`/`display` 는 `is_visible()`, 색은 `getComputedStyle`, 자리·겹침·잘림은 `bounding_box()`.
속성만 보고 통과시키지 마십시오. 요소끼리 겹치지 않는지, 폰 폭(390px)에서 화면 밖으로 안 나가는지도 보십시오.

## 할 것 1 - 지금 빨간 검사를 고치십시오 (하지만 **느슨하게 하지 마십시오**)

지금 `분담 전 요청의 ETA가 '미정'이다` 검사(248~290행)가 **운영 저장소의 지금 요청 상태**를 읽습니다.
그래서 요청이 늘고 줄 때마다 통과·실패가 바뀝니다(지금 15개 중 14개 통과 - `IN-PROGRESS` 인데
서브태스크가 0건인 요청에 걸렸습니다).

**임시 저장소로 바꾸십시오.** `monitor_server()` 를 고쳐 `root` 를 받게 하고,
이 검사만 **고정된 요청 네 건**(`NEW` · `PLANNED` · `IN-PROGRESS` · `DONE`, 모두 서브태스크 0건)을
담은 임시 폴더로 서버를 띄워 재십시오. 임시 폴더는 `tempfile.TemporaryDirectory()` 로 만들고
`.aimem/requests/*.json` 네 개를 직접 쓰면 됩니다(`aimem_db` 를 쓰지 않아도 화면은 그 파일을 읽습니다 -
안 보이면 `python3 tools/aimem_db.py migrate` 가 아니라 **서버가 무엇을 읽는지** 확인하십시오).
**다른 검사들은 지금처럼 운영 저장소로 두십시오** - 이 하나만 옮깁니다.

바뀐 화면에 맞춰 기대값도 고칩니다: 닫힌 요청에는 `.eta` 도 `.req-progress` 도 **없어야** 합니다.

## 할 것 2 - 새 검사 여섯

요청 트리 탭(`#tab-requests`)에서, 운영 저장소 화면으로 잽니다.

1. **요청 트리에서도 정리할 수 있다** - `#requests-tools` 가 `is_visible()` 이고 그 안의 단추가 보이며,
   글에 `끝난 요청` 과 숫자가 들어 있다. 단추를 누르면 패널이 열리고 제목에 `끝난 것 정리` 가 있다
2. **패널이 새 종류를 설명한다** - 열린 패널 안에 `실행 기록` · `이벤트` · `핸드오프` 글이 보이고
   (`is_visible()`), 미리보기 결과 줄에 `실행 기록` 과 `이벤트` 건수가 보인다.
   **패널에서 '실행' 을 누르지 마십시오** - 운영 저장소가 실제로 정리됩니다. 미리보기까지만 봅니다
3. **끝난 것이 접혀 있다** - 처음 열었을 때 `.closed-fold` 가 보이고, 그 아래로 닫힌 요청(`DONE`·`REJECTED`)
   블록이 **하나도 `is_visible()` 이 아니다**
4. **펼치면 보이고, 5초 뒤에도 그대로다** - `.closed-fold` 를 누르면 닫힌 요청 블록이 보인다.
   `page.wait_for_timeout(6000)` 뒤에도 여전히 보인다 (5초 폴링이 다시 그려도 접히지 않아야 합니다)
5. **DONE 요청에 100%·ETA 가 없다** - 닫힌 요청 블록 안에 `.req-progress` 도 `.eta` 도 없고,
   글자에 `100%` 도 `서브태스크 없이 끝난 요청입니다` 도 없다. 대신 `.req-done-line` 이 보인다
6. **겹치지 않고 밖으로 안 나간다** - `#requests-tools` 의 `bounding_box()` 가
   `#requests-list` 첫 블록과 **세로로 겹치지 않고**, 폰 폭 390px 로 줄였을 때
   `document.documentElement.scrollWidth - window.innerWidth == 0` 이다

## 주의

- **제품(`tools/**`)을 고치지 마십시오.** 검사가 결함을 찾으면 고치지 말고
  첫 줄을 `NEEDS-FIX: <무엇이 어디서>` 로 보고하십시오 - 뒤의 노드가 고칩니다
- 브라우저는 `chromium` 만 씁니다 (파이어폭스는 설치돼 있지 않습니다)
- 운영 모니터(18799 포트)를 부르지 마십시오. 검사는 임시 포트에 직접 띄운 서버만 씁니다

## 검증

```bash
python3 tests/browser_monitor_ui.py
```

마지막 줄이 `통과 N / 전체 N` 이고 **둘이 같아야** 하며 `전체` 가 **21 이상**이어야 합니다 (지금 15).

## 보고

첫 줄은 `DONE` / `PARTIAL` / `BLOCKED` / `NEEDS-FIX: …` 중 하나만. 그 아래 네 줄 안쪽으로
더한 검사와 마지막 `통과 N / 전체 N` 줄.
