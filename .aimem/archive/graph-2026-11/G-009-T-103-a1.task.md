# T-103 웹워들 고친 결과 다시 검수

## 할 일 (둘 다)

같은 라운드에 결함 여덟 개를 고쳤습니다. **고쳐졌는지 적대적으로 다시 보고**, 되돌아오지 않게
회귀 테스트를 더하십시오.

쓸 수 있는 파일은 `projects/웹워들/tests/smoke_integration.mjs` 하나입니다.
**다른 파일은 모두 다른 슬롯 소유이니 고치지 마십시오 - 찾은 것은 보고만 하십시오.**

### 1. 회귀 테스트를 더합니다 (기존 테스트는 그대로 두고 덧붙이기)

`web/js/game.js` 의 `fromJSON` 이 손상된 저장값을 막는지:

- `maxGuesses: 99` 가 6 으로 잡히는지
- `answer` 가 다섯 글자가 아니면 예외
- `rows` 의 한 줄이 모양에 안 맞으면 예외
- `rows.length` 가 `maxGuesses` 를 넘으면 예외
- 저장된 `status` 가 틀려도(`rows` 는 이긴 판인데 `status:"playing"`) 되살린 판이 `won` 인지
- `current` 에 이상한 글자가 들어 있으면 `""` 가 되는지

### 2. 고친 자리를 다시 봅니다 (읽기만)

아래가 **정말로** 고쳐졌는지 해당 파일을 읽어 확인하고, 안 됐거나 고치다 새로 생긴 문제를 보고하십시오.

1. `ui.js` - 새 판을 시작할 때 알림 영역(`#toasts`)을 비우는가
2. `storage.js` - `recordResult(won, guessCount, dayKey)` 가 `lastDay` 로 끊긴 연승을 다시 시작하는가.
   **예전 저장값(`lastDay` 없음)에서 연승이 멋대로 깎이지 않는가.** `ui.js` 가 세 번째 인자를 넘기는가
3. `style.css` - 칸과 키보드의 글자색이 배경에 맞게 바뀌었고, 테마를 갈아끼울 때 함께 바뀌는가.
   아래 열 가지 조합이 그대로 들어갔는가: `#6aaa64`+`#121213`, `#c9b458`+`#121213`, `#6b6f71`+`#ffffff`,
   `#538d4e`+`#121213`, `#b59f3b`+`#121213`, `#3a3a3c`+`#ffffff`, `#f5793a`+`#121213`,
   `#85c0f9`+`#121213`, `#d3d6da`+`#121213`, `#565758`+`#ffffff`
4. `style.css` - `dvh` 를 모르는 브라우저용 대비 선언이 있고 빼는 값이 `280px` 인가
5. `ui.js` - 마우스로 누른 화면 키에 포커스가 남지 않으면서, `Tab` 으로 오는 포커스와 그 테두리는 살아 있는가
6. `ui.js` - 이어받은 빈 판에 설정의 하드 모드가 반영되는가
7. 고치는 과정에서 계약이 깨지지 않았는가 - `ui.js` 가 부르는 `game.js`/`storage.js` 함수가 모두 있는가
