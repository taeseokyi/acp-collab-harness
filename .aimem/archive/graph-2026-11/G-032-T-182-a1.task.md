# T-182 `/api/archive` 계약을 **새 파일**에 못박으십시오

새로 만들 파일은 **`tests/test_archive_api.py` 하나**입니다. 다른 파일은 만들지도 고치지도 마십시오
(`tools/**` 금지 - 제품은 다른 슬롯이 썼습니다).

## 읽을 것 (이것만)

- `tests/test_aimem_monitor_slots.py` 의 1~37행(임시 저장소 `setUp` 틀)과 157~172행(`ArchiveActionTest`)
  - **그 틀을 그대로 베껴 새 파일에 씁니다.** 그 파일 자체는 고치지 마십시오
- `tools/aimem_monitor/server.py` 의 `archive_action` **만**

**읽지 마십시오:** `AIMEM.md`, `static/**`, `projects/**`, `tools/aimem_db.py` 의 나머지

## 무엇이 새로 생겼나

`archive_action(payload, by, root)` 의 응답이 이렇게 늘었습니다.

- 미리보기(`dry_run: True`): `body["plan"]["records"] = {"runs", "events", "handoff", "relay", "log_lines"}`
  (모두 **정수**), `body["plan"]["total_records"]` (정수)
- 실행: `body["moved_counts"]` - 종류별 **정수**(목록이 아님). `body["moved"]` 는 전처럼 원본
- 403(운영 저장소 아님) · 400(`days` 가 정수가 아니거나 범위 밖) 은 **그대로**

## 더할 검사 (여섯 개)

1. 미리보기에 `records` 다섯 키가 모두 있고 전부 `int` 다 (`bool` 은 안 됩니다)
2. **딸린 실행·이벤트가 셈에 든다** - 임시 저장소에 `DONE` 태스크 하나와 그 실행 파일,
   그 태스크를 가리키는 이벤트 하나를 두면 `records["runs"] >= 1` 이고 `records["events"] >= 1` 이다
3. 미리보기는 **아무것도 바꾸지 않는다** - 실행 파일도 요청 파일도 그대로 있다
4. 실행하면 `moved_counts` 가 돌아오고 그 값이 **전부 목록이 아니라 수**다
5. `days` 가 `"x"` · `True` · `-1` · `4000` 이면 400 이다
6. `root` 가 운영 저장소가 아니면 403 이고, 그때 **아무것도 옮겨지지 않았다**

## 주의

- 시각은 고정 문자열(`"2026-01-01T00:00:00"`)로 두고 `days=0` 을 쓰십시오
- `setUp` 에서 `aimem_db.ROOT`·`DB`·`AIMEM`·`HANDOFF` 와 `server.ROOT` 를 **모두** 임시 폴더로 바꿔야 합니다.
  하나라도 빠지면 **운영 저장소를 건드립니다** - 그러면 안 됩니다
- `aimem_db.cmd_init()` 의 표준출력은 `contextlib.redirect_stdout` 으로 막으십시오
  (`python3 -m unittest … | tail -3` 의 마지막 줄이 `OK` 여야 합니다)
- **제품을 고치지 마십시오.** 검사가 결함을 찾으면 고치지 말고 첫 줄을 `NEEDS-FIX: <무엇이 어디서>` 로 보고하십시오
- 파일은 **160줄 안쪽**
