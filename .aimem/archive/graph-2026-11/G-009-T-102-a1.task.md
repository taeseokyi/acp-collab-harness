# T-102 웹워들 `fromJSON` 이 저장된 값을 너무 믿습니다 (검수 5번)

## 배경

적대적 검수에서 나온 결함입니다. `projects/웹워들/web/js/game.js` **한 파일**만 고치십시오
(다른 파일은 다른 슬롯이 같은 라운드에 고치고 있습니다).

> `game.js:131~132, 232` - `fromJSON` 이 저장된 `maxGuesses` 를 그대로 믿습니다. `localStorage` 에
> 7 이상이 들어 있으면 보드에 여섯 줄밖에 없는데도 일곱 번째 제출을 받아, 화면 쪽 `tiles[6][c]` 에서
> TypeError 가 납니다. 같은 파일 203행 주석이 약속한 "손상된 저장값 방어" 에서 빠진 구멍입니다.

`localStorage` 는 사용자가 직접 고칠 수 있는 곳이니, 거기서 온 값은 **외부 입력으로 다루어야 합니다.**

## 고칠 것 - `fromJSON(data, options)` 이 저장값을 검사하게

- `maxGuesses`: 정수로 바꾸고 `1` 이상 `MAX_GUESSES`(6) 이하가 아니면 `MAX_GUESSES` 로 둡니다
- `answer`: 소문자 다섯 글자가 아니면 예외를 던집니다 (되살릴 수 없는 판입니다)
- `rows`: 배열이 아니면 빈 배열로. 각 줄은 `{guess, scores}` 모양이고 `guess` 가 다섯 글자,
  `scores` 가 `"correct"|"present"|"absent"` 다섯 개여야 합니다. 어긋나는 줄이 있으면 예외를 던지십시오
  (반쯤 맞는 판을 억지로 되살리는 것보다 새 판을 주는 쪽이 낫습니다)
- `rows.length` 가 `maxGuesses` 를 넘으면 예외
- `current`: 문자열이 아니거나 `a~z` 가 아닌 글자가 섞였으면 `""`, 다섯 글자를 넘으면 잘라냅니다
- `status`: **저장된 값을 믿지 말고 `rows` 와 `answer` 에서 다시 계산하십시오**
  (마지막 줄이 전부 `correct` 면 `won`, 줄이 `maxGuesses` 만큼 찼으면 `lost`, 아니면 `playing`)
- `hardMode` 는 참/거짓으로 맞춥니다

**계약은 그대로입니다** - 내보내는 이름, 인자, 돌려주는 모양을 바꾸지 마십시오. 화면 쪽이 이미 쓰고 있습니다.
예외를 던질 때는 왜 거절했는지 한국어 메시지로 밝히십시오. 다른 함수는 건드리지 마십시오.

## 검증 (이 명령이 통과해야 합니다)

```bash
node --test projects/웹워들/tests/*.mjs && node --input-type=module -e "import('./projects/웹워들/web/js/game.js').then(m=>{const ok={answer:'crane',rows:[],current:'',status:'playing',hardMode:false,puzzleNumber:1,maxGuesses:99};const g=m.fromJSON(ok,{allowed:['crane']});if(g.toJSON().maxGuesses>6)throw new Error('maxGuesses 안 막힘: '+g.toJSON().maxGuesses);let threw=0;for(const bad of [{...ok,answer:'xx'},{...ok,rows:[{guess:'abc',scores:['correct']}]},{...ok,maxGuesses:1,rows:[{guess:'slate',scores:['absent','absent','absent','absent','absent']},{guess:'slate',scores:['absent','absent','absent','absent','absent']}]}]){try{m.fromJSON(bad,{allowed:['crane']})}catch(e){threw++}}if(threw!==3)throw new Error('거절했어야 할 저장값 '+(3-threw)+'건을 받았습니다');const w=m.fromJSON({...ok,status:'playing',rows:[{guess:'crane',scores:['correct','correct','correct','correct','correct']}]},{allowed:['crane']});if(w.status!=='won')throw new Error('status 다시 계산 안 함: '+w.status);console.log('ok')})"
```
