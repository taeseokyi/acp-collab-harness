## 할 일
`tools/aimem_board.py` 는 `AIMEM.md` 의 **3절 보드 표를 직접 고치는** CLI 입니다. 그 표가 곧 `AIMEM.md` 에서 사라지므로 지금 그대로 두면 조용히 망가집니다. **`tools/aimem_db.py` 에 위임하도록 바꾸십시오.**

`board-set` 류 **쓰기 명령**과, 린터가 빌려 쓰는 **헬퍼**(`SEP_RE` / `VALID_STATUSES` / `_col_index` 같은 것)가 한 파일에 섞여 있습니다. 어느 쪽인지 위 `grep` 으로 실제 확인하고 시작하십시오.

## 기대 동작
1. **쓰기 경로를 DB 로 돌리십시오.** 보드 상태를 바꾸는 하위명령은 `AIMEM.md` 를 고치는 대신 `aimem_db` 를 import 해 `cmd_task` 와 같은 일(= `tasks` 테이블 upsert + `events` 기록)을 하게 하십시오. `aimem_db.py` 를 **고치지는 마십시오**(관리자 소유) - import 해서 쓰기만 합니다. 서브프로세스로 `python3 tools/aimem_db.py task set ...` 을 부르는 방식도 괜찮습니다. 더 단순한 쪽을 고르고 **왜 그쪽인지 보고에 한 줄** 적으십시오.
2. **읽기 명령**(보드 출력 등)도 DB 를 읽게 하십시오.
3. **다른 모듈이 빌려 쓰는 헬퍼는 남기십시오.** 위 `grep` 으로 `tools/aimem_lint.py` 나 테스트가 `aimem_board` 에서 import 하는 이름이 있으면 **그 이름은 지우지 말고 그대로 두십시오.** 지우면 린터가 죽습니다.
4. 모듈 docstring 맨 위에 **"2단계(REV 114~): 보드의 정본은 `.aimem/aimem.db` 다. 이 파일은 `AIMEM.md` 를 더 이상 쓰지 않는다"** 를 한 줄 적으십시오.
5. 폐기하는 쪽이 낫다고 판단되면(= 아무도 안 쓰고 헬퍼도 안 빌려 간다면) **파일을 지우지 말고** 각 하위명령이 "이 명령은 폐기됐습니다. `python3 tools/aimem_db.py task set` 을 쓰십시오" 를 찍고 rc 2 로 끝나게 하십시오. **삭제는 하드리밋입니다 - 하지 마십시오.**
