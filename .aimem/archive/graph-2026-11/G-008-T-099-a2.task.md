## 파일 뼈대

```js
import { test } from "node:test";
import assert from "node:assert/strict";
import { scoreGuess, keyboardState, hardModeViolation, createGame, fromJSON,
         dailyIndex, answerForDate, WORD_LENGTH, MAX_GUESSES } from "../web/js/game.js";
```

## 넣을 테스트 (이대로)

1. `WORD_LENGTH === 5`, `MAX_GUESSES === 6`

2. `scoreGuess(추측, 정답)` - `assert.deepEqual` 로 배열 비교

   | 정답 | 추측 | 기대 |
   | ---- | ---- | ---- |
   | crane | crane | `["correct","correct","correct","correct","correct"]` |
   | crane | nanny | `["absent","present","absent","correct","absent"]` |
   | abbey | bebop | `["present","present","correct","absent","absent"]` |
   | abide | eerie | `["absent","absent","absent","present","correct"]` |
   | sassy | stars | `["correct","absent","present","absent","present"]` |

3. `keyboardState`
   - `[{guess:"abbey", scores:["present","absent","absent","absent","absent"]}]` → `a` 가 `"present"`
   - 위에 `{guess:"about", scores:["correct","absent","absent","absent","absent"]}` 를 더하면 `a` 가 `"correct"`
   - 순서를 바꿔 correct 가 먼저 오고 present 가 나중에 와도 `a` 는 `"correct"` (색은 내려가지 않습니다)
   - 한 번도 안 나온 글자 `z` 는 결과에 키가 없음 (`assert.equal(state.z, undefined)`)

4. `hardModeViolation(추측, rows)` - `rows = [{guess:"crane", scores:["correct","absent","absent","absent","present"]}]`
   - `hardModeViolation("chess", rows)` → `null` (c 가 1번째에 그대로 있고 e 가 들어 있음)
   - `hardModeViolation("blown", rows)` → 문자열이고 `/C/` 에 걸림 (`assert.match`)
   - `hardModeViolation("crank", rows)` → 문자열이고 `/E/` 에 걸림

5. 판 진행 - `const g = createGame({answer:"crane", allowed:["crane","slate","audio","ghost"]})`
   - 글자를 세 개 넣고 `submit()` → `{ok:false, reason:"short"}`
   - `current` 를 비우고 `zzzzz` 를 넣어 `submit()` → `{ok:false, reason:"unknown"}`
     (글자를 지울 때는 `removeLetter()` 를 여러 번 부르십시오)
   - `slate` 를 넣어 `submit()` → `ok:true`, `status === "playing"`, `rows.length === 1`, `current === ""`
   - `crane` 를 넣어 `submit()` → `ok:true`, `status === "won"`
   - 이긴 뒤 또 `submit()` 하면 `{ok:false, reason:"over"}`

6. 지는 판 - `createGame({answer:"crane", allowed:["ghost"]})` 에 `ghost` 를 여섯 번 제출 →
   마지막에 `status === "lost"`, `rows.length === 6`

7. `shareText()` - 5번의 이긴 판에서
   - 첫 줄이 `웹워들` 로 시작하고 `2/6` 을 담고 있음
   - 줄 수가 `2 + rows.length` (제목 줄, 빈 줄, 줄마다 한 줄)
   - 마지막 줄이 `"🟩🟩🟩🟩🟩"`

8. 저장과 복원 - 5번처럼 두 줄 둔 판에서
   `const back = fromJSON(g.toJSON(), {allowed:["crane","slate","audio","ghost"]})` →
   `back.rows.length`, `back.status`, `back.answer` 가 원래 판과 같음

9. 날짜 - `const d = new Date(2026, 5, 1)`
   - `dailyIndex(d)` 가 정수이고 `dailyIndex(new Date(2026,5,2)) === dailyIndex(d) + 1`
   - `answerForDate(d, ANS)` 를 두 번 불러 같은 값이 나옴 (`ANS` 는 테스트 안에 쓴
     `["crane","slate","audio","ghost","pound"]`)
   - `answerForDate` 의 결과가 `ANS` 안에 있음
