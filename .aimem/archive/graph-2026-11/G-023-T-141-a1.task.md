## 왜

이 검사는 1280×900 한 폭에서만 돕니다. 그래서 **폰 폭(390px)에서 미리보기 높이 규칙이 죽어도
전부 초록**입니다(실제로 R10 에 그 결함이 있었고, 고친 뒤에도 검사는 그것을 못 봅니다).

## 무엇을 더하는가

지금 있는 `scenario(browser, base, checks)` 는 **건드리지 말고**, 그 아래에 함수 하나를 새로 만들어
`main()` 에서 `scenario(...)` 다음에 부르십시오.

```python
def narrow_scenario(browser, base, checks):
    """폰 폭(390x844)에서 미리보기가 좁은 화면 규칙대로 그려지는가."""
    ctx = browser.new_context(viewport={"width": 390, "height": 844})
    page = ctx.new_page()
    try:
        page.goto(base + "/", wait_until="load")
        page.wait_for_selector("#projects-list .proj-item", timeout=15000)
        project = page.locator("#projects-list .proj-item").filter(has_text="웹워들").first
        project.locator(".proj-run").first.click()
        page.wait_for_selector("iframe.proj-app-frame", state="visible", timeout=15000)
        iframe = page.locator("iframe.proj-app-frame").first
        box = iframe.bounding_box()
        ...
    finally:
        ctx.close()
```

`checks.ok(목표, 조건, 자세히)` 로 **세 가지**를 적으십시오. 셋 다 `bounding_box()` 로 잰 **그려진
값**으로 판정합니다 - 속성·클래스·CSS 문자열로 판정하지 마십시오.

1. `"폰 폭에서 미리보기 높이가 좁은 화면 규칙을 따른다"` - `box["height"]` 가
   `min(0.70 * 844, 640) = 590.8` 과 **2px 안쪽**으로 같은가. (기본 규칙이 이기면 658 이 나옵니다.)
2. `"폰 폭에서 패널 밖으로 잘리지 않는다"` - 이 파일에 이미 있는 `contains(inner, outer)` 를 그대로
   써서 iframe 상자가 `#detail-body` 상자 안에 있는가.
3. `"폰 폭에서 가로 스크롤이 생기지 않는다"` -
   `page.evaluate("document.documentElement.scrollWidth - window.innerWidth")` 가 1 이하인가.
   잰 값을 `자세히` 에 그대로 적으십시오.

`main()` 안은 이렇게 됩니다.

```python
                    scenario(browser, base, checks)
                    narrow_scenario(browser, base, checks)
```
