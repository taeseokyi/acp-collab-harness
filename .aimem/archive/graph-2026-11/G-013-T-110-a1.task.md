## 결함 1 - `hidden` 이 먹지 않아 공유 단추가 판 내내 보입니다

`ui.js` 는 `$('btn-share').hidden = !(game && game.status !== 'playing')` 로 **옳게** 숨깁니다.
그런데 `style.css:253` 의

```css
.primary { display: block; ... }
```

이 브라우저 기본 규칙 `[hidden] { display: none }` 을 **이깁니다**(둘 다 요소 하나를 가리키지만
작성자 규칙이 기본 규칙보다 셉니다). 그래서 `hidden` 속성이 붙어 있는데도 화면에 그대로 보입니다.

관리자 실측: 판을 하나도 안 둔 상태에서 통계 창을 열면
`hidden` 속성 있음 · `is_visible() == True` · 상자 104×45. 모달에는 `.modal[hidden] { display: none }`
(203행)이 있는데 단추에는 그런 것이 없습니다.

→ **`hidden` 속성이 붙은 요소는 어떤 것이든 화면에 보이지 않게** 하십시오.
   `.modal[hidden]` 이 지금처럼 계속 동작해야 하고, 판이 끝나면 공유 단추는 다시 보여야 합니다.

## 결함 2 - 낮은 창(900×420)에서 키보드 아래쪽이 창 밖으로 잘립니다

`ENTER` 가 있는 마지막 줄이 화면 아래로 넘어가 보이지도 눌리지도 않습니다.

관리자 실측 (900×420): `#keyboard` 상자가 `y=315, height=186` → **아래끝 501 > 창높이 420**.
`#board` 는 `y=66, width=200, height=241`.

원인 (확인했습니다):

- `.board` (86~94행) 의 `width: min(350px, 100%, calc((100dvh - 280px) * 5 / 6))` 는 창이 낮으면
  보드를 줄이도록 되어 있습니다. 420px 높이면 `(420-280)*5/6 ≈ 117px` 이 나와야 하는데,
  바로 아래 **`min-width: 200px` 이 그 축소를 막아** 200px 로 붙들립니다
- `.key` (149~152행) 의 `height: 54px` 은 고정이라 창이 낮아도 줄지 않습니다 (3줄 × 54px + 여백 = 186px)

→ 낮은 창에서 **보드와 키보드가 모두 창 안에 들어오게** 하십시오. 두 값이 낮은 창에서 양보하도록
   고치면 됩니다(`min-width` 를 낮은 창에서 풀거나 `min()` 안으로 넣기, 키 높이를 창 높이에 따라
   줄이기 등 - 방법은 맡깁니다). 제약:

- **360×640 과 420×900 에서 지금 모습이 나빠지면 안 됩니다** (지금 둘 다 통과합니다)
- 타일은 네모를 유지해야 합니다(가로세로 비 0.7~1.4)
- 키 높이는 어떤 크기에서도 **20px 이상**이어야 합니다

## 결함 3 - 토스트가 보드 첫 줄을 가립니다

`.toasts` (168~172행) 가 `position: fixed; top: 70px` 인데 머리글이 50px 이고 보드가 그 바로 아래
(`y≈66`) 에서 시작해서, 토스트가 **첫 줄 타일 위에 겹쳐 앉습니다.**

관리자 실측 (420×900, 진 판): 토스트 `정답: BRICK` 의 상자가 `top=70, bottom=109`,
가린 타일 = 첫 줄의 2·3·4번째 칸 (`A`, `R`, `O`). 이김 토스트(`천재!`)도 같은 자리에 뜨는데
2초 뒤 사라집니다. **진 판의 정답 토스트는 `ms=0` 이라 영영 사라지지 않아** 첫 추측이 계속 가려집니다.

→ **토스트가 `#board .tile` 중 어느 것과도 겹치지 않게** 하십시오.
   보드와 키보드 사이에 빈 자리가 꽤 있습니다(420×900 에서 보드 아래끝 ≈ 427, 키보드 위끝 ≈ 700).
   토스트는 계속 **가운데 정렬**이고 **클릭을 가로채지 않아야**(`pointer-events: none`) 하며,
   창이 열렸을 때 창보다 아래에 깔리면 안 됩니다. 420×900 · 360×640 · 900×420 **세 크기 모두**에서
   겹치지 않아야 합니다.

`#toasts` 는 `#app` 바깥에 있습니다 - **그 자리를 옮기지 마십시오**(창이 열리면 `#app` 에만
`inert` 가 붙어야 하므로 일부러 밖에 둔 것입니다). CSS 로만 해결하십시오.
