# T-211 적대적 검수 - 이번 라운드의 감사·티켓 변경이 무엇을 깨뜨렸는가

쓸 파일은 **`rounds/R16/REVIEW-ticket-url.md`** 하나입니다. **제품도 시험도 고치지 마십시오.**

## 무엇을 검수하는가

이 라운드가 `tools/aimem_monitor/server.py` 를 두 번 고쳤습니다.

1. **T-206** - 거절마다 감사 한 줄(`app-ticket-bad` · `session-bad` · `token-bad` · `github-revoked`),
   억제 키를 `(event, subject, path, method)` 로 (ip 를 뺌)
2. **T-207** - 티켓 URL 의 `gh:<로그인>` 을 **되돌릴 수 없는 태그 12자리**로 바꾸고,
   요청마다 허용 목록으로 후보를 만들어 태그를 되푸는 `app_ticket_resolve`

**T-212** (후속) - `_APP_RE` 의 이름 칸이 `~` 로 시작하지 못하게 해, 상한 160 을 넘는 티켓 칸이
프로젝트 이름으로 넘어가던 것을 막았습니다 (T-210 이 `NEEDS-FIX` 로 찾음).

그리고 시험 둘을 더했습니다: `tests/browser_monitor_auth.py`(T-208), `tests/test_monitor_ticket_regress.py`(T-210).

## 꼭 물을 것 (앞 라운드가 이 질문을 빠뜨려 운영이 깨졌습니다)

**"이 수정이 실제 브라우저에서 무엇을 깨뜨리는가."** R15 에서 같은 자리의 수정이 CSP `sandbox` 의
불투명 출처 때문에 인증 모드에서 앱의 js·css 를 전부 403 으로 만들었고, 단위 시험은 전부 초록이었습니다.
이번에도 **브라우저로 직접 재십시오**: `python3 tests/browser_monitor_auth.py`.

그 밖에 적어도 이것들을 보십시오.

- **회수가 정말 즉시 듣는가.** 태그를 후보 목록으로 되푸는 길이 생겼으니,
  목록 파일을 못 읽거나(권한·없음) 빈 줄·주석만 있을 때 **열려 버리는 길**이 없는지
- **후보 열거의 값.** 허용 목록이 아주 길 때(1,000줄) 요청마다 HMAC 1,000번이면 무엇이 되는가.
  **타이밍으로 로그인 존재 여부가 새는가** (`compare_digest` 를 썼는가, 이른 반환이 있는가)
- **태그 12자리(48비트)가 충분한가.** 충돌하면 무엇이 되는가 - 다른 주체로 풀리는가,
  풀린 뒤 mac 검사가 막는가
- **감사가 새 공격면이 아닌가.** 억제 키에 **경로**가 들어갔으니 경로를 조금씩 바꾸면
  억제를 피해 `.aimem/access.log` 를 불릴 수 있는가. 상한 256 은 어떻게 도는가.
  감사 줄에 티켓·토큰·쿠키가 새지 않는가
- **`session-bad`·`token-bad` 가 폴링으로 로그를 불리지 않는가** (쿠키가 있지만 만료된 창을 열어 두면?)
- **새 시험들이 거짓 초록이 아닌가.** 제품에 변이를 넣어(사본에서) 정말 빨개지는지 확인하십시오

## 변이 시험은 **사본에서**

```
cp -a . /tmp/r16rev && rm -rf /tmp/r16rev/.aimem/tls /tmp/r16rev/.git
```

`.aimem/tls/` 를 **빼고** 복사하고, 임시 토큰을 쓰십시오. 운영 서버를 `curl` 로 부르지 마십시오(401).
끝나면 **`rm -rf /tmp/r16rev`** 로 지우십시오 (자기가 만든 `/tmp` 폴더입니다).

## 쓸 것

`rounds/R16/REVIEW-ticket-url.md` 에:

- 맨 위 **결론 요약 다섯 줄 안쪽** (높음/중간/낮음/정보 건수와 제일 급한 것 한 줄)
- 결함마다: 번호(`D1`…) · 등급 · **재현 절차(그대로 따라 하면 나오는)** · 무엇이 잘못됐는지 · 고칠 방향
- 변이 표: 넣은 변이, 빨개진 시험 수, **0개면 그것이 시험 구멍**
- 브라우저 실측 결과 한 줄 (`통과 N / 전체 N`)

결함이 없으면 **없다고 쓰십시오.** 억지로 만들지 마십시오. 다만 "변이를 넣었는데 아무것도 안 빨개진 것"
은 반드시 적으십시오.
