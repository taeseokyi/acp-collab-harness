# T-112 `browser_core.py` 에 "토스트가 타일을 가리지 않는다" 검사 더하기

## 고칠 파일 (이 하나뿐입니다)

`projects/웹워들/tests/browser_core.py` - **검사를 더하기만** 합니다.
이미 있는 44개 검사는 **하나도 건드리지 마십시오.** 앱(`web/` 아래)도 건드리지 마십시오.

## 왜 필요한가

브라우저 검사가 44개 모두 초록인데도, 사람이 스크린샷을 보니 **토스트가 보드 첫 줄 위에 겹쳐
앉아 글자를 가리고 있었습니다.** 특히 진 판의 `정답: XXXXX` 토스트는 사라지지 않아 첫 추측이
영영 가려졌습니다. 겹침을 아무도 검사하지 않아서 놓친 것입니다. 그 구멍을 막습니다.

(겹침 자체는 T-110 이 CSS 에서 고치고 있습니다. 당신은 **다시는 그렇게 되지 않도록 검사를 남깁니다.**)

## 더할 검사

이미 있는 **"판 끝 - 지는 판"** 시나리오 안, 정답 공개 토스트가 뜬 뒤에 넣으십시오
(새 시나리오를 만들어도 됩니다). 목표 이름은 `"판 끝"` 을 쓰십시오.

쪽 안에서 사각형을 재어 겹치는 타일이 있는지 봅니다:

```python
JS_OVERLAP = (
    "() => {"
    "  const t = document.querySelector('#toasts .toast');"
    "  if (!t) return null;"
    "  const tr = t.getBoundingClientRect();"
    "  const hit = [];"
    "  document.querySelectorAll('#board .tile').forEach((el, i) => {"
    "    const r = el.getBoundingClientRect();"
    "    if (tr.left < r.right && tr.right > r.left && tr.top < r.bottom && tr.bottom > r.top)"
    "      hit.push(i);"
    "  });"
    "  return { text: t.textContent, hit: hit };"
    "}"
)
overlap = page.evaluate(JS_OVERLAP)
```

- 토스트가 **있어야** 합니다 (`overlap is not None`) - 없으면 그것부터 실패입니다
- `overlap["hit"]` 이 **빈 목록**이어야 합니다. 실패하면 가려진 타일 번호와 토스트 글을
  `detail` 에 그대로 찍으십시오 (예: `토스트='정답: BRICK' 가린 타일=[1, 2, 3]`)

**이김 토스트에 대해서도** 같은 검사를 하십시오 - 이기는 판 시나리오에서 `천재!` 류 토스트가
떠 있는 동안(사라지기 전) 같은 방법으로 재어 겹치는 타일이 없어야 합니다.

## 하지 말 것

- 검사를 조건부로 만들거나(`if ... else pass`) `try/except` 로 삼키지 마십시오
- 이미 있는 44개 검사의 문구·조건·순서를 바꾸지 마십시오
- 통과시키려고 CSS 나 다른 파일을 고치지 마십시오

## 검증 (이 명령이 rc 0 이어야 합니다)


마지막 줄이 `통과 N / 전체 N` (실패 0, 그리고 **N 은 44보다 커야** 합니다 - 검사를 더했으니까).
