# T-173 당신이 쓴 검사 하나가 틀렸습니다 - 조건을 좁히십시오

고칠 파일은 **`tests/browser_monitor_ui.py` 하나**입니다. 다른 파일은 고치지 마십시오.

## 무엇이 틀렸나

`KISTI 카드가 화면에 없다` 검사가 지금 빨갛습니다. 실측값:

```
[FAIL] KISTI 카드가 화면에 없다 - #kisti-section=None, page.content()의 KISTI=28회
```

`#kisti-section` 은 **실제로 없습니다**(카드는 제대로 지워졌습니다). 빨간 이유는
`page.content()` 에 `KISTI` 가 28번 나오기 때문인데, 그것은 **이번 라운드 작업 기록 행의 제목**입니다
(`server.py·reader.py: KISTI 상태 폴링·준비 점검·aimem.goal 제거` 같은 태스크 이름).
즉 검사가 **카드가 아니라 글자**를 보고 있습니다.

## 어떻게 고치나

`page.content()` 전체를 보는 조건을 버리고, **KISTI 카드라는 것이 화면에 없다**를 직접 재십시오.
셋 다 만족해야 합니다.

1. `page.query_selector('#kisti-section')` 가 `None`
2. `page.query_selector('#kisti-card')` 가 `None`
3. 함대 탭의 **카드 제목(`h2`)** 가운데 `KISTI` 로 시작하는 것이 하나도 없다 -
   `page.eval_on_selector_all('.card h2', 'els => els.map(e => e.textContent.trim())')` 로 제목만
   모아서 확인하십시오

상세에는 **실제로 모은 `h2` 제목 목록**과 두 selector 의 결과를 적으십시오.

**이 검사 하나만 고치십시오.** 나머지 열네 개는 손대지 마십시오.

## 검증

```bash
python3 tests/browser_monitor_ui.py
```

`통과 15 / 전체 15` 여야 합니다.

`통과 n / 전체 m` 줄을 그대로 옮기십시오.
