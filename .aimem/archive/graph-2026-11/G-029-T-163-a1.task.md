# T-163 모니터: 미리보기 칸에 '그 프로젝트 몫 보관함' 을 빌려 주기

고칠 파일은 **`tools/aimem_monitor/static/app.js` 하나**입니다. 다른 파일은 고치지 마십시오
(`server.py`·`index.html`·`style.css`·`tests/**` 는 다른 태스크 몫입니다).

## 먼저 읽을 것 - 설계가 정본입니다

`projects/웹워들/docs/preview-storage.md` 의 **2절(48~85행)·3절(86~177행)** 을 읽으십시오.
거기 적힌 메시지 꼴·검사 순서·상한이 **그대로 구현해야 할 규약**입니다. 그 밖의 절(1·4~9절)은
읽지 않아도 됩니다. 설계와 이 브리프가 어긋나면 **설계가 맞습니다.**

`app.js` 에서 볼 곳은 세 군데뿐입니다.

- `closeDetail()` - 352행 근처
- `openPanel(title, build)` - 383행 근처
- `openProjectApp(pr)` - 2843~2869행

`app.js` 의 나머지 3,200줄은 읽지 마십시오.

## 1. 패널 닫힘 훅 (설계 3.1)

지금 `closeDetail()` 은 오버레이를 **숨기기만** 해서 `openProjectApp` 이 만든 iframe 이 DOM 에
붙은 채 계속 돕니다. 정리할 자리를 만듭니다.

- `state` 객체에 `panelCleanups: []` 를 더합니다 (`state` 선언을 찾아 한 줄 더하면 됩니다)
- 새 함수

  ```js
  function runPanelCleanups() {
    const fns = state.panelCleanups;
    state.panelCleanups = [];            // 먼저 비운다 - 다시 불려도 두 번 돌지 않게
    for (const f of fns) { try { f(); } catch { /* 하나가 던져도 나머지는 돈다 */ } }
  }
  ```

- `openPanel` 의 **첫 줄**과 `closeDetail` 의 **첫 줄**에서 `runPanelCleanups()` 를 부릅니다.
  Esc·바깥 클릭은 모두 `closeDetail` 을 지나므로 따로 걸 것이 없습니다

## 2. `openProjectApp` 안에 보관함 리스너 (설계 3절)

`fr` 을 만든 **뒤, `body.appendChild(fr)` 전에** 겁니다. 설계 3절의 코드 골자를 그대로 따르되,
`loadPart`·`putIfFits`·`flushPut`·`okKey`·`okVal`·`rate` 는 **당신이 이 파일 안에 함수로** 씁니다.

- 보관함 키: `const part = 'aimem.app.v1.' + encodeURIComponent(name);`
  (`name` 은 이미 있는 지역 변수 `pr.name` 입니다 - **메시지에서 읽지 마십시오**)
- `loadPart(part)` → `Map`. `localStorage.getItem` + `JSON.parse` 를 `try/catch` 로 감싸고,
  평범한 객체가 아니면 빈 `Map`. `okKey`·`okVal` 을 지난 항목만 `Map` 에 넣습니다.
  `in` / `dict[key]` / `hasOwnProperty` 를 쓰지 말고 `Map` 의 `has`/`get`/`set`/`delete`/`size` 만 쓰십시오
- `okKey(k)` : `typeof k === 'string' && /^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$/.test(k)`
- `okVal(v)` : `v === null || (typeof v === 'string' && v.length <= 8192)`
- 리스너 (설계 3절 그대로, 첫 줄 세 조건을 **모두** 두십시오)

  ```js
  function onMsg(ev) {
    const src = ev.source;
    if (!src || src !== fr.contentWindow || !fr.isConnected) return;
    if (ev.origin !== 'null') return;
    const m = ev.data;
    if (!m || typeof m !== 'object' || Array.isArray(m) || m.aimem !== 'store.v1') return;
    if (m.op === 'ready' && rate.ready()) {
      src.postMessage({ aimem: 'store.v1', op: 'snapshot', items: Object.fromEntries(dict) }, '*');
    } else if (m.op === 'put' && rate.put() && okKey(m.key) && okVal(m.value)) {
      putIfFits(dict, m.key, m.value);
    }
  }
  window.addEventListener('message', onMsg);
  ```

- `rate` : 패널마다 새로 만드는 작은 계수기. `ready()` 는 **패널 수명당 2번까지**이고
  두 번째는 첫 번째로부터 **1초 뒤부터**. `put()` 은 **최근 1초 창에 20개까지**. 넘으면 `false`
- `putIfFits(dict, key, value)` : `value === null` 이면 `dict.delete(key)`, 아니면 `dict.set(key, value)`.
  반영한 뒤 `JSON.stringify(Object.fromEntries(dict))` 의 **길이가 65,536 을 넘거나** `dict.size > 64` 면
  **되돌리고 버립니다.** 반영됐으면 250ms 묶음 타이머를 걸어 `flushPart` 를 한 번 부릅니다
- `flushPart(part, dict)` : `localStorage.setItem(part, JSON.stringify(Object.fromEntries(dict)))` 를
  `try/catch` 로 감싸고, 실패하면 **그 쓰기만 버리고** `console.warn` 한 줄 뒤 계속합니다
- 정리 등록

  ```js
  state.panelCleanups.push(() => {
    window.removeEventListener('message', onMsg);
    clearTimeout(timer);
    flushPart(part, dict);
    fr.remove();
  });
  ```

## 3. 안내 문구 한 줄 (2849행 근처)

지금 이렇게 적혀 있습니다.

```
격리된 칸에서 돌아갑니다 - 기록(통계·설정)은 저장되지 않습니다
```

이제 저장되므로 **`격리된 칸에서 돌아갑니다 - 기록(통계·설정)은 이 브라우저에만 남습니다`** 로 바꾸십시오.
바로 아래 '새 탭에서 열기' 의 `tab.title` 에 있는 `기록은 저장되지 않습니다` 도 같은 뜻으로 고치십시오
(새 탭은 부모가 없어 여전히 안 남으므로 `새 탭에서는 기록이 남지 않습니다` 로).

## 4. 절대 하지 말 것

- `sandbox` 속성이나 CSP 를 **건드리지 마십시오** - `allow-same-origin` 을 넣으면 격리가 무의미해집니다
- 메시지 내용을 `fetch`·`eval`·`location`·URL·DOM 에 **닿게 하지 마십시오.** 보관함은
  `localStorage` 안의 **사전 한 칸의 필드**일 뿐이고, 메시지의 `key` 가 `localStorage` 키가 되면 안 됩니다
- 받은 값을 화면에 그리지 마십시오
- 프로젝트 이름을 메시지에서 읽지 마십시오
