# T-147 웹워들 `ui.js` 의 작은 결함 하나를 고치십시오

**고칠 파일은 `projects/웹워들/web/js/ui.js` 하나뿐입니다.** 다른 파일은 열지 마십시오.
이 파일에서 **고칠 자리는 세 군데, 모두 합쳐 다섯 줄 안쪽**입니다. 새 함수를 만들지 마십시오.

## 무엇이 잘못됐나

글자를 칠 때 칸에 `pop` class 가 붙어 0.1초 커졌다 돌아옵니다. 떼는 일은 `animationend`
리스너가 합니다(74행 근처):

```js
      t.addEventListener('animationend', () => t.classList.remove('pop', 'bounce'));
```

그런데 제출하면 같은 칸에 `flip` class 가 붙습니다(222행 근처). CSS 에서 `.tile.flip` 규칙이
`.tile.pop` 보다 뒤에 있어 `flip` 이 이깁니다 - **`pop` 애니메이션이 중간에 끊기고
`animationend` 는 영영 오지 않아 `pop` class 가 칸에 남습니다.** 0.5초 뒤 `flip` class 를
떼는 순간 남아 있던 `pop` 규칙이 다시 살아나 **칸이 한 번 더 커졌다 돌아옵니다.**

## 고치는 법 - 세 군데

**(1) `animationcancel` 에도 떼기.** 74행 근처의 그 줄을 두 줄로 바꿉니다:

```js
      const dropAnim = () => t.classList.remove('pop', 'bounce');
      t.addEventListener('animationend', dropAnim);
      t.addEventListener('animationcancel', dropAnim);
```

**(2) `flip` 을 붙이기 전에 `pop`·`bounce` 를 떼기.** 222행 근처의

```js
      t.classList.add('flip');
```

를

```js
      t.classList.remove('pop', 'bounce');
      t.classList.add('flip');
```

로.

**(3) `flip` 을 뗄 때 `pop` 도 함께 떼기.** 224행 근처의

```js
      setTimeout(() => t.classList.remove('flip'), FLIP_TIME);
```

를

```js
      setTimeout(() => t.classList.remove('flip', 'pop'), FLIP_TIME);
```

로.

그 밖에는 **한 줄도 바꾸지 마십시오.** 바꾼 뒤 `node --check projects/웹워들/web/js/ui.js` 가 조용해야 합니다.

보고 첫 줄은 `DONE` 또는 `BLOCKED - <이유>` 입니다.
