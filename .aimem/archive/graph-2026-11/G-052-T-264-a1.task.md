## 보탤 시험

### N3 회귀 (가장 중요) - `is_error: true` + 구조 표지 없음 → **`None`**
- `{"is_error": true, "result": "You've hit your 5-hour limit · resets 11:20am"}` (harness claude)
  → `run_limit_signal` 이 **`None`** (예전엔 `False` 였습니다)
- 같은 기록으로 `step()` 을 태워 노드가 **`blocked` + `limit` 참**이 되는지 (= 글자 판정이 살아 있다)
- `{"is_error": false, ...}` → `False` 는 그대로

### M3 - `is_error` 검사가 살아 있는가
- `{"is_error": false, "api_error_status": 429, "terminal_reason": "api_error", "result": "limit"}`
  → **`False`** (`is_error` 를 안 보면 `True` 가 됩니다)

### M4 - `terminal_reason == "api_error"` 갈래
- 이 갈래만 타는 기록(429 도 `api_error` 칸도 없고 `terminal_reason: "api_error"` +
  `result` 에 한도 문구) → **`True`**
- **반례(N4):** `{"is_error": true, "terminal_reason": "api_error",
  "result": "Prompt exceeds the context window limit"}` → **`None`**
  (`"limit"` 부분 일치가 사라졌으니 표지 없음 → `None`)

### M5 - `step()` 단에서 N3 을 막기
위 N3 기록으로 `rc != 0` 실행을 꾸며 `step()` 을 돌리고 노드가 `limit` 으로 `blocked` 되는지

### M6 - `harness == "claude"` 검사가 살아 있는가
지금 codex 시험의 `.out` 은 JSON 이 아니라서 검사를 지워도 통과합니다.
**codex·opencode 시험의 `.out` 을 claude 꼴 JSON**
(`{"is_error": true, "api_error_status": 429}`)으로 바꾸고 그래도 **`None`** 인지 보십시오.

### M7 - 1 MiB 읽기 상한
`.out` 을 **1 MiB + 넉넉히** 넘게 만들되 앞머리에 `{"is_error": true, "api_error_status": 429` 가
오게 하고(뒤는 공백이나 더미로 채워 JSON 이 잘리게) → **`None`**

### M8 - 로그의 출처 표시
`step()` 이 구조 신호로 막았을 때 그래프 로그에 **`(구조 신호)`**,
보고 글자로 막았을 때 **`(보고 글자)`** 가 들어 있는지 각각 `assertIn`

### N5·N7 (`report_limit_hit` / `run_id`)
- `report_limit_hit("NEEDS-FIX: verify step time limit reached, test failed")` → **`False`**
- `report_limit_hit("DONE - added handler for HTTP 429 Too Many Requests")` → **`False`**
- `report_limit_hit("You've hit your weekly limit")` → **`True`**
- `run_limit_signal("../outside/evil")` → **`None`** (`runs/` 밖에 `evil.json`·`evil.out` 을
  진짜로 두고도 `None` 이어야 합니다). `run_id` 가 `str` 이 아닐 때도 `None`
