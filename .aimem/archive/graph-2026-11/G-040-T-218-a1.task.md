# T-218 '끝난 것 정리' 미리보기가 15초 넘게 걸리는 원인을 고치십시오

고칠 파일은 **`tools/aimem_db.py` 하나**입니다. 시험 파일은 손대지 마십시오(다른 슬롯이 씁니다).

## 증상 (관리자가 실측함)

```
$ time python3 tools/aimem_db.py archive --dry-run
archive: 14일 지난 끝난 것 없음 (기준 2026-10-29T11:54:35)
real	0m15.599s
```

아무것도 안 옮기는 미리보기가 15.6초 걸립니다. 웹의 '끝난 것 정리…' 미리보기가 그 사이 멈춘 것처럼 보이고,
브라우저 검사 `tests/browser_monitor_ui.py` 의 '패널이 새 종류를 설명한다' 가 15초 시간 초과로 **실패합니다**.

프로파일: 전체 17초 중 **13.7초가 `re.escape` 안의 `str.translate`** 이고, `_mentions` 가 281,373번 불립니다.
`_mentions(body, ident)` 의 `ident` 중 123개가 **길이 5,000~8,000자**였습니다. 그 내용은 식별자가 아니라
**작업자 브리프 본문 전체**(`# T-098 웹워들 화면 …` 같은 글)였습니다.

## 원인

`tools/aimem_db.py` 의 `archive_plan()` 안, 아직 안 끝난 그래프를 지키는 자리입니다(`if not archived:` 가지):

```python
            if not archived:
                protected_ids.add(gid)
                for n in nodes:
                    for key in (n.get("id"), n.get("task")):
                        if isinstance(key, str) and key:
                            protected_ids.add(key)
```

노드의 `task` 칸은 **입력 파일 이름일 수도, 지시 본문 전체일 수도** 있습니다. 바로 위쪽 `archived` 가지는
이미 그것을 알고 꼴 검사를 걸어 두었습니다(`re.fullmatch(r"[A-Za-z0-9][A-Za-z0-9._-]{0,79}", key)` 가
아니면 건너뜀 - 그 자리의 주석에 `File name too long` 으로 죽었던 이야기가 적혀 있습니다). **이 가지에만
그 검사가 빠져 있습니다.**

그래서 본문 수천 자가 통째로 `protected_ids` 에 들어가고, 아래쪽 이벤트 걸러내기가
`any(_mentions(body, ident) for ident in protected_ids)` 를 이벤트마다 돌면서 그 긴 글을 `re.escape` 합니다.
느릴 뿐 아니라 **그런 '식별자' 는 어떤 이벤트 본문과도 맞지 않아 지키는 일도 못 합니다.**

## 고칠 내용

1. 파일 맨 위쪽(다른 상수들 옆)에 식별자 꼴을 한 곳에 못박는 상수를 두십시오. 이름은
   `_ARCHIVE_ID_RE` 로 하고 값은 위 `archived` 가지가 쓰던 것과 **같은 꼴**
   (`re.compile(r"[A-Za-z0-9][A-Za-z0-9._-]{0,79}")`) 로 하십시오.
2. `archived` 가지의 `re.fullmatch(r"[A-Za-z0-9][A-Za-z0-9._-]{0,79}", key)` 를
   `_ARCHIVE_ID_RE.fullmatch(key)` 로 바꾸십시오 (동작은 그대로).
3. `if not archived:` 가지의 안쪽을 아래로 바꾸십시오.

```python
            if not archived:
                protected_ids.add(gid)
                for n in nodes:
                    for key in (n.get("id"), n.get("task")):
                        # `task` 는 **지시 본문 전체**일 수도 있다. 본문을 식별자로 넣으면 아래 `_mentions`
                        # 가 이벤트마다 수천 자를 `re.escape` 해 미리보기가 15초 걸렸고(2026-11-12 실측),
                        # 어차피 어떤 본문과도 맞지 않아 지키지도 못한다. 식별자 꼴일 때만 넣는다.
                        if isinstance(key, str) and _ARCHIVE_ID_RE.fullmatch(key):
                            protected_ids.add(key)
```

4. 같은 함수 안에서 `protected_ids` 에 넣는 **다른 자리들도 한 번씩 보십시오.** 큐에서 긁어 오는 자리
   (`re.findall(r"\b(?:T-\d+|Q-\d{6}-[0-9a-f]{4}|G-\d+)\b", …)`)와 `run_id` 들은 이미 짧은 꼴이라
   그대로 두면 됩니다. **안전망으로**, 이벤트를 거르기 직전에 한 줄을 넣어 긴 것이 끼어도 터지지 않게
   하십시오:

```python
    protected_ids = {i for i in protected_ids if isinstance(i, str) and _ARCHIVE_ID_RE.fullmatch(i)}
```

   이 줄은 `plan["tasks"] = [r for r in plan["tasks"] if r["id"] not in protected_ids]` **앞**에 두십시오.
