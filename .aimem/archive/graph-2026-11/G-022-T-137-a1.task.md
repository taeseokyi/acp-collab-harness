# T-137 적대적 검수 B - TLS·프록시 Host·좁은 화면·그리고 **검사가 진짜 빨개지는가**

## 쓸 수 있는 파일 (이 하나뿐입니다)

`rounds/R11/REVIEW-B.md` (새로 만듭니다)

## 무엇을 검수하는가

R10 이 모니터에 넣은 **프로젝트 결과물 실행**(`/app/<이름>/`, 경로 티켓, sandbox)의 네 구석입니다.
같은 라운드의 다른 슬롯(T-136)이 **티켓 인가와 격리**를 때리고 있으니 그쪽은 건드리지 마십시오.
당신 몫은 아래 넷입니다.

### 1. TLS 모드 (`tls=True`)
운영은 https 로 돌고, 바깥에서는 **윈도우 통과 프록시(0.0.0.0:18800 → 127.0.0.1:18799)** 를 거쳐
들어옵니다. 즉 서버가 보는 `Host` 헤더의 포트는 18800 이고, 서버는 18799 를 듣고 있습니다.

- 티켓 302 의 `Location` 이 https 로 맞는가, 포트가 바뀐 Host 에서도 맞는가 (지금 코드는 경로만
  돌려주는 것으로 보입니다 - 그렇다면 그 사실을 확인해 적으십시오)
- `app_csp(origin)` 에 들어가는 출처(`_app_origin()`, server.py 2387행)가 TLS 에서 `https://...`
  인가. `Host: 192.168.0.5:18800` 으로 보냈을 때도 그 이름·포트가 그대로 들어가는가
- 세션 쿠키의 `Secure`·`SameSite`·`HttpOnly` 가 TLS 에서 붙는가
- 프록시를 **실제로 흉내 내십시오**: `/tmp/t137/` 에 TCP 통과 프록시를 하나 띄우고
  (`socketserver` + `socket` 20줄이면 됩니다. TLS 는 통과만 하면 되니 바이트를 그대로 중계합니다)
  브라우저가 프록시 포트로 접속해 미리보기가 뜨는지까지 봅니다. 자체 서명 인증서는
  `openssl req -x509 -newkey ec -pkeyopt ec_paramgen_curve:prime256v1 -nodes -days 2 \
   -subj "/CN=127.0.0.1" -addext "subjectAltName=IP:127.0.0.1" -keyout key.pem -out crt.pem`
  로 `/tmp/t137/` 에 만들고, playwright 는 `pw.chromium.launch()` + `browser.new_context(
  ignore_https_errors=True)` 로 띄웁니다. 서버는 `ssl.SSLContext` 로 소켓을 감싸고
  핸들러에 `"tls": True` 를 줍니다
- **https 와 http 를 섞어 보십시오**: TLS 서버에 평문으로 보내면 어떻게 되는가

### 2. 좁은 화면 (폭 720px 이하)
R10 검수 결함 4 는 "`@media (max-width: 720px)` 의 `.proj-app-frame` 높이 규칙이 뒤에 오는 기본
규칙에 덮여 죽어 있다" 였고, 고침은 **규칙 순서를 바꾼 것**입니다
(`tools/aimem_monitor/static/style.css` 1329행 기본, 1334행 미디어 쿼리). 캐스케이드만 보면
고쳐진 것처럼 보이지만 **브라우저로 잰 사람이 아직 없습니다.**

- 390×844(폰), 720×900(경계), 1280×900(기준) 세 폭에서 '실행' 을 눌러 미리보기를 띄우고
  **`bounding_box()` 로 실제로 재십시오**
- 속성·클래스·CSS 텍스트로 판정하지 마십시오. `is_visible()`, `getComputedStyle`,
  `bounding_box()` 로 **그려진 것**을 봅니다
- 물어볼 것: 미리보기 iframe 이 패널 밖으로 잘리는가(iframe 아래 끝 vs 패널 스크롤 영역 아래 끝),
  요소끼리 겹치는가('새 탭에서 열기' 링크·메타 줄·iframe), 가로 스크롤이 생기는가
  (`document.documentElement.scrollWidth > innerWidth`), 결과물 안의 키보드 맨 아랫줄이 보이는가
- '새 탭에서 열기'(static/app.js 2693~2699행)를 **실제로 눌러** 새 탭이 뜨고 그 안에 보드가
  그려지는지 보십시오(인증 켠 서버에서)

### 3. 서비스 워커
`tools/aimem_monitor/static/sw.js` 가 `/app/` 을 캐시하지 않고 지나치는지, 버전이 올라갔는지
**브라우저에서** 확인하십시오(코드만 읽지 말고 - R10 은 코드로만 봤습니다). 서비스 워커가 등록된
컨텍스트에서 미리보기를 띄우고, 티켓 응답이 캐시에서 오는지 봅니다
(`caches.keys()`, `performance.getEntriesByType('resource')` 의 `transferSize`).

### 4. 검사가 진짜 빨개지는가 (변이 시험)
이 라운드가 "초록이다" 라고 말할 근거가 검사입니다. 그 검사가 **아무것도 지키지 않고 있을지도**
모릅니다. **저장소 사본에서** 제품을 일부러 깨뜨리고, 검사가 빨개지는지 봅니다.

```bash
mkdir -p /tmp/t137 && cp -a /home/tsyi/work/ai-fleet /tmp/t137/mut && rm -rf /tmp/t137/mut/.git
```

사본에서 다음 변이를 **하나씩** 넣고(넣고 → 검사 돌리고 → 원본 바이트로 되돌리고 → 다음),
`python3 -m unittest discover -s tests -p 'test_aimem_monitor*'` 와
`python3 tests/browser_monitor_app.py`, `python3 tests/browser_monitor_auth.py`,
`python3 tests/browser_monitor_ui.py` 중 **무엇이 빨개지는지** 적으십시오.

| 변이 | 무엇을 묻는가 |
|---|---|
| `app_ticket_ok` 가 언제나 `True` | 티켓 검사를 지켜 주는 검사가 하나라도 있는가 |
| `app_ticket_ok` 에서 만료 검사(`exp < now`)만 제거 | 만료를 지키는 검사가 있는가 |
| `app_ticket_ok` 에서 이름을 서명 대상에서 빼기(`f"app.v1.{exp}"`) | 프로젝트 교차 재사용을 막는 검사 |
| `_auth_gate` 의 `/app/~` 면제를 `/app/` 전체 면제로 넓히기 | 인증 우회를 잡는 검사가 있는가 |
| `/app/` 200 응답에서 `Access-Control-Allow-Origin: null` 제거 | 미리보기가 죽는 것을 잡는 검사 |
| `app_csp` 에서 `sandbox` 지시어 제거 | 새 탭 격리를 지키는 검사 |
| `fr.setAttribute('sandbox', …)` 줄 삭제 (static/app.js 2707행) | iframe 격리를 지키는 검사 |

**빨개지지 않는 변이가 결함입니다** - "검사 구멍 N: <무슨 변이가 초록으로 지나간다>" 로 적고,
어떤 파일에 어떤 검사를 더해야 메워지는지 한 줄로 적으십시오. 검사를 **고치지는 마십시오**
(다음 태스크의 일입니다). 끝나면 `rm -rf /tmp/t137/mut` 로 사본을 지웁니다.

주의: `tests/browser_monitor_auth.py` 는 **이 라운드에서 다른 슬롯이 동시에 고치고 있습니다.**
사본에서 돌린 결과만 적고, 작업 트리의 그 파일은 읽기만 하십시오.

## 어떻게 돌리는가 (인증 켠 http 서버 본보기 - TLS 는 여기에 ssl 을 얹으십시오)

```python
# 임시 루트에 모니터를 띄우는 본보기 (관리자가 실제로 돌려 확인한 코드입니다)
import http.server, pathlib, shutil, sys, tempfile, threading
ROOT = pathlib.Path("/home/tsyi/work/ai-fleet")
sys.path.insert(0, str(ROOT / "tools"))
from aimem_monitor import server

tmp = pathlib.Path(tempfile.mkdtemp())
(tmp / ".aimem").mkdir()
shutil.copy(ROOT / ".aimem/aimem.db", tmp / ".aimem/aimem.db")   # 프로젝트 목록이 비지 않게
shutil.copy(ROOT / "AIMEM.md", tmp / "AIMEM.md")
(tmp / "projects/웹워들").mkdir(parents=True)
shutil.copy(ROOT / "projects/웹워들/app.json", tmp / "projects/웹워들/app.json")
shutil.copytree(ROOT / "projects/웹워들/web", tmp / "projects/웹워들/web")

TOKEN = "a" * 64
H = type("H", (server.Handler,), {"root": tmp, "require_auth": True, "tls": False,
                                  "access_token": TOKEN, "guard": server.LoginGuard(),
                                  "timeout": 5, "log_message": lambda *a, **k: None})
httpd = http.server.ThreadingHTTPServer(("127.0.0.1", 0), H)
httpd.daemon_threads = True
threading.Thread(target=httpd.serve_forever, daemon=True).start()
base = f"http://127.0.0.1:{httpd.server_address[1]}"
```
