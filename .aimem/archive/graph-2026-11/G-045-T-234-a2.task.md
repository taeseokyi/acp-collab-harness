## 왜

유료 슬롯(관리자·S1·S4)이 **한 계정의 Claude 사용 한도**를 같이 씁니다. R16 라운드가 5시간 한도에

### 화면 계약 (이 이름 그대로 - 브라우저 검사가 이 선택자를 씁니다)

`index.html` 의 `#panel-fleet` **맨 위**, `#fleet-section` **앞**에:

```html
<section class="card" id="usage-section">
  <h2>Claude 사용 한도 <span class="hint" id="usage-stale"></span></h2>
  <div id="claude-usage" class="claude-usage"></div>
</section>
```

`app.js` 에 `renderClaudeUsage(data)` 를 만들고, `renderFleetControl(data)` 를 부르는 **두 자리**
(1113행 근처와 3469행 근처)에서 바로 뒤에 같이 부릅니다.

- `data.claude_usage` 가 **없거나 `null`** → `#claude-usage` 안에 `<p class="empty">` 하나,
  글은 `상태줄 명령을 등록하면 보입니다`. `#usage-stale` 은 빈 글
- 있으면 `rows` 마다 하나씩:

```html
<div class="usage-row usage-ok" data-key="five_hour">
  <span class="usage-label">5시간</span>
  <span class="usage-bar"><span class="usage-fill"></span></span>
  <span class="usage-pct">42%</span>
  <span class="usage-reset">초기화 18:00</span>
</div>
```

- `.usage-row` 의 둘째 클래스: `percent < 80` → `usage-ok`, `80 <= percent < 95` → `usage-warn`,
  `percent >= 95` → `usage-crit`
- `.usage-fill` 의 `style.width` 는 `percent` 를 퍼센트로 (`42.4` → `width: 42.4%`). **0% 여도 칸은
  보입니다** (`.usage-bar` 가 테두리를 가짐)
- `.usage-pct` 글: `Math.round(percent) + '%'`
- `.usage-reset` 글: `resets_at_iso` 가 **오늘이면** `초기화 HH:MM`, 오늘이 아니면 `초기화 M/D HH:MM`.
  `resets_at_iso` 가 `null` 이면 **`.usage-reset` 요소를 아예 만들지 않습니다**
- `#usage-stale`: `age_seconds` 가 **600 을 넘으면** `N분 전 기준`(분은 내림, 60분 넘으면 `N시간 전 기준`),
  아니면 빈 글

### `style.css`
- `.usage-row` 는 한 줄에 라벨·막대·퍼센트·초기화가 **나란히**(flex), 좁은 화면(390px)에서도 **서로
  겹치지 않고** 카드 밖으로 **넘치지 않습니다**
- `.usage-ok .usage-fill` / `.usage-warn .usage-fill` / `.usage-crit .usage-fill` 의
  `background-color` 는 **셋이 서로 다릅니다** (평상 / 주의 / 경고). 이미 있는 변수
  (`--ok`·`--warn`·`--danger` 류)를 쓰십시오 - 없으면 `style.css` 위쪽 변수 선언을 보고 맞추십시오.
  밝은 테마·어두운 테마 양쪽에서 읽혀야 합니다
- `.usage-pct` 는 고정폭 숫자(`font-variant-numeric: tabular-nums`)
