# T-228 프로젝트 탭 분리로 깨진 브라우저 검사 셋을 고치십시오

고칠 파일은 **하나**입니다. (`browser_monitor_auth.py` 와 `browser_monitor_preview_guard.py` 는 **다른 슬롯이 맡습니다 - 건드리지 마십시오**.) 제품 코드(`tools/aimem_monitor/**`)는 **읽기만 하고 절대 고치지 마십시오.**

- `tests/browser_monitor_preview.py`

## 무엇이 깨졌나 (관리자가 실측함)

이번 라운드에 **프로젝트 카드가 함대 탭에서 빠져 별도 탭(`#tab-projects` / `#panel-projects`)으로**
옮겨졌습니다. 처음 화면은 **함대 탭**이고 다른 패널은 `hidden` 입니다. 그래서 첫 화면에서
`#projects-list` 를 기다리는 검사들이 전부 시간 초과로 죽습니다.

```
tests/browser_monitor_auth.py           통과 4 / 전체 10   (locator resolved to hidden <article class="proj-item">)
tests/browser_monitor_preview.py        통과 0 / 전체 5
tests/browser_monitor_preview_guard.py  통과 0 / 전체 1
```

같은 저장소의 `tests/browser_monitor_ui.py` 는 이미 고쳐졌습니다 - **그 파일이 하는 그대로** 하면 됩니다:
`#projects-list` 를 건드리기 **직전에** `page.click("#tab-projects")` 를 한 줄 넣습니다
(`browser_monitor_ui.py` 의 74·155·195행 근처를 보십시오).

## 고칠 자리 (이것뿐입니다)

| 파일 | 줄 | 지금 |
|---|---|---|
| `browser_monitor_auth.py` | 110 근처 | `page.wait_for_selector("#projects-list .proj-item", timeout=10000)` |
| `browser_monitor_auth.py` | 221 근처 | `page.wait_for_selector("#projects-list .proj-item", timeout=10000)` |
| `browser_monitor_preview.py` | 109 근처 | `page.wait_for_selector("#projects-list", timeout=10000)` |
| `browser_monitor_preview_guard.py` | 131 근처 | `page.wait_for_selector("#projects-list .proj-run", timeout=10000)` |

각 자리 **바로 위**에 한 줄씩 넣으십시오.

```python
        page.click("#tab-projects")      # 프로젝트가 별도 탭이 됐다 (2026-11-12)
```

그 페이지에서 이미 다른 탭을 눌렀거나 `goto` 직후라면 그대로 넣으면 됩니다. 클릭할 요소가 아직 없을 수
있으니 필요하면 **그 앞에** `page.wait_for_selector("#tab-projects", state="visible", timeout=10000)`
한 줄을 더 넣으십시오. `browser_monitor_preview.py` 는 66·68행에서도 `#projects-list` 를 쓰지만
109행 위에서 탭을 열어 두면 같은 페이지이므로 따로 더 넣을 것이 없습니다 - **돌려 보고 판단하십시오.**

## 하지 말 것

- 검사 내용·기대값을 바꾸지 마십시오. **탭을 여는 줄만** 더합니다
- 검사를 느슨하게 만들지 마십시오(`try/except` 로 삼키기, 타임아웃 늘리기, 확인 지우기)
- `tests/browser_monitor_ui.py` 와 `tests/browser_monitor_tabs.py` 는 건드리지 마십시오 (이미 맞습니다)
- 제품 코드를 고쳐 "프로젝트 카드를 함대 탭에도 두는" 식으로 되돌리지 마십시오

## 검증 (이 명령이 0 으로 끝나야 합니다 - 셋 다 **전부 통과**)

```bash
for f in browser_monitor_auth browser_monitor_preview browser_monitor_preview_guard; do python3 tests/$f.py > /tmp/t228-$f.txt 2>&1; done; python3 -c "
import pathlib,sys
ok=True
for f in ('browser_monitor_auth','browser_monitor_preview','browser_monitor_preview_guard'):
    p=pathlib.Path(f'/tmp/t228-{f}.txt').read_text().strip().splitlines()[-1].split()
    good = len(p)==5 and int(p[1])==int(p[4]) and int(p[4])>=1
    print(f, p[-4:], good)
    ok = ok and good
sys.exit(0 if ok else 1)"
```
