## 더할 검사 셋

지금 파일의 짜임새를 그대로 따라 하십시오(같은 헬퍼, 같은 `ok()` 호출, 같은 요약 줄).

**(1) 낮은 창에서 화면 키가 32px 이상이다**
뷰포트 **1000x500** 으로 열고 `#keyboard` 안의 키 하나(예: `.key` 첫 번째)의
`bounding_box()["height"]` 가 **>= 32** 인지 봅니다. 글자 하나를 친 뒤에도 다시 재서
여전히 >= 32 인지 봅니다. (검사 2개)

**(2) 가로로 넓고 낮은 창에서 보드와 키보드가 좌우로 놓인다**
뷰포트 **900x420** 으로 열고 `#board` 와 `#keyboard` 의 `bounding_box()` 를 잽니다.

- 키보드의 왼쪽 끝이 보드의 오른쪽 끝보다 오른쪽이다
  (`kb["x"] >= board["x"] + board["width"] - 1`)
- 두 상자가 세로로 겹친다 (같은 줄에 있다는 뜻:
  `kb["y"] < board["y"] + board["height"]` 이고 `board["y"] < kb["y"] + kb["height"]`)
- 둘 다 창 안에 있다 (`x >= 0`, `y >= 0`, `x + width <= 900 + 1`, `y + height <= 420 + 1`)
- 이 창에서 타일 하나의 `bounding_box()["width"]` 가 **>= 30** 이다
  (세로로 쌓였을 때는 18px 이었습니다)

(검사 4개 안쪽)

**(3) 뒤집기가 끝난 뒤 칸 크기가 원래대로 돌아온다**
기본 뷰포트에서 다섯 글자를 치고 Enter 를 누릅니다. **제출 전** 첫 칸의
`bounding_box()` 를 재 두고, 뒤집기가 모두 끝나기를 충분히 기다린 뒤
(`page.wait_for_timeout` 으로 2,500ms) **같은 칸을 다시 재서**

- 너비·높이가 제출 전과 **1px 안쪽으로 같다** (pop 이 남아 있으면 1.12배로 커 보입니다)
- `page.evaluate` 로 그 칸의 `classList` 를 읽어 **`pop` 이 들어 있지 않다**

(검사 2개)

낱말은 `browser_layout.py` 가 이미 쓰고 있는 방식(사전에 있는 다섯 글자)을 그대로 쓰십시오.
칸을 고르는 선택자도 파일에 이미 있는 것을 쓰십시오.
