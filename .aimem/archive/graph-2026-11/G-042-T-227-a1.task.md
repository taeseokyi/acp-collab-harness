# T-227 그래프 제목 펼치기 검사를 **임시 저장소**에서 돌게 고치십시오

고칠 파일은 **`tests/browser_monitor_ui.py` 하나**입니다. 제품 코드(`tools/aimem_monitor/**`)는
**읽기만 하고 절대 고치지 마십시오.**

## 무엇이 문제인가 (관리자가 실측함)

방금 더한 `graph_title_expand_scenario`(592행 근처)가 **진짜 저장소**를 보고 있습니다. 요청 트리의
태스크 그래프는 **끝난 그래프를 접어 둡니다.** 그래서 도는 그래프가 하나도 없는 순간(= 라운드가 끝난
뒤)에는 `#graphs-list .graph-title` 이 보이지 않고, 검사가 통째로

```
[FAIL] 그래프 제목 펼치기 - 그래프 없음
```

하나로 떨어집니다. 실제로 지금 그렇습니다(`통과 21 / 전체 23`). 다섯 개를 재야 할 검사가 **한 개**로
줄어들어 검사 수도 들쭉날쭉합니다.

## 고칠 내용

같은 파일의 `zero_subtask_scenario` 가 쓰는 본을 그대로 따르십시오 - **임시 저장소를 만들고
`monitor_server(root=temp_root)` 로 그 폴더를 읽는 서버를 띄우는** 방식입니다(`main()` 의 아래쪽,
`tempfile.TemporaryDirectory()` 블록을 보십시오).

1. **고정 그래프를 쓰는 도우미를 더하십시오.**

   ```python
   def write_fixed_graph(root):
       """제목이 아주 긴, 아직 끝나지 않은 그래프 하나를 임시 저장소에 씁니다."""
   ```

   - 쓸 곳은 `root / ".aimem" / "graph" / "G-FIXED.json"` 입니다
   - 내용은 `{"id": "G-FIXED", "request": "<아주 긴 한 줄 제목>", "created": …, "updated": …,
     "concurrency": 1, "nodes": [...]}` 꼴입니다. **지금 저장소의 `.aimem/graph/G-040.json` 을 열어
     칸 이름을 맞추십시오** (노드는 `id`·`slot`·`deps`·`status`·`title` 정도면 됩니다)
   - **노드 하나는 `status` 를 `running` 또는 `todo`** 로 두십시오. 끝난 그래프는 접히므로 제목이
     안 보입니다
   - `request` 제목은 **200자 이상**으로 길게 쓰십시오. 폰 폭 390px 에서 반드시 `...` 로 줄여지도록

2. `graph_title_expand_scenario` 의 서명을 바꾸지 말고(`browser, base, checks`), **`main()` 에서
   부르는 자리**를 임시 저장소 블록으로 옮기십시오.

   ```python
   with tempfile.TemporaryDirectory() as temp_dir:
       temp_root = pathlib.Path(temp_dir)
       write_fixed_graph(temp_root)
       with monitor_server(root=temp_root) as temp_base:
           graph_title_expand_scenario(browser, temp_base, checks)
   ```

   (기존 `write_fixed_requests` 블록과 **합쳐도 되고 따로 두어도 됩니다.** 합친다면 두 도우미를 모두
   부르십시오.)

3. `#graphs-list .graph-title` 을 못 찾았을 때의 `checks.ok("그래프 제목 펼치기", False, "그래프 없음")`
   **예외 갈래는 그대로 두십시오.** 이제는 정말로 깨졌을 때만 걸립니다.

4. 다섯 검사의 내용(처음엔 줄여져 있다 / 누르면 펼쳐진다 / 화면 밖으로 안 나간다 / 6초 뒤에도 펼친
   채다 / 다시 누르면 접힌다)은 **고치지 마십시오.** 보던 저장소만 바뀝니다.

## 하지 말 것

- 다른 시나리오를 고치지 마십시오
- 진짜 `.aimem/graph/` 에 파일을 쓰지 마십시오 - **임시 폴더에만** 씁니다
- 검사를 느슨하게 만들지 마십시오(`try/except` 로 삼키기, 확인 지우기)
