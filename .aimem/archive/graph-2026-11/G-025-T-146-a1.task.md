# T-146 웹워들 CSS 두 군데를 고치십시오

고칠 파일은 **`projects/웹워들/web/css/style.css` 하나뿐**입니다. 다른 파일은 열지도 마십시오.
(`web/js/**`, `tests/**` 는 다른 슬롯이 같은 시각에 고치고 있습니다.)

---

## 수정 1 - 화면 키가 20px 까지 쪼그라듭니다

지금 `.key` 의 높이 하한이 `20px` 입니다. 낮은 창(예: 1000x500)에서 키가 20px 가 돼
손가락으로 누를 수 없습니다. **하한을 32px 로 올립니다.** 네 줄입니다.

`.key { ... }` (160행 근처) 안의 두 줄:

```css
  height: clamp(20px, calc((100vh - 330px) / 3), 54px);
  height: clamp(20px, calc((100dvh - 330px) / 3), 54px);
```

를

```css
  height: clamp(32px, calc((100vh - 330px) / 3), 54px);
  height: clamp(32px, calc((100dvh - 330px) / 3), 54px);
```

로. 그리고 `@media (max-width: 400px)` (288행 근처) 안의 두 줄:

```css
    height: clamp(20px, calc((100vh - 330px) / 3), 50px);
    height: clamp(20px, calc((100dvh - 330px) / 3), 50px);
```

를 같은 방식으로 `clamp(32px, ..., 50px)` 으로. **`20px` 이 네 번 모두 `32px` 이 돼야 합니다.**

## 수정 2 - 가로로 넓고 낮은 창에서 보드와 키보드를 좌우로

지금은 창이 900x420 이어도 `#app` 이 `max-width: 500px` 세로 한 줄이라 보드 칸이 18px 까지
작아집니다. **가로로 넓고 낮은 창에서는 보드를 왼쪽, 키보드를 오른쪽에 둡니다.**

지금 구조(고치기 전에 알아 둘 것):

```css
#app { display: flex; flex-direction: column; height: 100%; max-width: 500px; margin: 0 auto; }
main { flex: 1; display: flex; flex-direction: column; justify-content: space-between;
       min-height: 0; padding: 8px 6px 8px; }
.board { display: grid; grid-template-rows: repeat(6, 1fr); gap: 5px;
         width: var(--board-width); margin: 8px auto; }
.keyboard { width: 100%; max-width: 500px; margin: 0 auto; }
```

`#app > .header` 다음에 `main` 이 오고, `main` 안에 `.board` 와 `.keyboard` 가 있습니다.

**파일 맨 끝의 `@media (prefers-reduced-motion: reduce)` 블록 바로 앞**에 아래 블록을
통째로 더하십시오(이미 있는 규칙은 하나도 지우지 마십시오):

```css
/* 가로로 넓고 낮은 창 - 보드와 키보드를 좌우로 놓습니다 (R12 항목 3).
   세로로 쌓으면 900x420 에서 칸이 18px 까지 작아집니다. */
@media (min-width: 760px) and (max-height: 560px) {
  :root {
    --board-width: min(350px, calc(45vw - 24px), calc((100vh - 90px) * 5 / 6));
  }
  #app { max-width: 1100px; }
  main {
    flex-direction: row;
    align-items: center;
    justify-content: center;
    gap: 24px;
    padding: 8px 12px;
  }
  .board { margin: 0; flex: none; }
  .keyboard { flex: 1 1 auto; max-width: 520px; min-width: 300px; margin: 0; }
  .key { height: clamp(32px, calc((100vh - 120px) / 3.6), 54px); }
}

@supports (height: 100dvh) {
  @media (min-width: 760px) and (max-height: 560px) {
    :root {
      --board-width: min(350px, calc(45vw - 24px), calc((100dvh - 90px) * 5 / 6));
    }
    .key { height: clamp(32px, calc((100dvh - 120px) / 3.6), 54px); }
  }
}
```

## 확인

바꾼 뒤 `.key` 선언 안에서 `20px` 이 하나도 남지 않았는지 보십시오:

```
grep -c "clamp(20px" projects/웹워들/web/css/style.css      # 0 이어야 합니다
grep -c "min-width: 760px" projects/웹워들/web/css/style.css  # 2 여야 합니다
```

보고 첫 줄은 `DONE` 또는 `BLOCKED - <이유>` 입니다.
