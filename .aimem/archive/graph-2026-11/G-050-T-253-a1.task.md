# T-253 한도 판정의 **구조 신호** (재검수 R19-P3)

쓸 파일은 **하나**입니다: `tools/fleet_graph.py`. `tests/**` 와 다른 `tools/**` 는 읽기만 하고
**절대 고치지 마십시오**(특히 `tools/fleet.py`). 계획을 세우지 말고 바로 고치십시오.

## 지금 어떻게 보나

`step()` (`:830` 근처) 이 `if rc != 0 and report_limit_hit(att["report"]):` 로 봅니다.
`report_limit_hit` (`:426`) 은 보고 본문 끝 2000자에서 `_LIMIT_PATTERNS` 의 **글자**를 찾습니다.
글자 판정은 `"You've hit your weekly limit"` 같은 형제 문구를 놓칩니다.

## 더 믿을 만한 신호

claude 하네스의 실행 기록 `.aimem/runs/<run_id>.out` 은 **JSON 한 덩이**이고 이런 칸이 있습니다
(실측 `.aimem/runs/T-248-S1-a1-170153.out`): `is_error`, `api_error_status`, `terminal_reason`,
`stop_reason`, `result`, `subtype`. 한도에 부딪힌 실행은 `is_error: true` 이고
`api_error_status: 429` · `api_error: "usage_limit_reached"` · `terminal_reason: "api_error"` 중
하나 이상을 답니다. codex·opencode 의 `.out` 은 그냥 글자라 **글자 판정이 그대로 남습니다.**

하네스는 `.aimem/runs/<run_id>.json` 의 `harness` 칸에 있습니다 (`fleet._run_meta(run_id)` 가 읽어 줍니다).

## 만들 것

### 1. `run_limit_signal(run_id)` - 새 함수

`report_limit_hit` 바로 아래에 두십시오. **이 이름과 이 인자 하나**여야 합니다.

```python
def run_limit_signal(run_id):
    """실행 기록의 구조 신호로 사용 한도를 봅니다. 모르면 None.

    claude 하네스만 JSON 을 남깁니다. True/False/None 셋을 돌려줍니다 -
    None 은 "구조 신호가 없다"(codex·opencode, 깨진 파일)이고 글자 판정으로 넘깁니다.
    """
```

- `fleet._run_meta(run_id)` 로 `harness` 를 읽고 `"claude"` 가 아니면 **`None`**
- `fleet.RUNS / f"{run_id}.out"` 을 **최대 1 MiB 까지만** 읽습니다. 없거나 못 읽으면 `None`
- `json.loads` 가 실패하거나 결과가 `dict` 가 아니면 `None`
- `dict` 면: `is_error` 가 참이고 아래 중 하나라도 맞으면 **`True`**
  - `api_error_status` 가 `429` (글자 `"429"` 도 같게 봅니다)
  - `api_error` 를 소문자로 했을 때 `"usage_limit"` 또는 `"rate_limit"` 가 들어 있음
  - `terminal_reason` 이 `"api_error"` 이고 `result`·`api_error`·`stop_reason` 어느 글자에든
    `report_limit_hit` 가 참이거나 `"limit"` 이 들어 있음
- `is_error` 가 참인데 위 어디에도 안 걸리면 **`False`** (JSON 은 읽혔는데 한도는 아니다)
- `is_error` 가 거짓이면 **`False`**
- **어떤 예외도 밖으로 내보내지 마십시오.** 파일이 어떻게 깨져 있어도 `None` 이어야 합니다
  (`json` 재귀 한계·유니코드·거대 파일 포함). `try/except Exception: return None` 로 감싸십시오

### 2. `step()` 의 판정 (`:830` 근처)

```python
        if rc != 0:
            sig = run_limit_signal(att["run_id"])
            limit = report_limit_hit(att["report"]) if sig is None else sig
        else:
            limit = False
        if limit:
            ...지금 그대로...
```

- **`rc != 0` 조건은 절대 풀지 마십시오.** R19 가 실측으로 넣은 것입니다(rc 0 의 멀쩡한 DONE 보고
  셋이 '사용 한도' 글자 때문에 막혔습니다)
- 구조 신호가 `False` 면 글자 판정을 **보지 않습니다** - 그게 이 수정의 핵심입니다
  (claude 실행은 JSON 이 진실이고, 보고 본문에 한도 얘기가 적혀 있어도 한도가 아닙니다)
- `_log` 줄에 어느 신호였는지 적으십시오: `limit {id} ({run_id}) - 사용 한도로 끊김 (구조 신호)` /
  `(보고 글자)`

### 3. `_LIMIT_PATTERNS` 에 형제 문구 넷 보태기

`"hit your weekly limit"`, `"hit your usage limit"`, `"limit reached"`, `"too many requests"`.
기존 항목은 **지우지 마십시오**.
