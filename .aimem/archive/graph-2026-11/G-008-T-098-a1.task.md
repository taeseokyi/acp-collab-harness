**공유 문구 형식** (`shareText()`):

```
웹워들 123 4/6

⬛🟨⬛⬛⬛
🟩⬛⬛🟨⬛
🟩🟩⬛⬛🟩
🟩🟩🟩🟩🟩
```

- 첫 줄 `웹워들 <puzzleNumber> <맞힌 횟수 또는 X>/<maxGuesses>`, 하드 모드면 끝에 `*`
- 둘째 줄은 빈 줄, 그 뒤에 줄마다 이모지 다섯 개
- correct `🟩` / present `🟨` / absent `⬛`

**겹치는 글자 판정** - 반드시 이 순서로 (워들의 핵심이고 틀리기 쉬운 곳입니다):

1. 먼저 자리가 같은 글자를 `correct` 로 하고, **정답에서 그 글자를 하나 뺍니다**
2. 그다음 남은 칸을 왼쪽부터 보며, 남은 정답 글자 중에 있으면 `present` 로 하고 **하나 뺍니다**.
   없으면 `absent`

| 정답 | 추측 | 결과 |
| ---- | ---- | ---- |
| crane | nanny | absent present absent correct absent |
| abbey | bebop | present present correct absent absent |
| abide | eerie | absent absent absent present correct |
| sassy | stars | correct absent present absent present |
| crane | crane | correct correct correct correct correct |

```js
export function loadStats()      // {played, wins, streak, maxStreak, dist:[0,0,0,0,0,0]}

```

- 키는 `webwordle.` 로 시작합니다. `dayKey` 는 `YYYY-MM-DD` (로컬 날짜)
- `localStorage` 가 막힌 브라우저에서도 **예외로 죽지 않게** `try/catch` 로 감싸고 메모리로 대신하십시오
- **import 되는 순간에는 `localStorage` 를 건드리지 마십시오** (함수 안에서만). node 로 구문을 검사하기 때문입니다
- `dist` 는 1~6번째 시도에 맞힌 횟수입니다. `streak` 는 진 판에서 0 으로

## 화면이 해야 할 일

1. **오늘의 판**: `answerForDate(new Date(), ANSWERS)` 가 정답, `dailyIndex(new Date())` 가 번호.
   `loadDaily(오늘)` 이 있으면 `fromJSON` 으로 이어서, 없으면 새 판. 날짜가 바뀌면 새 판
2. **보드**: 6줄 × 5칸. 입력 중인 글자가 보이고, 글자가 들어갈 때 칸이 살짝 커집니다
3. **키보드**: 화면 키보드(QWERTY 3줄 + `ENTER`/`⌫`) 와 물리 키보드(a~z, Enter, Backspace) 둘 다.
   화면 키보드는 진짜 `<button>` 으로 만드십시오
4. **제출**: 칸을 왼쪽부터 0.1초 간격으로 뒤집으며 색을 드러내고, 다 뒤집힌 뒤 키보드 색을 `keyboardState` 로 갱신
5. **거절**: `submit()` 이 `{ok:false}` 면 그 줄을 좌우로 흔들고 `message` 를 토스트로 띄웁니다
6. **끝**: 이기면 맞힌 줄이 통통 튀고, 지면 정답을 토스트로 보여 줍니다. 잠시 뒤 통계 창이 열립니다
7. **통계 창**: 판수·승률·연승·최대 연승·추측 분포 막대, 그리고 **공유** 단추
   (`navigator.clipboard.writeText(game.shareText())`. 실패하면 임시 `<textarea>` + `document.execCommand('copy')`
   로 대신하고, 복사됐다는 토스트를 띄웁니다)
8. **설정 창**: 하드 모드 / 어두운 테마 / 색약 모드. `saveSettings` 로 남고 다음에 열 때 그대로입니다.
   하드 모드는 **판이 시작된 뒤에는 바꿀 수 없습니다**(토스트로 거절)
9. **도움말 창**: 규칙과 색 예시. 처음 열었을 때 저절로 한 번 뜨고, 머리글의 `?` 로 다시 봅니다

## 보기

NYT 와 같은 색을 쓰십시오.

| | 맞음 | 자리 틀림 | 없음 |
| - | - | - | - |
| 밝은 테마 | `#6aaa64` | `#c9b458` | `#787c7e` |
| 어두운 테마 | `#538d4e` | `#b59f3b` | `#3a3a3c` |
| 색약 모드 | `#f5793a` (주황) | `#85c0f9` (파랑) | 위와 같음 |

- 색은 `:root` 의 CSS 변수로 두고 `<html>` 의 `data-theme` / `data-colorblind` 로 갈아끼우십시오
- 글꼴은 시스템 글꼴 묶음만 (`system-ui, -apple-system, "Segoe UI", sans-serif`)
- 좁은 화면(360px)에서도 보드와 키보드가 잘리지 않아야 합니다
- 글자와 배경의 대비는 4.5:1 이상

## 접근성

- 칸마다 `aria-label`(예: "3번째 줄 2번째 칸, R, 자리 틀림"), 토스트는 `aria-live="polite"` 영역
- 마우스 없이 키보드만으로 한 판을 끝낼 수 있어야 하고, 포커스 테두리를 지우지 마십시오
- 창(모달)은 `Esc` 로 닫히고 열렸을 때 바깥이 눌리지 않습니다
