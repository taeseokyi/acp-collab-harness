# T-161 웹워들: 격리된 미리보기 안에서도 기록이 남게 (결과물 쪽)

고칠 파일은 **둘뿐**입니다. 다른 파일은 열지도 마십시오.

- `projects/웹워들/web/js/storage.js` (133줄, 전부 읽으십시오)
- `projects/웹워들/web/js/ui.js` (478줄, **18행과 455~478행만** 보면 됩니다)

`web/js/game.js`, `web/js/words.js`, `tests/**`, 저장소 최상위 `tools/`·`tests/` 는 다른 슬롯 것입니다.

## 배경 (이것만 알면 됩니다)

웹워들은 함대 모니터의 `<iframe sandbox="allow-scripts allow-popups allow-modals">` 안에서도 돕니다.
`allow-same-origin` 이 없어 문서 출처가 불투명(opaque)이고, `localStorage` 를 **읽는 순간**
`SecurityError` 가 납니다. 그래서 지금은 `storage.js:14` 의 `catch` 로 메모리(`Map`)만 쓰고,
새로 고치면 통계·설정·진행 중인 판이 날아갑니다.

해결: 그 경우 **부모 창(모니터)에 postMessage 로 보관함을 빌립니다.** 모니터 쪽은 다른 태스크가
같은 시각에 만듭니다 - 당신은 **결과물 쪽만** 쓰면 됩니다. 규약은 아래에 전부 적혀 있습니다.

## 1. `storage.js` 에 더할 것

위쪽(기존 `store()` 아래)에 부모 모드를 더합니다. **기존 export 함수의 겉모습은 하나도 바꾸지
마십시오** (`loadStats`·`recordResult`·`loadDaily`·`saveDaily`·`clearDaily`·`loadSettings`·
`saveSettings`·`loadSeenHelp`·`saveSeenHelp` 는 지금 그대로 동기 함수입니다).

### 1-1. 새 export `init()`

```js
export async function init() { ... }
```

하는 일, 이 순서로:

1. `store()` 가 참을 돌려주면(= `localStorage` 가 된다) **아무것도 하지 않고 바로 돌아갑니다.**
   `serve.py` 로 띄운 평소 화면이 지금과 똑같이 돌아야 합니다
2. `localStorage` 를 못 쓰고 `globalThis.parent && globalThis.parent !== globalThis` 이면 부모 모드:
   - `globalThis.addEventListener('message', onMsg)` 를 **먼저** 걸고
   - `globalThis.parent.postMessage({aimem:'store.v1', op:'ready'}, new URL(location.href).origin)` 를 보냅니다
   - `snapshot` 응답을 **최대 500ms** 기다립니다. 오면 `items` 의 각 `키: 문자열` 을
     `memory.set(PREFIX + 키, 문자열)` 로 채우고 끝냅니다. 안 오면 그냥 끝냅니다(메모리 모드)
   - 어느 쪽이든 `parentMode = true` 로 두어 이후 쓰기를 부모에게도 흘립니다
3. 부모가 없으면(새 탭에서 연 경우) 아무것도 하지 않고 돌아갑니다. **기다리지 마십시오**

`onMsg(ev)` 는 다음을 모두 통과한 것만 받습니다. 하나라도 어긋나면 **조용히 무시**합니다.

- `ev.source === globalThis.parent`
- `ev.data` 가 평범한 객체이고 `Array.isArray` 가 아니며 `ev.data.aimem === 'store.v1'`
- `ev.data.op === 'snapshot'` 이고 `ev.data.items` 가 평범한 객체

`snapshot` 을 받았거나 500ms 가 지나면 리스너를 **뗍니다**(`removeEventListener`).
`init()` 은 두 번 불려도 한 번만 일하도록 하십시오(모듈 변수 하나로 충분합니다).

### 1-2. `write()` / `remove()` 가 부모에게도 보냄

`write(key, value)` 는 지금처럼 `memory.set` 과 `localStorage` 를 한 뒤, `parentMode` 이면

```js
globalThis.parent.postMessage({aimem:'store.v1', op:'put', key: key, value: text}, origin);
```

를 보냅니다. **`key` 는 접두 `webwordle.` 를 붙이지 않은 쪽**(`stats`, `settings`, `seenHelp`,
`daily.2026-11-11`)입니다 - 보관함은 프로젝트마다 따로라 접두가 필요 없습니다.
`remove(key)` 는 같은 꼴에 `value: null` 로 보냅니다.

보내기 전에 **스스로 걸러야 하는 것** (모니터도 거르지만 우리가 먼저 지킵니다):

- `key` 가 `/^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$/` 에 맞지 않으면 보내지 않습니다
- `text.length > 8192` 이면 보내지 않습니다

`postMessage` 를 `try { } catch { }` 로 감싸십시오 - 실패해도 게임은 계속돼야 합니다.
`origin` 은 `new URL(location.href).origin` 입니다(문서 출처는 `"null"` 이지만 URL 출처는
모니터 호스트라, 부모가 모니터가 아니면 배달되지 않습니다). 모듈 한 번만 계산해 두십시오.

### 1-3. 지난 날 기록 지우기

`init()` 에서 스냅숏을 받아 `memory` 를 채운 **뒤**, `memory` 의 키 중
`PREFIX + 'daily.'` 로 시작하면서 **오늘 날짜가 아닌 것**을 `remove()` 로 지웁니다
(보관함 키 상한 64개 대비). 오늘 날짜는 `new Date()` 에서 `YYYY-MM-DD` 로 만듭니다
(`ui.js` 의 `dayKeyOf` 와 같은 지역 시간 기준: `getFullYear`/`getMonth`+1/`getDate`, 2자리 0채움).

## 2. `ui.js` 에서 고칠 것 - 딱 두 군데

### 2-1. 18행

```js
let settings = loadSettings();
```

을

```js
let settings;
```

로 바꿉니다 (`import` 줄 7~9행에 `init` 을 더해야 합니다).

### 2-2. 455행 근처 `/* ---------- 시작 ---------- */` 바로 아래

지금:

```js
applySettings();
```

앞에 두 줄을 넣습니다.

```js
await init();              // 격리된 미리보기면 부모(모니터)에서 보관함을 받아 온다
settings = loadSettings();
applySettings();
```

`ui.js` 는 `<script type="module">` 로 실려 **최상위 await 가 됩니다** - 그대로 두면 됩니다.
`import` 줄에 `init` 을 더하는 것을 잊지 마십시오.

## 3. 하지 말 것

- `fetch`·`eval`·`location` 이동을 새로 넣지 마십시오
- 부모에게서 받은 값을 `JSON.parse` 해서 믿고 쓰지 마십시오 - `memory` 는 **문자열**을 담고,
  해석은 기존 `read()` 가 `try/catch` 안에서 합니다
- `sandbox` 속성이나 CSP 를 언급하는 코드를 넣지 마십시오
