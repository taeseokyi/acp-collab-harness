## `tests/test_aimem_monitor_app.py` - 셋

이 파일 `ProjectAppTests` 에는 이미 `self.app()`(임시 프로젝트 `알파`)과
`self.route(path, auth=False, host=..., tls=...)` 가 있습니다. **그대로 쓰십시오.**
맨 위 import 에 `import contextlib` 와 `import io` 가 필요합니다(`io` 는 이미 있습니다).

**(1) `test_ticket_is_masked_in_server_log`** - 티켓이 로그에 원문으로 남지 않는가.

```python
    def test_ticket_is_masked_in_server_log(self):
        h = server.Handler.__new__(server.Handler)
        h.log_date_time_string = lambda: "11/Nov/2026 00:00:00"
        mac = "97fa92835ac417492797dc21825a7fbb"
        buf = io.StringIO()
        with contextlib.redirect_stderr(buf):
            h.log_message('"%s" %s -', f"GET /app/~1794422924.{mac}/알파/index.html HTTP/1.1", "200")
        self.assertNotIn(mac, buf.getvalue())
        self.assertIn("/app/~***/", buf.getvalue())
```

**(2) `test_mint_branch_needs_a_session_even_without_the_gate`** - 인증 문을 지나쳐 라우팅으로 바로
들어와도 **세션 없이는 티켓을 내주지 않는가**(심층 방어). 게이트를 끄고 `do_GET` 을 부릅니다.

```python
    def test_mint_branch_needs_a_session_even_without_the_gate(self):
        self.app()
        h = server.Handler.__new__(server.Handler)
        h.path = "/app/%EC%95%8C%ED%8C%8C/"
        h.command = "GET"
        h.tls = False
        h.require_auth = True
        h.root = self.root
        h.access_token = "a" * 64
        h.headers = email.message.Message()
        h.headers["Host"] = "localhost:18799"
        h.client_address = ("127.0.0.1", 0)
        h._auth_gate = lambda path: False          # 인증 문이 뚫렸다고 치고
        status, headers = [], []
        h.send_response = lambda code: status.append(code)
        h.send_header = lambda key, value: headers.append((key, value))
        h.end_headers = lambda: None
        h.wfile = io.BytesIO()
        h.do_GET()
        self.assertEqual((status[-1], dict(headers).get("Location")), (302, "/login"))
        self.assertNotIn("/app/~", str(dict(headers).get("Location")))
```

**(3) 이미 있는 `test_csp_origin_rejects_unknown_host_name` 에 꼴을 더하십시오** - 그 검사가 지금
`evil.com` 하나만 본다면, 같은 방식으로 `"[::1].evil.com"`, `"[::1]evil.com"`, `"127.0.0.1:abc"` 도
CSP 에 `evil.com`·`127.0.0.1` 이 들어가지 않는지(출처 없이 `'self'` 만 남는지) 확인하게 하십시오.
`for host in (...)` + `with self.subTest(host=host):` 꼴이면 됩니다. **그 검사의 기존 단언은 지우지
마십시오.** 그리고 같은 파일에 이미 IP·`localhost` 가 통과하는 검사가 있으니 그것도 손대지 마십시오.

## `tests/browser_monitor_ui.py` - 하나

이 파일에는 이미 1280×900 짜리 `scenario()` 와 390×844 짜리 `narrow_scenario()` 가 있고
`main()` 에서 차례로 부릅니다. **그 둘은 건드리지 말고** 짧은 화면(가로 폰) 하나를 더합니다.

```python
def short_scenario(browser, base, checks):
    """짧은 화면(844x390)에서 미리보기 최소 높이가 결과물 키 크기를 지켜 주는가."""
    ctx = browser.new_context(viewport={"width": 844, "height": 390})
    page = ctx.new_page()
    try:
        page.goto(base + "/", wait_until="load")
        page.wait_for_selector("#projects-list .proj-item", timeout=15000)
        project = page.locator("#projects-list .proj-item").filter(has_text="웹워들").first
        project.locator(".proj-run").first.click()
        page.wait_for_selector("iframe.proj-app-frame", state="visible", timeout=15000)
        box = page.locator("iframe.proj-app-frame").first.bounding_box()
        key = page.frame_locator("iframe.proj-app-frame").locator(".key").first
        key.wait_for(state="visible", timeout=20000)
        key_box = key.bounding_box()
        checks.ok(
            "짧은 화면에서도 결과물 키가 32px 이상이다",
            box is not None and key_box is not None and box["height"] >= 426 and key_box["height"] >= 32,
            f"iframe 높이={box and round(box['height'], 1)}, 키 높이={key_box and round(key_box['height'], 1)}",
        )
    finally:
        ctx.close()
```

`main()` 안에서 `narrow_scenario(browser, base, checks)` **다음 줄**에
`short_scenario(browser, base, checks)` 를 부르십시오.
