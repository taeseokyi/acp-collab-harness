### `server.claude_usage(root=ROOT)` - 돌려주는 값

읽는 파일: `<root>/.aimem/claude-usage.json` (`tools/claude_usage_statusline.py` 가 씁니다. 지금 운영
저장소에는 **아직 없습니다** - 태석님이 상태줄을 등록해야 생깁니다). 꼴:
`{"at": "<ISO>", "rate_limits": {"five_hour": {...}, "seven_day": {...}, ...}}`

**`None` 을 돌려주는 경우** (어느 경우에도 예외를 올리지 않습니다):
- 파일이 없다 / 읽을 수 없다 (`OSError`)
- 파일 크기가 **64 KiB 를 넘는다**
- JSON 이 깨졌다 / 최상위가 dict 가 아니다
- `rate_limits` 가 dict 가 아니거나 비었다
- 아래 거르기를 마친 `rows` 가 **비었다**

**아니면 이 dict:**

```python
{"at": "2026-11-12T14:03:11",   # 파일의 `at` 을 문자열 그대로. 문자열이 아니면 None
 "age_seconds": 912,            # 지금 - at (int, 음수면 0). at 을 못 읽으면 None
 "rows": [{"key": "five_hour", "label": "5시간", "percent": 42.4,
           "resets_at_iso": "2026-11-12T18:00:00"}, ...]}
```

**`rows` 규칙**
- 차례와 라벨은 **고정**이고, `rate_limits` 에 없는 칸은 건너뜁니다. `rate_limits` 의 **모르는 칸은 버립니다**:

  | `rate_limits` 의 키 | `label` |
  |---|---|
  | `five_hour` | `5시간` |
  | `seven_day` | `주간` |
  | `seven_day_opus` | `주간·Opus` |
  | `seven_day_sonnet` | `주간·Sonnet` |

- `percent`: 그 행 dict 에서 `used_percentage` → `utilization` → `percent` 차례로 보고 **처음 나오는
  int/float**(`bool` 은 숫자로 치지 않습니다)를 씁니다. **0.0~100.0 으로 자르고** 소수 첫째 자리로
  반올림합니다. 셋 다 숫자가 아니면 **그 행을 버립니다**
- `resets_at_iso`: 그 행의 `resets_at` 에서 만듭니다
  - int/float → `datetime.datetime.fromtimestamp(v).isoformat(timespec="seconds")` (**현지 시각**)
  - str → `datetime.datetime.fromisoformat(v.replace("Z", "+00:00"))` 로 읽고, tz 가 붙어 있으면
    `.astimezone().replace(tzinfo=None)` 로 현지 시각으로 바꾼 뒤 `isoformat(timespec="seconds")`
  - 그 밖(없음·못 읽음) → `None`. **`resets_at` 이 없다고 행을 버리지는 않습니다**


### `/api/state` 계약

- `_blank_keys()` 에 `"claude_usage": None` 을 더합니다

  `_empty_state` 의 주석을 보십시오)


## 써야 할 시험 (최소 12건, `unittest.TestCase`)

1. 파일이 없으면 `None`
2. JSON 이 깨졌으면 `None`
3. `rate_limits` 가 없으면 / 비었으면 `None` (두 건으로 나눠도 됩니다)
4. 64 KiB 를 넘는 파일이면 `None`
5. 네 칸이 다 있을 때 `rows` 의 `key` 차례와 `label` 이 계약대로
6. `rate_limits` 의 **모르는 칸**(`"nonsense"`)은 `rows` 에 안 들어간다
7. `used_percentage` / `utilization` / `percent` 를 **그 차례로** 집어 온다 (셋이 섞인 입력 하나로)
8. 숫자가 아닌 값(`"많음"`, `True`)인 행은 **버려진다**
9. `percent` 가 0 아래·100 위면 **잘린다**
10. `resets_at` 이 **epoch 숫자**이면 현지 ISO 문자열이 된다
11. `resets_at` 이 **tz 붙은 ISO 문자열**(`...Z`)이면 현지 시각 ISO 가 된다
12. `resets_at` 이 없거나 쓰레기면 `resets_at_iso is None` 이고 **행은 남는다**
13. `at` 이 20분 전이면 `age_seconds` 가 1100~1300 이고, `at` 이 없으면 `age_seconds is None`
14. 거르고 나서 `rows` 가 비면 전체가 `None`
15. `_blank_keys()` · `collect_state()` · `_empty_state()` 셋 다 `"claude_usage"` 키를 가진다
16. `claude_usage()` 가 **예외를 올리지 않는다** - 디렉터리를 `.aimem/claude-usage.json` 자리에
    만들어 두고 불러도 `None`

임시 저장소는 `tempfile.TemporaryDirectory()` 로 만들고 `.aimem/claude-usage.json` 을 손으로 씁니다.
**운영 저장소(`ROOT`)에는 아무것도 쓰지 마십시오.**
