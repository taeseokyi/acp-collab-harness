# T-126 모니터에 `/app/<프로젝트>/` 실행 경로를 만듭니다 (뒷단 + 단위 시험)

## 무엇을 하는 일인가

태석님 요청 `Q-261111-5593`: "함대 모니터 웹에서 프로젝트 결과물(웹워들)을 따로 서버를 띄우지 않고 실행".
**이 태스크는 그 뒷단입니다.** 프로젝트가 `app.json` 한 장으로 "내 웹앱은 여기 있다" 고 선언하면,
모니터가 `/app/<프로젝트>/...` 로 그 폴더의 정적 파일을 그대로 내려 줍니다. 화면(단추·iframe)은 다음 태스크입니다.

## 고칠 파일 (이 셋뿐입니다)

- `tools/aimem_monitor/server.py` (구현)
- `tools/aimem_monitor/__init__.py` (계약 상수와 주석)
- `tests/test_aimem_monitor_app.py` (**새 파일**, 단위 시험)

## 1. `__init__.py` - 계약

다음을 **추가**하십시오 (있는 것은 건드리지 않습니다).

```python
#: 프로젝트가 "내 웹앱은 여기 있다" 고 적는 선언 파일. 없으면 그 프로젝트는 실행할 수 없습니다.
PROJECT_APP_MANIFEST = "app.json"
#: 실행 경로 접두. `/app/<프로젝트>/<앱 안의 상대 경로>`
PROJECT_APP_URL_PREFIX = "/app/"
#: 실행 경로가 내려 주는 한 파일의 크기 상한.
PROJECT_APP_FILE_MAX_BYTES = 8 * 1024 * 1024
#: 인증이 없을 때 로그인 화면으로 **보내 주는** 경로 접두 (`AUTH_UNAUTH_REDIRECT_PATHS` 의 접두판).
#: 결과물을 새 탭에서 열었는데 JSON 401 이 뜨면 사람이 막힙니다.
AUTH_UNAUTH_REDIRECT_PREFIXES = ("/app/",)
```

`SERVER_KEYS["projects"]` 문자열 끝에 `, app` 을 더하고, 바로 위 주석에 한 줄 적으십시오:

```
# app = 실행 선언(`projects/<이름>/app.json`). {runnable, url, title, root, entry, reason} 또는 null
```

그리고 `PROJECT_APP_MANIFEST` 위에 **왜 이렇게 하는지**를 4~6줄로 적으십시오. 요지는:
결과물은 모니터와 **같은 출처(origin)** 에서 내려가지만 화면은 그것을 `sandbox` iframe(= 불투명 출처)에
넣는다. 그래서 결과물 코드가 `/api/*` 를 인증된 세션 쿠키로 부를 수 없다. 대신 불투명 출처에서는
CSP 의 `'self'` 가 아무것도 가리키지 못하므로, `/app/` 응답의 CSP 는 **요청의 Host 로 만든 출처를 직접 적는다.**

## 2. `server.py` - 구현

### (a) `CONTENT_TYPES` 를 늘립니다

지금은 `.html .js .css .json .svg .ico .png .webmanifest` 뿐입니다. 결과물이 쓸 만한 것을 더하십시오:
`.mjs`(=`text/javascript; charset=utf-8`), `.txt`, `.jpg`/`.jpeg`, `.gif`, `.webp`, `.woff2`, `.wasm`, `.map`(=json).
**모르는 확장자는 `application/octet-stream`** 그대로 둡니다(`X-Content-Type-Options: nosniff` 가 이미 붙습니다).

### (b) `project_app(name, root=ROOT)` - 선언 읽기

기존 `_project_dir()` 를 그대로 쓰십시오. 돌려주는 것:

- `app.json` 이 없으면 **`None`** (실행 못 하는 평범한 프로젝트)
- 있으면 `{"runnable": True, "url": "/app/<이름>/", "title": ..., "root": ..., "entry": ...}`
- 선언이 잘못됐으면 `{"runnable": False, "reason": "<사람이 읽을 한 줄>"}`

읽는 값과 기본값: `root`(기본 `"web"`), `entry`(기본 `"index.html"`), `title`(기본 = 프로젝트 이름).
`root`·`entry` 는 **프로젝트 폴더 안의 상대 경로**여야 합니다. 거절 조건을 하나도 빼지 마십시오:

- 문자열이 아니다 / 비었다 / 400자를 넘는다 / `\x00` 이나 `\` 가 들어 있다
- `/` 로 시작한다, 조각에 `""`·`"."`·`".."` 가 있다, 조각이 `.` 으로 시작한다
- 조각이 8개를 넘는다
- 풀어낸 실제 경로(`resolve()`)가 프로젝트 폴더 밖이다 - **`project_file()` 과 똑같은 방식으로**
  (`f.resolve() == d.resolve().joinpath(*parts)`) 중간에 낀 심볼릭 링크까지 잡으십시오
- `root` 가 폴더가 아니다 / 심볼릭 링크다 / `root`+`entry` 가 파일이 아니다
- `title` 이 문자열이 아니거나 80자를 넘는다 → 잘라 쓰십시오 (거절하지 말고)

**어떤 입력에도 예외를 던지지 마십시오.** JSON 파싱 실패·읽기 실패도 `runnable: False` + `reason` 입니다.

### (c) `list_projects()` 항목에 `"app"` 을 싣습니다

각 프로젝트 항목에 `"app": project_app(name, root)` 를 더하십시오 (`exists` 가 거짓이면 `None`).
**기존 키는 하나도 바꾸지 마십시오.**

### (d) `project_app_file(name, rel, root=ROOT)` - 파일 하나 내려 주기

`(code, data, ctype)` 를 돌려주십시오. `data` 는 **bytes**(성공) 또는 오류 dict 입니다.

- 선언이 `runnable` 이 아니면 `(404, {"ok": False, "error": "..."}, None)`
- `rel` 이 비면 `entry` 를 씁니다
- 경로 안전 검사는 **(b) 와 똑같은 규칙**을 `root` 아래에 적용합니다. 바깥·심볼릭 링크·숨김은 전부 404
- 파일 크기가 `PROJECT_APP_FILE_MAX_BYTES` 를 넘으면 `(413, {...}, None)` - **잘라 보내지 마십시오**
  (반쪽짜리 js 는 조용히 깨집니다)
- 성공이면 `(200, <bytes>, CONTENT_TYPES.get(suffix, "application/octet-stream"))`

### (e) `app_csp(origin)` - 순수 함수로 **따로** 빼십시오

```python
def app_csp(origin=""):
    """`/app/` 응답에 붙는 CSP. `origin` 은 `https://host:port` 또는 빈 문자열."""
```

만드는 문자열(순서·세미콜론 그대로):

```
default-src 'self' <O>; img-src 'self' <O> data: blob:; style-src 'self' <O> 'unsafe-inline';
script-src 'self' <O>; connect-src 'self' <O>; font-src 'self' <O> data:;
frame-ancestors 'self'; base-uri 'none'; form-action 'none'
```

(실제로는 한 줄입니다.) `<O>` 자리는 `origin` 이 있을 때만 끼워 넣고, 없으면 그 자리를 아예 비웁니다
(`'self' ;` 처럼 빈칸이 남지 않게). **`frame-ancestors 'self'` 가 핵심입니다** - 기본 보안 헤더의
`frame-ancestors 'none'` 이 그대로 가면 모니터가 결과물을 iframe 에 넣지 못합니다.

### (f) `_send()` 에 `csp=None` 을 더합니다

`SECURITY_HEADERS` 를 돌 때 `csp` 가 주어졌으면 `Content-Security-Policy` **대신 그 값**을 보냅니다.
**두 개를 다 보내면 안 됩니다** - CSP 헤더가 둘이면 브라우저는 교집합을 적용해서 `frame-ancestors 'none'`
이 살아남습니다. 나머지 보안 헤더(`nosniff`, `Referrer-Policy`, HSTS)는 그대로 붙입니다.

### (g) 라우팅 (`do_GET` 안, `/api/projects/...` 분기 **뒤**, `/` 분기 **앞**)

```python
_APP_RE = re.compile(r"\A/app/([^/]{1,400})(/(.*))?\Z", re.S)
```

- `/app/<이름>` (끝 슬래시 없음) → **302 Location: `/app/<이름>/`**. 끝 슬래시가 없으면 `css/style.css`
  같은 상대 경로가 `/app/css/style.css` 로 틀리게 풀립니다. 기존 `self._redirect(...)` 를 쓰십시오
- 그 밖에는 `project_app_file()` 을 부르고, 성공이면
  `self._send(200, data, ctype, extra=[], csp=app_csp(self._app_origin()))`,
  실패면 `self._json(code, body)` (오류 응답에는 CSP 를 바꾸지 마십시오)
- `<이름>` 은 `urllib.parse.unquote` 하고, `rel` 도 unquote 한 뒤 쿼리(`?`)는 떼십시오
  (`urllib.parse.urlparse(self.path).path` 를 쓰는 기존 방식과 어긋나지 않게)

`_app_origin(self)` 도 만드십시오: `Host` 헤더를 읽어 `("https" if self.tls else "http") + "://" + host`.
**Host 가 `\A[A-Za-z0-9._:\[\]-]{1,100}\Z` 에 맞지 않으면 빈 문자열**을 돌려주십시오
(헤더 주입으로 CSP 에 아무 말이나 끼워 넣지 못하게).

### (h) 인증

`_auth_gate()` 에서, 아직 `AUTH_UNAUTH_REDIRECT_PATHS` 로 `/login` 에 보내는 자리 바로 옆에
`AUTH_UNAUTH_REDIRECT_PREFIXES` 중 하나로 **시작하는** GET/HEAD 도 `/login` 으로 보내도록 더하십시오.
**`/app/` 을 `AUTH_EXEMPT_PATHS` 에 넣지 마십시오** - 결과물은 인증 뒤에 있어야 합니다.

## 3. `tests/test_aimem_monitor_app.py` - 새 단위 시험 (12개 이상)

기존 `tests/test_aimem_monitor_projects.py` 의 틀을 그대로 쓰십시오(`tempfile` 로 가짜 저장소,
`sys.path.insert` 로 `tools` 를 넣고 `from aimem_monitor import server`). **소켓을 열지 마십시오** -
여기서는 함수를 직접 부릅니다. 최소한 이것들:

1. `app.json` 이 없으면 `project_app()` 이 `None`
2. 기본값: `{}` 만 적힌 `app.json` → `root="web"`, `entry="index.html"`, `title=<프로젝트 이름>`, `url="/app/<이름>/"`
3. 직접 적은 `root`/`entry`/`title` 이 그대로 나온다
4. JSON 이 깨졌거나 객체가 아니면 `runnable False` + `reason` (예외가 나지 않는다)
5. `root` 가 `"../.."`, `"/etc"`, `".hidden"`, `"a\\b"`, `"a/../../b"` 면 전부 `runnable False`
6. `root` 가 프로젝트 밖을 가리키는 **심볼릭 링크**면 `runnable False`
7. `entry` 가 없는 파일이면 `runnable False`
8. `project_app_file(name, "")` 이 `entry` 의 바이트와 `text/html; charset=utf-8` 을 돌려준다
9. `project_app_file(name, "js/x.mjs")` 가 `text/javascript; charset=utf-8`, 모르는 확장자는 `application/octet-stream`
10. `project_app_file(name, "../../AIMEM.md")` 와 `"../app.json"` 이 404 (저장소 파일이 새지 않는다)
11. 앱 폴더 안에서 **밖을 가리키는 심볼릭 링크**는 404
12. `PROJECT_APP_FILE_MAX_BYTES` 를 넘는 파일은 413 이고 **잘린 본문을 주지 않는다**
13. 바이너리(`\x00` 이 든 png)도 바이트 그대로 나온다
14. `app_csp("https://h:1")` 가 `frame-ancestors 'self'` 를 담고 `'none'` 을 담지 않으며 출처가 6번 들어간다;
    `app_csp("")` 는 `;` 앞뒤에 빈칸이 겹치지 않는다
15. `list_projects()` 항목에 `app` 키가 있고, 선언이 없는 프로젝트는 `None`
16. 계약: `SERVER_KEYS["projects"]` 에 `app` 이 적혀 있다

## 검증 (엔진이 돌립니다)

```bash
python3 -m unittest tests.test_aimem_monitor_app
python3 -m unittest discover -s tests          # 432개가 OK 인 상태를 깨면 안 됩니다
```

`pytest` 는 없습니다. 당신의 샌드박스에서는 **소켓을 못 엽니다**(`PermissionError`) - 그래서
`discover` 전체는 당신 쪽에서 빨갛게 보일 수 있습니다. 그것은 당신 잘못이 아닙니다.
**새로 쓴 `tests/test_aimem_monitor_app.py` 만은 당신 쪽에서도 초록이어야 합니다**(소켓을 안 쓰니까).
`python3 -m unittest tests.test_aimem_monitor_app` 까지 꼭 돌려 보고 끝내십시오.
