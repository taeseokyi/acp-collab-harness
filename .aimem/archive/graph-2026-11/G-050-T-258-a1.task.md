# T-258 사용 한도 카드의 시험 구멍 둘 (R18-B10 · R18-B12)

쓸 파일은 **하나**입니다: `tests/browser_monitor_usage.py` (지금 **13건 전부 통과**).
**다른 `tests/**` 와 `tools/**` 는 읽기만 하고 절대 고치지 마십시오.** 바로 보태십시오.

## 구멍 1 - R18-B10: 퍼센트 **반올림**을 안 재고 있다

- 서버(`tools/aimem_monitor/server.py` 의 `claude_usage`)는 `percent: round(percent, 1)` 로
  **소수 한 자리**까지 보냅니다
- 화면(`tools/aimem_monitor/static/app.js:1609`)은 `Math.round(pct) + '%'` 로 **반올림**해 찍습니다
- 지금 검사는 **정수 퍼센트만** 넣어서, `Math.round` 를 `Math.floor` 로 바꿔도 전부 초록입니다

**보탤 검사:** `.aimem/claude-usage.json` 의 `used_percentage` 를 **`79.6`** 으로 두고
그 줄의 `.usage-pct` 글자가 **`'80%'`** 인지 (`inner_text`). `Math.floor` 였다면 `'79%'` 입니다.
덤으로 같은 줄의 클래스가 `usage-ok` 인지도 보십시오 (`79.6 < 80` 이라 색은 아직 ok 입니다 -
**글자는 80 인데 색은 ok** 인 이 어긋남이 바로 반올림이 살아 있다는 증거입니다).

## 구멍 2 - R18-B12: `'N시간 전 기준'` 경계를 안 재고 있다

`app.js:1564` 의 `usageStaleText(ageSeconds)`:

```js
if (minutes > 60) return Math.floor(minutes / 60) + '시간 전 기준';
return minutes + '분 전 기준';
```

**보탤 검사:** `at` 을 조절해 `age_seconds` 가 각각 **정확히 60분**과 **61분**이 되게 하고
`#usage-stale` 글자가 **`'60분 전 기준'`** / **`'1시간 전 기준'`** 인지 보십시오.
(`at` 은 ISO 시각 글자입니다 - 지금 있는 "오래된 자료는 'N분 전 기준'" 검사가 어떻게 꾸미는지
먼저 읽고 같은 도우미를 쓰십시오. 초 단위로 조금 밀려 59/60 을 넘나들지 않게 **몇 초 여유**를
두고 계산하십시오 - 예를 들어 60분 쪽은 `60*60 + 5`초 전, 61분 쪽은 `61*60 + 5`초 전.)

## 규칙

- 지금 검사 13건을 지우거나 고치지 마십시오. **보태기만** 하십시오
- 검사는 **그려진 것**을 물으십시오 - `inner_text()`, `is_visible()`, `getComputedStyle`,
  `bounding_box()`. 속성이나 내부 변수를 보지 마십시오
- 제품(`tools/**`)이 틀려 새 검사가 빨개지면 **고치지 말고** 보고 첫 줄을
  `NEEDS-FIX: <무엇이 어디서>` 로 쓰십시오

## 검증

검증 명령이 봅니다: `python3 tests/browser_monitor_usage.py` 의 마지막 줄이 `통과 N / 전체 M`
이고 **전체가 16건 이상** 인 것(= 검사를 정말 보탰는가).
