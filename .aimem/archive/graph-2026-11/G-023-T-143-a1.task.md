## 배경

이번 라운드 1단계에서 적대적 검수 둘이 돌았고(`rounds/R11/REVIEW-A.md`,
`rounds/R11/REVIEW-B.md` - **이 둘은 읽으십시오**), 2단계에서 결함을 고쳤습니다. 당신은 **고친
결과를 다시 때리는 사람**입니다. 고친 사람의 말을 믿지 마십시오.

고쳐진 것 (네 갈래):

1. **인증 우회 (검수 A 결함 1, 심각도 높음)** - 라운드 도중 다른 세션(클로드 코드)이 먼저 고쳤습니다.
   `tools/aimem_monitor/server.py` 의 `_auth_gate` 가 이제 **원본 경로**를 `_APP_RE` 로 맞춰
   "티켓 조각이 있고 원본에 `.`·`..`·빈 조각이 없을 때만" 세션 검사를 건너뜁니다. 아니면 404.
   그리고 발급 갈래(`if ticket is None:`)가 서명 전에 `require_auth and not self._subject()` 이면
   `/login` 302 를 돌려줍니다. 회귀 시험은 `tests/test_aimem_monitor_app_gate.py` (새 파일).
   **이것을 가장 세게 때리십시오.** 검수 A 가 쓴 우회(`/app/<이름>/../~x/`)와 그 변형
   (`…/x/../../~x`, `…/../~`, `…/./../~/`, HEAD, 절대 URI 요청줄, 없는 이름, 인코딩 변형
   `%2e%2e`, `..%2f`, `%252e`, 이중 슬래시, 뒤에 `?`·`#` 붙이기, `;` 조각)을 **전부 다시** 돌리고,
   **새로운 변형도 스스로 찾아보십시오**. 무인증 소켓이 티켓을 발급받거나 200 을 받으면 결함입니다.
   정상 동작도 함께 확인하십시오: 로그인한 뒤 `/app/웹워들/` 302 → 티켓 경로 200, 티켓 경로는
   쿠키 없이 200.
2. **티켓이 로그에 남던 것 (검수 A 결함 2)** - `log_message` 가 `/app/~<티켓>` 을 `/app/~***` 로
   가립니다. 실제로 서버 표준오류를 받아 티켓 문자열이 **한 줄도** 없는지 확인하고, 가리기를
   우회하는 요청 꼴(티켓이 질의 문자열·헤더·본문에 들어가는 길)이 있는지 보십시오.
3. **Host 가 CSP 출처가 되던 것 (검수 B 결함 1)** - `_app_origin` 이 `_app_host_allowed`(IP 리터럴·
   `localhost`·`AIMEM_MONITOR_PUBLIC_HOSTS`)만 받습니다. `Host: evil.com`, `evil.localhost`,
   `127.0.0.1.evil.com`, `evil.com:18800`, 끝에 점, 대문자, IPv6 괄호 꼴, 환경변수를 설정한 경우까지
   때려 보고, **막혀야 할 것이 막히고 통해야 할 것이 통하는지**(운영은 IP 로 들어옵니다) 확인하십시오.
4. **미리보기 최소 높이 (검수 B 결함 2)** - `.proj-app-frame` 의 `min-height` 가 380px 입니다.
   짧은 화면(390×500, 844×390)에서 브라우저로 **재어** 결과물 키 높이가 32px 이상인지,
   그 높이가 패널 밖으로 삐져나오지 않는지 보십시오(`bounding_box()`·`getComputedStyle`).

그리고 **검사 여섯이 더해졌습니다**(`tests/test_aimem_monitor_app.py`,
`tests/test_aimem_monitor_auth.py`, `tests/browser_monitor_ui.py`, `tests/browser_monitor_auth.py`).

4. 1단계 검수가 "결함 아님" 으로 적어 둔 것 중 **권고**(티켓 `exp` 상한, `re.ASCII`)는 고치지 않은

httpd = http.server.ThreadingHTTPServer(("127.0.0.1", 0), H)
httpd.daemon_threads = True
threading.Thread(target=httpd.serve_forever, daemon=True).start()
base = f"http://127.0.0.1:{httpd.server_address[1]}"
