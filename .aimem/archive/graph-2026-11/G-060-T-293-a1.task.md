# T-293 하드 모드 설정이 다른 모드의 빈 판에 바로 닿게 (`rounds/R24/REVIEW-r24-2.md` 2절 새 N5)

쓸 파일: `projects/자모맞히기/web/js/ui.js`, `projects/자모맞히기/tests/browser_modes.py`. 다른 파일은 읽기만. **바로 파일을 고치십시오.**

## 결함

연습에서 하드 모드를 켜고(설정 창 `#set-hard`) 아직 한 줄도 내지 않은 날마다 판으로 가면, 체크박스는 꺼짐(판 값)인데 저장 설정은 켜짐입니다. 새로 고치면 같은 빈 판이 말없이 하드로 바뀝니다(반대 방향도 같음). `startDaily()` 는 518~522행에서 빈 판을 저장 설정에 맞춰 다시 만들지만 `selectMode()`(553행~)는 그러지 않습니다.

## 고칠 것 (ui.js)

- 518~522행의 "빈 판이면 설정의 하드 값으로 다시 만들되 입력 중인 글자는 옮김" 을 **함수 하나**(예: `alignEmptyHard(g)` → 새 판 또는 그대로 돌려줌)로 빼고, `startDaily()` 와 `selectMode()` 둘 다 그것을 쓰게 합니다. `selectMode` 에서는 들어가는 판(`dailyGame` 또는 `practiceGame`)에 적용하고 `dailyGame`/`practiceGame` 변수도 새 판으로 바꿉니다. 줄이 하나라도 있는 판은 그대로 둡니다.
- 다른 동작은 바꾸지 마십시오.

## 더할 시험 (browser_modes.py, 3개 이상 - 기존 76개는 그대로)

1. 연습에서 하드 켬 → 날마다(빈 판) → 설정 창 `#set-hard` 가 **켜져 있음** → 새로 고친 뒤에도 켜져 있음
2. 반대: 하드 켠 상태에서 날마다 빈 판 → 연습 → 하드 끔 → 날마다 → **꺼져 있음**
3. 한 줄 낸 날마다 판은 연습에서 하드를 바꾸고 돌아와도 **판 값 그대로**

화면 검사 규칙: 그려진 것을 묻습니다(`is_visible()`, `getComputedStyle`, `bounding_box()`, 체크박스는 `is_checked()`).
