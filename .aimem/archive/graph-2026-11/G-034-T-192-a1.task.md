# T-192 정리가 **`AIMEM.md` 를 건드리는 길**을 막으십시오

고칠 파일은 **`tools/aimem_db.py` 하나**입니다. 다른 파일은 고치지 마십시오.

## 읽을 것 (이것만)

- `tools/aimem_db.py` 의 `render()`(591행 근처) · `sync_rev_in_aimem()`(573행 근처) · `handoff_sync()`
- `archive_apply` 끝에서 `render()` 를 부르는 자리

**읽지 마십시오:** `AIMEM.md` 본문, `tools/aimem_monitor/**`, `tests/**`, `projects/**`

## 결함 N3 (재검수가 찾음) - 정리 단추가 관리자 전용 파일을 쓴다

`archive_apply` 가 끝에 `render()` 를 부릅니다. 그런데 `render()` 는
`sync_rev_in_aimem()` 을 부르고, 그 함수는 **`AIMEM.md` 를 고쳐 씁니다**(서문 REV 줄과 '최종 갱신' 줄).

- `AIMEM.md` 는 **관리자만** 쓰는 파일입니다. 웹의 '끝난 것 정리' 단추가 그것을 쓰면 안 됩니다
- 게다가 `AIMEM` 은 **모듈 상수**라, `ROOT` 만 임시 폴더로 바꾼 시험도 **진짜 `AIMEM.md` 를 씁니다**
  (같은 꼴의 결함으로 이미 운영 `AIMEM-state.md` 가 한 번 덮어써졌습니다)

## 고칠 것

1. **생성물만 다시 쓰는 길을 따로 만드십시오.** 예: `render(sync_aimem=True)` 로 기본값은 지금 그대로
   두고, `archive_apply` 는 `render(sync_aimem=False)` 로 부르게 하십시오.
   `sync_aimem=False` 면 `AIMEM-state.md` 와 `.aimem/handoff.md` 만 쓰고 `sync_rev_in_aimem()` 은
   **부르지 않습니다.** CLI `aimem_db.py render` 는 지금과 똑같이(서문까지 맞추게) 두십시오
2. `sync_rev_in_aimem()` 안에서 쓸 경로를 **부를 때** `ROOT / "AIMEM.md"` 로 만드십시오
   (`AIMEM` 상수는 남겨 두되 쓰기는 부를 때 만든 경로로). `handoff_sync()` 쪽도 같은 눈으로 보십시오
3. `archive_apply` 의 `out["render_error"]` 는 그대로 두되, **render 가 실패했으면 그 사실이
   `cmd_archive` 출력에도 한 줄 찍히게** 하십시오 (재검수 N3: 지금 조용히 삼켜집니다)
