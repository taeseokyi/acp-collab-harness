## 수정 1 - 발급된 티켓의 `exp` 상한

`app_ticket_ok` (225행 근처)는 **만료**만 봅니다:

```python
    exp = int(exp_s)
    if exp < int(time.time() if now is None else now):
        return False
```

서명이 맞기만 하면 `exp` 가 10년 뒤여도 통과합니다. 서명 키는 접근 토큰이라 키가 새면
영영 죽지 않는 티켓이 만들어집니다. **상한을 겁니다** - 위 두 줄 다음에 더하십시오:

```python
    # 발급은 TTL 안쪽에서만 합니다. 서명이 맞아도 그보다 먼 `exp` 는
    # 이 서버가 발급한 것일 수 없습니다 (키가 샜을 때 영구 티켓을 막는 심층 방어).
    if exp > int(time.time() if now is None else now) + PROJECT_APP_TICKET_TTL_SEC + 60:
        return False
```

`PROJECT_APP_TICKET_TTL_SEC` 는 이 파일이 이미 import 하고 있습니다(81행 근처).

## 수정 2 - `%7E` 로 인코딩된 티켓 경로도 로그에서 가리기

135행 근처:

```python
_TICKET_LOG_RE = re.compile(r"/app/~[^/\s]+")
```

`~` 는 URL 에서 `%7E`/`%7e` 로도 적을 수 있고, 라우팅은 언퀘이트한 뒤 보므로 그런 요청도
받아집니다. 그런데 로그에는 **원문 그대로** 남아 이 정규식이 못 가립니다.
`~` 자리를 셋 중 하나로 넓히십시오:

```python
_TICKET_LOG_RE = re.compile(r"/app/(?:~|%7[Ee])[^/\s]+")
```

이 정규식을 쓰는 자리(2321행 근처 `_TICKET_LOG_RE.sub("/app/~***", line)`)는 그대로 둡니다.

## 단위 시험 (`tests/test_aimem_monitor_app.py`)

이미 있는 시험은 지우지 말고 더하십시오. **서버를 띄우지 말고** 함수를 바로 부르십시오
(이 파일에 이미 그렇게 하는 시험이 있습니다 - 그 짜임새를 따라 하십시오).

1. `app_ticket_ok` - 정상 티켓(지금 + TTL)은 `True`
2. `app_ticket_ok` - 만료된 티켓(지금 - 10)은 `False` (회귀)
3. `app_ticket_ok` - **`exp` 가 지금 + TTL + 3600 인, 같은 키로 올바로 서명된 티켓**은
   `False` (이번에 더한 상한). `app_ticket(name, exp, key)` 로 직접 만드십시오
4. `app_ticket_ok` - `exp` 가 지금 + TTL + 30 이면 `True` (60초 여유 안쪽)
5. `_TICKET_LOG_RE` - `GET /app/~1234.abcdef0123456789abcdef0123456789/웹워들/` 한 줄이
   `/app/~***` 로 가려진다 (회귀)
6. `_TICKET_LOG_RE` - `GET /app/%7E1234.abcdef0123456789abcdef0123456789/웹워들/` 도
   가려지고, **원래 티켓 글자가 결과 문자열에 남지 않는다** (`assertNotIn`)
7. `_TICKET_LOG_RE` - `%7e` 소문자도 같다
8. `_TICKET_LOG_RE` - `/app/웹워들/` 처럼 티켓이 없는 줄은 **안 바뀐다**
