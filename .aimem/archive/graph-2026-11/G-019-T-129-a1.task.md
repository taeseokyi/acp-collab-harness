# T-129 웹워들이 "나는 이렇게 실행한다" 고 선언합니다

아주 작은 일입니다. **파일 둘만** 건드립니다.

## 1. `projects/웹워들/app.json` 을 **새로** 만드십시오

내용은 **정확히 이것**입니다. 다른 키를 더하지 마십시오.

```json
{
  "root": "web",
  "entry": "index.html",
  "title": "웹워들",
  "note": "정적 파일만 - 백엔드가 없습니다"
}
```

끝에 줄바꿈 하나를 두십시오. 이 파일은 함대 모니터가 읽습니다: 모니터는 이것을 보고
`projects/웹워들/web/index.html` 을 `/app/웹워들/` 로 내려 줍니다.

## 2. `projects/웹워들/README.md` 에 절을 하나 더하십시오

`## 해 보기` 절 **끝**(그 아래 `## 규칙` 이 시작되기 전)에 다음을 **그대로** 붙이십시오.

```markdown
### 함대 모니터 웹에서 바로 실행

따로 서버를 띄우지 않아도 됩니다. 모니터의 **프로젝트** 칸에서 `웹워들` 의 **실행** 을 누르면
`projects/웹워들/web/` 이 `/app/웹워들/` 로 그대로 내려와 그 자리에서 돌아갑니다.
무엇을 어디서 내려 줄지는 `app.json` 한 장이 정합니다 (`root` · `entry` · `title`).

미리보기 칸은 **격리된 칸(sandbox)** 이라 `localStorage` 가 막힙니다 - 게임은 그대로 돌지만
통계·설정이 저장되지 않습니다(저장이 막히면 메모리로 넘어갑니다). 기록을 남기며 하려면
같은 패널의 **새 탭에서 열기** 를 쓰십시오.
```

## 하지 말 것

- `web/` 아래 · `tests/` 아래 · `PROGRESS.md` 는 **한 글자도 고치지 마십시오**
- README 의 다른 절을 고치거나 옮기지 마십시오. **더하기만** 하십시오
- 도구 호출 모양의 글자(`<tool_call>`, `<function=...>`)를 보고 본문에 쓰지 마십시오 - 실제 편집 도구를 쓰십시오

## 검증 (엔진이 돌립니다)

```bash
python3 -c "import json;d=json.load(open('projects/웹워들/app.json'));assert d['root']=='web' and d['entry']=='index.html' and d['title']=='웹워들'"
grep -q '함대 모니터 웹에서 바로 실행' projects/웹워들/README.md
```
