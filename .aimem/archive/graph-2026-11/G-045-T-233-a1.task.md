## 상태 주입은 **임시 저장소**로 합니다 (`page.route` 쓰지 마십시오)

`monitor_server(root=...)` 는 저장소 경로를 받습니다. 빈 임시 디렉터리에 `.aimem/claude-usage.json`
만 써 두고 그 저장소로 서버를 띄우면, **진짜 서버 코드가 진짜 파일을 읽어** 화면에 그립니다.
(빈 저장소라 `errors` 에 "AIMEM.md 가 없습니다" 가 뜨지만 화면은 정상으로 뜹니다 - 관리자가 확인했습니다.)

```python
import json, pathlib, tempfile, datetime as dt

def usage_root(rows, at=None):
    d = pathlib.Path(tempfile.mkdtemp(prefix="r18-usage-"))
    (d / ".aimem").mkdir()
    at = at or dt.datetime.now().isoformat(timespec="seconds")
    (d / ".aimem" / "claude-usage.json").write_text(
        json.dumps({"at": at, "rate_limits": rows}, ensure_ascii=False), encoding="utf-8")
    return d
```

### 화면 계약 (이 이름 그대로 - 브라우저 검사가 이 선택자를 씁니다)

`index.html` 의 `#panel-fleet` **맨 위**, `#fleet-section` **앞**에:

```html
<section class="card" id="usage-section">
  <h2>Claude 사용 한도 <span class="hint" id="usage-stale"></span></h2>
  <div id="claude-usage" class="claude-usage"></div>
</section>
```

`app.js` 에 `renderClaudeUsage(data)` 를 만들고, `renderFleetControl(data)` 를 부르는 **두 자리**
(1113행 근처와 3469행 근처)에서 바로 뒤에 같이 부릅니다.

- `data.claude_usage` 가 **없거나 `null`** → `#claude-usage` 안에 `<p class="empty">` 하나,
  글은 `상태줄 명령을 등록하면 보입니다`. `#usage-stale` 은 빈 글
- 있으면 `rows` 마다 하나씩:

```html
<div class="usage-row usage-ok" data-key="five_hour">
  <span class="usage-label">5시간</span>
  <span class="usage-bar"><span class="usage-fill"></span></span>
  <span class="usage-pct">42%</span>
  <span class="usage-reset">초기화 18:00</span>
</div>
```

- `.usage-row` 의 둘째 클래스: `percent < 80` → `usage-ok`, `80 <= percent < 95` → `usage-warn`,
  `percent >= 95` → `usage-crit`
- `.usage-fill` 의 `style.width` 는 `percent` 를 퍼센트로 (`42.4` → `width: 42.4%`). **0% 여도 칸은
  보입니다** (`.usage-bar` 가 테두리를 가짐)
- `.usage-pct` 글: `Math.round(percent) + '%'`
- `.usage-reset` 글: `resets_at_iso` 가 **오늘이면** `초기화 HH:MM`, 오늘이 아니면 `초기화 M/D HH:MM`.
  `resets_at_iso` 가 `null` 이면 **`.usage-reset` 요소를 아예 만들지 않습니다**
- `#usage-stale`: `age_seconds` 가 **600 을 넘으면** `N분 전 기준`(분은 내림, 60분 넘으면 `N시간 전 기준`),
  아니면 빈 글

### `style.css`
- `.usage-row` 는 한 줄에 라벨·막대·퍼센트·초기화가 **나란히**(flex), 좁은 화면(390px)에서도 **서로
  겹치지 않고** 카드 밖으로 **넘치지 않습니다**
- `.usage-ok .usage-fill` / `.usage-warn .usage-fill` / `.usage-crit .usage-fill` 의
  `background-color` 는 **셋이 서로 다릅니다** (평상 / 주의 / 경고). 이미 있는 변수
  (`--ok`·`--warn`·`--danger` 류)를 쓰십시오 - 없으면 `style.css` 위쪽 변수 선언을 보고 맞추십시오.
  밝은 테마·어두운 테마 양쪽에서 읽혀야 합니다
- `.usage-pct` 는 고정폭 숫자(`font-variant-numeric: tabular-nums`)

## 재야 할 것 (최소 12건 - **그려진 것**을 묻습니다)

바탕 상태 하나: `five_hour` 40%(초기화 2시간 뒤), `seven_day` 85%, `seven_day_opus` 97%,
`seven_day_sonnet` 12%(`resets_at` 없음). `at` 은 **지금**.

1. `#usage-section` 이 **함대 탭에서 보인다** (`is_visible()`), 그리고 **`#fleet-section` 보다 위에 있다**
   (`bounding_box()["y"]` 비교)
2. `.usage-row` 가 **넷**이고 `data-key` 차례가 `five_hour, seven_day, seven_day_opus, seven_day_sonnet`
3. 라벨 글이 `5시간 / 주간 / 주간·Opus / 주간·Sonnet`
4. `.usage-pct` 글이 `40% / 85% / 97% / 12%`
5. `.usage-fill` 의 **그려진 너비**가 퍼센트를 따른다 - `bounding_box()` 로 재서
   `fill.width / bar.width` 가 0.40 / 0.85 / 0.97 / 0.12 에 ±0.05 안
6. 행의 클래스가 `usage-ok / usage-warn / usage-crit / usage-ok`
7. **색이 셋 다 다르다** - `getComputedStyle(.usage-fill).backgroundColor` 를 세 행에서 읽어
   서로 다른 값인지 (`page.eval_on_selector`)
8. `seven_day_sonnet` 행에는 `.usage-reset` 요소가 **없다** (`count() == 0`), 나머지 셋에는 **있고**
   글이 `초기화 ` 로 시작한다
9. `five_hour` 의 `.usage-reset` 글이 **오늘 꼴**(`초기화 HH:MM`, 정규식 `^초기화 \d{1,2}:\d{2}$`)
10. `at` 이 **30분 전**인 저장소에서는 `#usage-stale` 글이 비어 있지 않다(`분 전 기준` 포함),
    `at` 이 **지금**인 저장소에서는 비어 있다 (저장소 두 개를 띄웁니다)
11. `.aimem/claude-usage.json` 이 **없는** 임시 저장소에서는 `#claude-usage .empty` 가 보이고
    글에 `상태줄` 이 들어 있다. `.usage-row` 는 0개
12. **390px 폭**에서 한 행의 라벨·막대·퍼센트·초기화가 **서로 겹치지 않는다**
    (`bounding_box()` 로 x 구간이 안 겹침) 그리고 **카드 밖으로 안 나간다**
    (각 요소의 `x + width <= #usage-section 의 x + width + 1`)
13. 1280px 와 390px 양쪽에서 `#usage-section` 이 **가로 스크롤을 만들지 않는다**
    (`document.documentElement.scrollWidth <= clientWidth + 1`)
