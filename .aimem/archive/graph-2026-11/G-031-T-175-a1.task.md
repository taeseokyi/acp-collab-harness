# T-175 한 줄 결함 - 지난 날 기록 정리가 엉뚱한 키를 지웁니다

고칠 파일은 **`projects/웹워들/web/js/storage.js` 하나**입니다. 다른 파일은 고치지 마십시오
(`tests/**` 도 금지 - 검사는 다른 슬롯이 씁니다).

## 결함

`init()` 안, 지난 날 기록을 지우는 고리(123행 근처):

```js
    const dailyPrefix = PREFIX + 'daily.';
    for (const k of [...memory.keys()]) {
      if (!k.startsWith(dailyPrefix)) continue;
      const day = k.slice(dailyPrefix.length);
      if (day !== today) remove(day);          // ← 여기
    }
```

`remove(key)` 는 **스스로 `PREFIX` 를 붙입니다.** 그런데 넘기는 값이 `day`(예: `2025-01-01`)라
실제로 지워지는 키는 `webwordle.2025-01-01` 입니다. 지워야 할 `webwordle.daily.2025-01-01` 은
그대로 남고, 부모에게도 엉뚱한 키의 `put` 이 나갑니다.

`ui.js` 는 `clearDaily` 를 부르지 않으므로 **이 고리가 유일한 정리 경로**입니다. 그래서 하루에
키가 하나씩 쌓여 61일째부터 키 64개 상한에 걸려 새 날의 판이 조용히 안 저장됩니다
(적대적 재검수 T-174 가 재현했습니다).

## 고칠 것 - 한 줄

      if (day !== today) remove('daily.' + day);
