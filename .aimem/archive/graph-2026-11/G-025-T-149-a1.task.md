## 할 일 1 - `build_words.py` 에 거르는 규칙

`load_words` 는 소문자 다섯 글자만 받습니다. 그래서 사전 원문을 한 번 더 읽어
**대문자로 시작하는 꼴이 사전에 있는지**를 알아야 합니다. `load_words` 바로 아래에
함수 하나를 더하십시오:

```python
def load_capitalized(path: Path) -> set[str]:
    """사전에 `Crane` 처럼 대문자로 적힌 다섯 글자 낱말의 소문자 꼴."""
    words: set[str] = set()
    with path.open(encoding="utf-8", errors="ignore") as handle:
        for line in handle:
            word = line.strip()
            if len(word) == 5 and word[0].isupper() and word.isalpha() and word.isascii():
                words.add(word.lower())
    return words
```

그리고 `main()` 의 위 네 줄을 아래로 바꾸십시오:

```python
    dictionary_words = [load_words(path) for path in DICTIONARIES]
    allowed = set().union(*dictionary_words)
    answers = dictionary_words[0].intersection(*dictionary_words[1:])
    answers = filter_answers(answers, allowed, capitalized)
```

`capitalized` 는 `dictionary_words` 를 만드는 줄 바로 다음에서 구합니다:

```python
    capitalized = set().union(*(load_capitalized(path) for path in DICTIONARIES))
```

`filter_answers` 를 `load_capitalized` 아래에 새로 쓰십시오. 거르는 규칙은 **넷**입니다:

```python
def filter_answers(answers: set[str], allowed: set[str], capitalized: set[str]) -> set[str]:
    """꼴만 보고 흔하지 않은 정답 후보를 거릅니다 (빈도 자료 없음).

    1. 고유명사 - 사전에 대문자 꼴이 함께 있으면 뺍니다 (`roman`/`Roman`)
    2. 복수형·3인칭 - `s` 로 끝나면 뺍니다 (전부터 있던 규칙)
    3. 굴절형 - `ed`/`er` 로 끝나고 그 어간이 허용 목록에 있으면 뺍니다 (`abler` <- `able`)
    4. 고어 꼴 - `eth`/`est` 로 끝나고 그 어간이 허용 목록에 있으면 뺍니다 (`doeth`)
    """
    kept: set[str] = set()
    for word in answers:
        if word in capitalized:
            continue
        if word.endswith("s"):
            continue
        if word.endswith(("ed", "er")) and _has_stem(word[:-2], allowed):
            continue
        if word.endswith(("eth", "est")) and _has_stem(word[:-3], allowed):
            continue
        kept.add(word)
    return kept


def _has_stem(stem: str, allowed: set[str]) -> bool:
    """어간 자체, 또는 `e` 를 붙인 꼴, 또는 끝 자음을 겹친 꼴이 사전에 있는가."""
    if len(stem) < 3:
        return False
    if stem in allowed or (stem + "e") in allowed:
        return True
    return len(stem) >= 4 and stem[-1] == stem[-2] and stem[:-1] in allowed
```

규칙 3·4 의 어간은 세 글자·네 글자라 `allowed`(다섯 글자만 있음)에 없을 때가 많습니다.
그러니 **사전 원문에서 길이를 가리지 않고 읽은 낱말 집합**이 따로 필요합니다.
`load_words` 를 그대로 두고, `main()` 에서 어간 조회용 집합을 따로 만드십시오:

```python
    stems = set().union(*(load_any_lowercase(path) for path in DICTIONARIES))
```

`load_any_lowercase` 는 `load_words` 와 같되 **길이 제한과 `WORD_RE` 없이**
`word.islower() and word.isalpha() and word.isascii()` 인 것을 모두 담습니다.
그리고 `filter_answers(answers, stems, capitalized)` 로 넘겨 `_has_stem` 이 `stems` 를
보게 하십시오(매개변수 이름 `allowed` 는 그대로 둬도 됩니다).

## 할 일 3 - `test_words.py` 에 검사 넷 더하기

이미 있는 검사는 지우지 말고, 클래스 끝에 메서드 넷을 더하십시오:

- `test_answer_count_range` - 지금 있는 `test_sizes` 의 `ANSWERS` 하한 `2_000` 을
  **`1_500`** 으로 낮춥니다(거른 뒤 수가 줄었습니다). `ALLOWED` 범위는 그대로 둡니다.
  이것은 새 메서드가 아니라 `test_sizes` 를 한 글자 고치는 일입니다
- `test_answers_exclude_inflected` - `ANSWERS` 에 `abler` 가 없음
- `test_answers_exclude_archaic` - `ANSWERS` 의 어떤 낱말도 `eth`/`est` 로 끝나지 않음
  (`west`·`best` 처럼 어간이 없는 것은 남아 있을 수 있으니, 단언은
  "`doeth`·`doest` 가 없다" 로 하십시오)
- `test_answers_subset_of_allowed_still` - `set(ANSWERS) <= set(ALLOWED)` (이미 있으면 건너뜀)
- `test_filtered_count_dropped` - `len(ANSWERS) < len(ALLOWED) / 2`
