# T-127 프로젝트 칸에 '실행' 단추와 격리된 미리보기 칸을 답니다 (화면)

## 무엇을 하는 일인가

앞 태스크(T-126)가 `/app/<프로젝트>/` 로 결과물을 내려 주는 길을 뚫었습니다.
**이 태스크는 사람이 그것을 누를 수 있게 하는 일입니다.**

## 고칠 파일 (이 셋뿐입니다)

- `tools/aimem_monitor/static/app.js`
- `tools/aimem_monitor/static/style.css`
- `tools/aimem_monitor/static/sw.js`

## 1. `app.js` - '실행' 단추

`renderProjects()` 안에 이미 이런 자리가 있습니다:

```js
if (pr.exists) {
  const view = linkButton('결과물 보기', () => openProjectFiles(pr));
  ...
}
```

그 **바로 앞**에, `pr.app && pr.app.runnable` 일 때만 단추를 하나 더 다십시오:

```js
const run = linkButton('실행', () => openProjectApp(pr));
run.classList.add('proj-run');
run.title = `${pr.app.title} 을(를) 모니터 안에서 바로 돌려 봅니다 (projects/${pr.name}/${pr.app.root}/)`;
```

`pr.app` 이 있는데 `runnable` 이 거짓이면 단추 대신 `proj-meta` 한 줄로
`실행 선언(app.json)에 문제가 있습니다: <pr.app.reason>` 을 보이십시오.

## 2. `app.js` - `openProjectApp(pr)`

`openProjectFiles(pr)` 바로 아래에 새 함수를 쓰십시오. 기존 `openPanel(제목, (body) => {...})` 틀을
그대로 씁니다. 패널 제목은 `프로젝트 <이름> 실행`. 본문에 **이 순서로** 넣으십시오.

1. 안내 한 줄 (`proj-meta`):
   `projects/<이름>/<root>/<entry> · 격리된 칸에서 돌아갑니다 - 기록(통계·설정)은 저장되지 않습니다`
2. `새 탭에서 열기` 링크. `<a href="/app/<이름>/" target="_blank" rel="noopener noreferrer">`,
   `title` 은 `새 탭에서는 기록이 저장됩니다`
3. 미리보기 `<iframe>`:

```js
const fr = document.createElement('iframe');
fr.className = 'proj-app-frame';
fr.src = '/app/' + encodeURIComponent(name) + '/';
fr.setAttribute('sandbox', 'allow-scripts allow-popups allow-modals');
fr.setAttribute('referrerpolicy', 'no-referrer');
fr.title = (pr.app.title || name) + ' 미리보기';
```

**`allow-same-origin` 을 절대 넣지 마십시오.** 넣는 순간 결과물 코드가 모니터와 같은 출처가 되어
인증된 세션으로 `/api/*` 를 부를 수 있게 됩니다. 격리는 전적으로 이 한 줄에 달려 있습니다.
(그 대가로 `localStorage` 가 막혀 기록이 안 남습니다 - 그래서 1번 안내와 2번 링크가 있습니다.
웹워들은 저장이 막히면 메모리로 넘어가므로 게임 자체는 그대로 돌아갑니다.)

`DEMO` 가 참이면 iframe 대신 `데모 화면에서는 실행할 수 없습니다` 한 줄만 보이십시오
(파일 목록 쪽이 `DEMO` 를 어떻게 다루는지 보고 똑같이 하십시오).

## 3. `style.css` - `.proj-app-frame` 과 `.proj-run`

```css
.proj-app-frame { display:block; width:100%; height:min(78vh, 900px); min-height:420px;
                  border:1px solid <선 색>; border-radius:8px; background:#fff; }
```

`<선 색>` 과 단추 색은 **이 파일에 이미 있는 CSS 변수**(`--line` 꼴)를 찾아 쓰십시오.
새 색을 만들어 내지 마십시오. `.proj-run` 은 `.proj-view` 와 같은 꼴로 두되 눈에 먼저 띄게만 하십시오.
좁은 화면(기존 미디어 쿼리 안)에서 `height` 를 `min(70vh, 640px)` 로 낮추십시오.

## 4. `sw.js` - v12 + `/app/` 우회

- `VERSION` 을 `'aimem-shell-v11'` → **`'aimem-shell-v12'`**
- `fetch` 처리에서 `/api/`·`/auth/`·`/login` 을 그냥 보내는 줄 **바로 옆**에
  `/app/` 으로 시작하는 경로도 그냥 네트워크로 보내도록 더하십시오.
  **결과물이 껍데기 캐시에 들어가면 고친 결과물이 화면에 안 나옵니다.** 한 줄 주석으로 이유를 적으십시오
