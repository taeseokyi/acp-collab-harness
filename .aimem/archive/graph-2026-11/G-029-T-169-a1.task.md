# T-169 표 두 가지 고치기 - 프로젝트 칸의 볼드 기준, 폰에서 생략된 제목 펼치기

  기준에 따라 명확한 볼드 처리 해."
- `Q-261111-2e0f`: "작업 트리, 태스크 그래프의 제목이 생략됐는데, 모바일 폰에서 전체 제목을 확인 못함."

고칠 파일은 둘뿐입니다. 다른 파일은 고치지 마십시오.

## 1. 프로젝트 칸의 볼드 기준 (`Q-261111-d64b`)

지금 `.proj-tag` 는 `font-weight: 500`, `.proj-tag.none` 은 `400` 입니다. 눈으로는 거의 구분이
안 되고, 이름과 라운드 꼬리표(`· R12`)가 한 덩이라 **무엇이 굵은 것인지 기준이 안 보입니다.**

**정할 기준: 굵은 것은 "프로젝트 이름" 하나뿐.** 함대 자체의 일(`함대`)도, 라운드 꼬리표도 굵지 않습니다.

### 1-1. `app.js` **1952~1958행**

지금:

```js
    const proj = document.createElement('span');
    proj.className = r.project ? 'proj-tag' : 'proj-tag none';
    proj.textContent = (r.project || '함대') + (r.round ? ` · R${r.round}` : '');
```

이름과 라운드를 **다른 span 으로** 나눕니다 (`proj.title = …` 두 줄은 그대로 두십시오).

```js
    const proj = document.createElement('span');
    proj.className = r.project ? 'proj-tag' : 'proj-tag none';
    const projName = document.createElement('span');
    projName.className = 'proj-name';
    projName.textContent = r.project || '함대';
    proj.appendChild(projName);
    if (r.round) {
      const projRound = document.createElement('span');
      projRound.className = 'proj-round';
      projRound.textContent = ` · R${r.round}`;
      proj.appendChild(projRound);
    }
```

`app.js` 에 `proj-tag` 를 쓰는 다른 곳이 있는지 `grep -n "proj-tag" tools/aimem_monitor/static/app.js`
로 확인하고, 있으면 **거기도 같은 꼴로** 고치십시오.

### 1-2. `style.css` **1312~1313행**

지금:

```css
.proj-tag { font-size: 13px; font-weight: 500; }
.proj-tag.none { color: var(--st-ink-muted); font-weight: 400; }
```

→

```css
/* 볼드 기준: 굵은 것은 '프로젝트 이름' 하나뿐이다. 함대 자체의 일과 라운드 꼬리표는 굵지 않다 (Q-261111-d64b) */
.proj-tag { font-size: 13px; font-weight: var(--st-fw-regular); }
.proj-tag .proj-name { font-weight: var(--st-fw-bold); }
.proj-tag.none { color: var(--st-ink-muted); }
.proj-tag.none .proj-name { font-weight: var(--st-fw-regular); }
.proj-tag .proj-round { color: var(--st-ink-muted); font-weight: var(--st-fw-regular); }
```

`--st-fw-regular`(400)·`--st-fw-bold`(700)·`--st-ink-muted` 는 이 파일 7행 근처에 이미 있습니다.

## 2. 폰에서 생략된 제목 펼치기 (`Q-261111-2e0f`)

생략된 칸(`.elide`)은 지금 `td.title` 로만 전문을 보여 줍니다. **폰에는 마우스 호버가 없어
영영 못 봅니다.** 칸을 누르면 그 자리에서 펼쳐지게 합니다. 표 하나만 고치지 말고
**`newTable` 한 군데**만 고치면 보드·큐·그래프 노드·실행 표가 한꺼번에 고쳐집니다.

### 2-1. `app.js` **272~275행** (`newTable` 안)

지금:

```js
      if (ellipsis.has(index)) {
        td.classList.add('elide');
        td.title = raw instanceof Node ? raw.textContent : show(raw, '');
      }
```

→

```js
      if (ellipsis.has(index)) {
        td.classList.add('elide');
        const full = raw instanceof Node ? raw.textContent : show(raw, '');
        td.title = full;
        // 폰에는 호버가 없어 title 을 볼 길이 없다 - 눌러서 그 자리에 펼친다 (요청 Q-261111-2e0f)
        if (full && full !== '-') {
          td.tabIndex = 0;
          td.setAttribute('role', 'button');
          td.setAttribute('aria-expanded', 'false');
          td.setAttribute('aria-label', '전문 보기: ' + full);
          const toggleFull = (event) => {
            event.preventDefault();
            event.stopPropagation();          // 행 전체의 '상세 보기' 가 같이 열리지 않게
            const open = td.classList.toggle('elide-open');
            td.setAttribute('aria-expanded', open ? 'true' : 'false');
          };
          td.addEventListener('click', toggleFull);
          td.addEventListener('keydown', (event) => {
            if (event.key === 'Enter' || event.key === ' ') toggleFull(event);
          });
        }
      }
```

### 2-2. `style.css` **353~357행**의 `.elide` 규칙 **바로 아래**에 더하기

```css
/* 눌러서 전문 보기 (Q-261111-2e0f) - 폰에는 호버 툴팁이 없다 */
.elide[role="button"] { cursor: zoom-in; }
.elide.elide-open {
  white-space: normal;
  overflow: visible;
  overflow-wrap: anywhere;
  text-overflow: clip;
  cursor: zoom-out;
}
```

기존 `.elide` 규칙은 **지우지 마십시오.**
