# T-097 웹워들 단어 목록

## 할 일

시스템 사전에서 워들 단어 목록을 뽑는 **생성기**, 그 **생성물**, 생성물을 재는 **검사** 셋을 만드십시오.
네트워크를 쓰지 않고 아무것도 설치하지 않습니다. 파이썬은 **표준 라이브러리만** 쓰고 `pytest` 는 없습니다.

- `projects/웹워들/tools/build_words.py` - 생성기
- `projects/웹워들/web/js/words.js` - 생성물 (생성기가 덮어씁니다)
- `projects/웹워들/tests/test_words.py` - 검사 (`unittest`)

## 뽑는 규칙

입력은 `/usr/share/dict/american-english` 와 `/usr/share/dict/cracklib-small` 입니다 (둘 다 이 기계에 있습니다).

- 각 사전에서 **`^[a-z]{5}$` 에 맞는 줄만** 취합니다 (고유명사와 아포스트로피 소유격은 이 조건에서 저절로 빠집니다)
- `ALLOWED`(허용 추측) = 두 사전의 **합집합**. 약 5,600개
- `ANSWERS`(정답 후보) = 두 사전의 **교집합**에서 **`s` 로 끝나는 낱말을 뺀 것**. 약 2,500개
  (NYT 의 정답 2,309개처럼 흔한 낱말만 남기고 복수형을 거르는 것이 목적입니다)
- 둘 다 알파벳 순으로 정렬, 중복 없음
- 사전 파일이 없으면 무엇이 없는지 찍고 `rc 1` 로 끝냅니다. **그럴 때 `words.js` 를 건드리지 않습니다**

## 생성물 형식 (`web/js/words.js`)

```js
// 생성물입니다 - 손으로 고치지 말고 `python3 projects/웹워들/tools/build_words.py` 로 다시 만드십시오.
// 출처: /usr/share/dict/american-english + /usr/share/dict/cracklib-small (YYYY-MM-DD 생성)
export const ANSWERS = [
  "aback", "abase", "abash", "abate", "abbey", "abbot", "abhor", "abide", "abode", "abort",
  ...
];
export const ALLOWED = [
  ...
];
```

한 줄에 열 개씩 끊어 사람이 열어 봐도 읽히게 하십시오. 두 배열 말고 다른 것을 내보내지 마십시오.

## 검사 (`tests/test_words.py`, `unittest`)

`words.js` 를 **텍스트로 읽어** 두 배열을 뽑아 재십시오 (정규식으로 충분합니다. node 를 부르지 않습니다).
경로는 `__file__` 에서 계산하십시오.

- 모든 낱말이 소문자 다섯 글자
- `ANSWERS` 2,000~3,000개 / `ALLOWED` 5,000~6,500개
- `ANSWERS` 가 `ALLOWED` 의 부분집합
- 각각 중복이 없고 알파벳 순으로 정렬되어 있음
- `ANSWERS` 에 `s` 로 끝나는 낱말이 없음
- `crane`, `about`, `ghost`, `vivid` 가 `ANSWERS` 에 있음

## 검증 (이 명령이 통과해야 합니다)

```bash
python3 projects/웹워들/tools/build_words.py && python3 -m unittest discover -s projects/웹워들/tests -p "test_words.py"
```
