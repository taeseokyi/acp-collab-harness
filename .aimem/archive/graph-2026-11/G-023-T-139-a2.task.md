## 수정 1 - 티켓이 서버 로그에 원문으로 남습니다 (검수 A 결함 2)

`/app/~<티켓>/<이름>/…` 의 티켓은 **12시간짜리 인가 수단**입니다. 지금은 요청줄이 그대로
표준오류로 나가고, `monitorctl.sh` 가 그것을 `.aimem/monitor.log` 로 보냅니다. 로그를 읽는 쪽이
티켓을 그대로 다시 쓸 수 있습니다(실측: 로그 6줄 중 5줄에 티켓 원문).

**(a)** `tools/aimem_monitor/server.py` 131행 `_LOG_SAFE = {...}` **바로 아래**에 다음을 더하십시오.

```python
#: 로그에 남는 `/app/~<티켓>/` 의 티켓을 가립니다. 티켓은 12시간짜리 인가 수단이라
#: 로그를 읽을 수 있는 쪽이 그대로 다시 쓸 수 있습니다 (R11 검수 A 결함 2).
_TICKET_LOG_RE = re.compile(r"/app/~[^/\s]+")
```

**(b)** 2236~2241행 `def log_message(self, fmt, *args):` 안에서, `line = "%s %s" % (...)` 다음 줄에
가리기를 넣습니다. 바꾼 뒤 모습은 이렇습니다(주석은 그대로 두십시오).

```python
    def log_message(self, fmt, *args):
        # 제어문자를 `\xNN` 으로 바꿉니다 - 요청 경로의 ESC 가 그대로 찍히면 로그를 보는
        # 터미널이 조종당합니다 (S4 검수 7번. 표준 구현의 치환을 덮어쓰면서 잃었던 것입니다).
        line = "%s %s" % (self.log_date_time_string(), fmt % args)
        line = _TICKET_LOG_RE.sub("/app/~***", line)      # 티켓은 가립니다 (R11 검수 A 결함 2)
        sys.stderr.write(line.translate(_LOG_SAFE) + "\n")
```

## 수정 2 - `Host` 헤더가 그대로 CSP 허용 출처가 됩니다 (검수 B 결함 1)

`_app_origin()` 은 Host 의 **꼴만** 보고 아무 이름이나 받아, `/app/` 응답 CSP 의
`script-src`·`connect-src`·`default-src` 에 넣습니다. `Host: evil.com` 으로 부르면 서버가
`script-src 'self' https://evil.com` 인 CSP 를 스스로 발급합니다(실측). 앞단 프록시나 DNS
리바인딩이 생기면 결과물(작업자 AI 가 쓴 코드)이 바깥 스크립트를 불러올 수 있는 길이 됩니다.

**(a)** `tools/aimem_monitor/server.py` 497행 `_ENV_KEYS = (...)` **위**에 상수와 함수를 더합니다.

```python
#: CSP 출처에 넣어도 되는 **추가** 호스트 이름 (쉼표로 나눔). 바깥 주소가 이름(도메인)이면
#: `.aimem/monitor.env` 에 `AIMEM_MONITOR_PUBLIC_HOSTS=aimem.example.org` 처럼 적습니다.
MONITOR_PUBLIC_HOSTS_ENV = "AIMEM_MONITOR_PUBLIC_HOSTS"


def _app_host_allowed(name):
    """그 호스트 이름을 `/app/` CSP 의 허용 출처로 써도 되는가 (R11 검수 B 결함 1).

    IP 리터럴·`localhost`·환경변수에 적은 이름만 참입니다. 아무 이름이나 받으면
    `Host: evil.com` 요청 하나로 서버가 evil.com 을 `script-src` 에 넣은 CSP 를 발급합니다.
    """
    n = (name or "").strip().lower().rstrip(".")
    if not n:
        return False
    if n == "localhost" or n.endswith(".localhost"):
        return True
    try:
        ipaddress.ip_address(n)
        return True
    except ValueError:
        pass
    extra = (os.environ.get(MONITOR_PUBLIC_HOSTS_ENV) or "").split(",")
    return n in {h.strip().lower().rstrip(".") for h in extra if h.strip()}
```

`ipaddress`·`os`·`re` 는 이미 import 돼 있습니다. **더 import 하지 마십시오.**

**(b)** 같은 파일 497행 `_ENV_KEYS = (KISTI_API_KEY_ENV, GITHUB_CLIENT_ID_ENV, GITHUB_CLIENT_SECRET_ENV)`
를 다음으로 바꿉니다(그래야 `.aimem/monitor.env` 에서 읽힙니다).

```python
_ENV_KEYS = (KISTI_API_KEY_ENV, GITHUB_CLIENT_ID_ENV, GITHUB_CLIENT_SECRET_ENV, MONITOR_PUBLIC_HOSTS_ENV)
```

**(c)** 2387~2392행 `def _app_origin(self):` 을 다음으로 바꿉니다.

```python
    def _app_origin(self):
        """요청 Host 로 만든 출처. 꼴 검사에 더해 **이름까지** 봅니다 (R11 검수 B 결함 1).

        허용하지 않는 이름이면 빈 문자열입니다 - CSP 는 `'self'` 만 남습니다.
        """
        host = (self.headers.get("Host") or "").strip() if self.headers else ""
        if not re.match(r"\A[A-Za-z0-9._:\[\]-]{1,100}\Z", host):
            return ""
        if host.startswith("["):                                   # IPv6 리터럴 `[::1]:18800`
            name = host[1:host.find("]")] if "]" in host else ""
        else:
            name = host.rsplit(":", 1)[0] if host.count(":") == 1 else host
        if not _app_host_allowed(name):
            return ""
        return ("https" if self.tls else "http") + "://" + host
```

운영은 IP 주소(`192.168.0.5:18800`)로 들어오므로 그대로 동작합니다. `localhost:18799` 도 그대로입니다.
