## 덧붙임 (관리자) - **먼저 고칠 것: 옛 이동 순서를 박아 둔 시험 하나**

다른 슬롯이 방금 N1 을 고쳐 실행 파일 이동 차례가 **`.rc` 가 맨 마지막**이 됐습니다.
그런데 R14 에 쓴 시험 하나가 **옛 차례(`.json` 이 마지막)** 를 그대로 단언하고 있어 빨간색입니다:

```
tests.test_aimem_db_cli.ArchiveAttachedRecordsTest.test_run_json_moved_last_so_plan_rediscovers_after_failure
  - ['run-900.brief.md', 'run-900.json', 'run-900.out']      <- 지금 실제 (새 차례)
  + ['run-900.brief.md', 'run-900.out',  'run-900.rc']       <- 시험이 기대하는 옛 차례
```

**시험이 틀렸습니다. 제품이 아니라 시험을 고치십시오.** 고칠 때:

- 시험 이름도 새 뜻에 맞게 바꾸십시오 (예: `test_rc_moved_last_so_plan_rediscovers_after_failure`)
- 단언을 "**`.rc` 가 맨 마지막**이고, 그 앞 어디에서 죽어도 다음 계획이나 고아 줍기가 받아 간다" 로
  바꾸십시오. `.rc` 없는 `.json` 이 남는 일이 없어야 한다는 것이 이 고침의 핵심입니다
- 이 시험을 **지우지 마십시오.** 뜻을 새 동작에 맞게 옮기는 것입니다
