## 읽을 것 (이것만)

세 자리를 모두 156 으로 맞추십시오.

- 13행 표: `rc 0, `통과 155 / 전체 155`` → `통과 156 / 전체 156`
- 15행: `ui 155/155` → `ui 156/156`. 그 줄은 2026-11-11 (T-125) 의 기록이므로
  **`2026-11-12 (R15 T-200) 에 ui 가 156/156 으로 하나 늘었습니다.` 를 한 문장 덧붙이고**
  155 를 156 으로 고치십시오
- 19행: ``browser_ui.py` 의 155 가운데 52 는 대비 측정이고` → `156 가운데 52 는`

숫자만 고치십시오. 표의 다른 칸, 다른 줄, 다른 파일은 건드리지 마십시오.
