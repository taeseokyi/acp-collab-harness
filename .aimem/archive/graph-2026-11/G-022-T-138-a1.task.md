# T-138 `tests/browser_monitor_auth.py` 가 **운영 기록을 더럽힙니다** - 임시 루트로 바꾸십시오

## 고칠 파일 (이 하나뿐입니다)

`tests/browser_monitor_auth.py` - 그중에서도 **`monitor_server()` 함수 하나**(44~61행)와
파일 맨 위의 import 줄입니다. **다른 함수는 건드리지 마십시오.**

## 지금 무엇이 잘못됐는가

`monitor_server()` 가 서버의 루트를 **저장소 자체**(`"root": ROOT`)로 둡니다. 이 검사는 로그인을
하므로, 돌릴 때마다 서버가 **운영 감사 기록 `.aimem/access.log` 에 `login-ok` 줄을 씁니다.**
검사가 운영 기록을 더럽히면 안 됩니다. 루트를 `/tmp` 아래 **임시 폴더**로 바꾸면 끝납니다.

## 이렇게 고치십시오

`monitor_server()` 의 `handler = type(...)` 줄 **앞에** 임시 루트를 만드는 코드를 넣고,
`"root": ROOT` 를 `"root": tmp` 로 바꾸고, `finally:` 에서 임시 폴더를 지웁니다.
아래 코드는 **관리자가 실제로 돌려 확인한 것**입니다. 그대로 쓰십시오.

```python
@contextmanager
def monitor_server():
    """인증 켠 http 모니터를 임시 포트 + **임시 루트**에 띄웁니다.

    루트를 저장소로 두면 로그인 기록이 운영 `.aimem/access.log` 에 남습니다 (R11 T-138).
    """
    tmp = pathlib.Path(tempfile.mkdtemp(prefix="browser-monitor-auth-"))
    (tmp / ".aimem").mkdir()
    shutil.copy(ROOT / ".aimem" / "aimem.db", tmp / ".aimem" / "aimem.db")
    shutil.copy(ROOT / "AIMEM.md", tmp / "AIMEM.md")
    (tmp / "projects" / "웹워들").mkdir(parents=True)
    shutil.copy(ROOT / "projects" / "웹워들" / "app.json", tmp / "projects" / "웹워들" / "app.json")
    shutil.copytree(ROOT / "projects" / "웹워들" / "web", tmp / "projects" / "웹워들" / "web")
    handler = type("H", (server.Handler,), {"root": tmp, "require_auth": True, "tls": False,
                                            "access_token": TOKEN, "guard": server.LoginGuard(),
                                            "timeout": 5, "log_message": lambda *a, **k: None})
    httpd = http.server.ThreadingHTTPServer(("127.0.0.1", 0), handler)
    httpd.daemon_threads = True
    thread = threading.Thread(target=httpd.serve_forever, daemon=True)
    thread.start()
    try:
        yield f"http://127.0.0.1:{httpd.server_address[1]}"
    finally:
        httpd.shutdown()
        httpd.server_close()
        thread.join(timeout=3)
        shutil.rmtree(tmp, ignore_errors=True)
```

파일 맨 위 import 에 **`import shutil`** 과 **`import tempfile`** 을 더하십시오(알파벳 순서로
`import pathlib` 앞뒤에 맞춰 넣으면 됩니다). `pathlib`·`threading`·`http.server` 는 이미 있습니다.
