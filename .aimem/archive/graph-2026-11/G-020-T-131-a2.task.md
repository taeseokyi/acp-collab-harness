# T-131 결과물이 `/app/웹워들/` 에서 **진짜로 그려지는지** 브라우저로 잽니다

## 쓸 파일 (이 하나뿐입니다)

`tests/browser_monitor_app.py` (**새 파일**)

## 배경 (이미 다 만들어져 있습니다)

모니터 서버에 `/app/<프로젝트>/...` 길이 뚫렸습니다. `projects/웹워들/app.json` 이
`{"root":"web","entry":"index.html"}` 이라, `http://<모니터>/app/웹워들/` 를 열면
`projects/웹워들/web/index.html` 이 그대로 나옵니다. **관리자가 직접 확인했습니다** -
200, `text/html`, 4015바이트. 당신이 할 일은 **그것이 브라우저에서 사람 눈에 어떻게 보이는지**를
재는 것뿐입니다. 서버도 앱도 고치지 않습니다.

## 뼈대 - 이대로 쓰십시오 (그대로 복사해도 됩니다)

```python
#!/usr/bin/env python3
"""<여기에 무엇을 재는 스크립트인지 한 줄>"""
import http.server
import pathlib
import sys
import threading
from contextlib import contextmanager

from playwright.sync_api import sync_playwright

ROOT = pathlib.Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT / "tools"))

from aimem_monitor import server          # noqa: E402


class Checks:
    def __init__(self):
        self.results = []

    def ok(self, goal, cond, detail=""):
        self.results.append((bool(cond), goal, detail))
        return bool(cond)

    def finish(self):
        failures = 0
        for passed, goal, detail in self.results:
            line = f"[{'OK' if passed else 'FAIL'}] {goal}"
            if detail:
                line += f" - {detail}"
            print(line)
            if not passed:
                failures += 1
        print(f"통과 {len(self.results) - failures} / 전체 {len(self.results)}")
        return failures


@contextmanager
def monitor_server():
    """인증 끈 평문 http 모니터를 임시 포트에 띄웁니다."""
    handler = type("H", (server.Handler,), {"root": ROOT, "require_auth": False, "tls": False,
                                            "access_token": None, "guard": server.LoginGuard(),
                                            "timeout": 5, "log_message": lambda *a, **k: None})
    httpd = http.server.ThreadingHTTPServer(("127.0.0.1", 0), handler)
    httpd.daemon_threads = True
    thread = threading.Thread(target=httpd.serve_forever, daemon=True)
    thread.start()
    try:
        yield f"http://127.0.0.1:{httpd.server_address[1]}"
    finally:
        httpd.shutdown()
        httpd.server_close()
        thread.join(timeout=3)
```

그리고 맨 아래:

```python
def main():
    checks = Checks()
    try:
        with monitor_server() as base:
            with sync_playwright() as pw:
                browser = pw.chromium.launch()
                try:
                    scenario(browser, base, checks)     # 아래에서 당신이 쓰는 함수
                finally:
                    browser.close()
    except Exception as exc:
        checks.ok("검사 실행", False, f"{type(exc).__name__}: {exc}")
    return checks.finish()


if __name__ == "__main__":
    raise SystemExit(main())
```

## `scenario(browser, base, checks)` 안에서 잴 것 (8개)

페이지 열기:

```python
ctx = browser.new_context(viewport={"width": 420, "height": 900})
page = ctx.new_page()
errors = []
page.on("pageerror", lambda e: errors.append(f"pageerror: {e}"))
page.on("console", lambda m: errors.append(f"console: {m.text}") if m.type == "error" else None)
resp = page.goto(base + "/app/웹워들/", wait_until="load")
page.wait_for_selector("#board .tile", timeout=10000)
```

1. **보드가 30칸** - `page.locator("#board .tile").count() == 30`
2. **보드가 눈에 보인다** - `#board` 가 `is_visible()` 이고 `bounding_box()` 의 `width`·`height` 가 둘 다 0보다 큼
   (`detail` 에 그 상자 숫자를 적으십시오)
3. **보드와 화면 키보드가 겹치지 않는다** - `#board` 와 `#keyboard` 의 `bounding_box()` 두 개가
   서로 교차하지 않음 (`a["y"] + a["height"] <= b["y"] + 1` 꼴로 재십시오)
4. **화면 밖으로 삐져나오지 않는다** -
   `page.evaluate("document.documentElement.scrollWidth <= window.innerWidth + 1")`
5. **글자를 치면 보인다** - `page.keyboard.type("crane")` 뒤 첫 줄 다섯 칸의 `text_content()` 가
   `C R A N E` (대문자/소문자는 실제 값을 보고 맞추십시오)
6. **제출하면 색이 실제로 칠해진다** - Enter 치기 **전** 첫 칸의
   `getComputedStyle(el).backgroundColor` 를 읽어 두고, `page.keyboard.press("Enter")` +
   `page.wait_for_timeout(2000)` 뒤 다시 읽어 **달라졌는지** 보십시오. 두 값을 `detail` 에 적으십시오
7. **CSP 가 내려온다** - `resp.header_value("content-security-policy")` 에
   `frame-ancestors 'self'` 가 있고 `frame-ancestors 'none'` 이 **없다**
8. **자바스크립트 오류가 하나도 없다** - 위에서 모은 `errors` 가 빈 목록
   (`detail` 에 `errors[:3]` 를 적으십시오)

끝에 `ctx.close()` 하십시오.
