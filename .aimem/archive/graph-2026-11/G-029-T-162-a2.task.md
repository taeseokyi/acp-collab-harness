## 무엇을 재는가

`storage.js` 는 `localStorage` 를 못 쓰고 부모 창이 있으면 **부모 모드**로 돕니다:
`{aimem:'store.v1', op:'ready'}` 를 부모에게 보내고, 부모가 `{aimem:'store.v1', op:'snapshot',
items:{키:문자열}}` 을 돌려주면 그것으로 메모리를 채웁니다. 그 뒤 쓰기마다
`{aimem:'store.v1', op:'put', key, value}` 를 부모에게 보냅니다(지우기는 `value: null`).

## 어떻게 가짜 부모를 만드나

`storage.js` 는 `globalThis.localStorage` / `globalThis.parent` / `globalThis.addEventListener` 와
`location.href` 만 씁니다. **import 하기 전에** 그것들을 `globalThis` 에 심으십시오.

```js
import test from 'node:test';
import assert from 'node:assert/strict';

const sent = [];
const listeners = [];
globalThis.location = { href: 'https://monitor.example/app/x/' };
Object.defineProperty(globalThis, 'localStorage', {
  configurable: true,
  get() { throw new Error('SecurityError'); },   // 격리된 칸 흉내
});
const fakeParent = { postMessage(m) { sent.push(m); } };
globalThis.parent = fakeParent;
globalThis.addEventListener = (type, fn) => { if (type === 'message') listeners.push(fn); };
globalThis.removeEventListener = (type, fn) => {
  const i = listeners.indexOf(fn); if (i >= 0) listeners.splice(i, 1);
};
const S = await import('../web/js/storage.js');
```

부모가 답하려면 `listeners` 에 걸린 함수를 직접 부르면 됩니다:

```js
const reply = (data, source = fakeParent) => { for (const fn of [...listeners]) fn({ source, data, origin: 'null' }); };
```

`init()` 은 `await` 하는 동안 답이 와야 하므로, `init()` 을 **await 하지 말고 먼저 부른 뒤**
`ready` 가 `sent` 에 들어온 것을 확인하고 `reply(...)` 를 부르고, 그다음 `await` 하십시오.

```js
const p = S.init();
await new Promise((r) => setTimeout(r, 0));
reply({ aimem: 'store.v1', op: 'snapshot', items: { settings: '{"hardMode":true}' } });
await p;
```

## 검사 여섯 개 (각각 `test(...)` 하나, 이름은 한국어로)

1. **ready 를 보낸다** - `init()` 뒤 `sent[0]` 이 `{aimem:'store.v1', op:'ready'}` 이고,
   `postMessage` 의 둘째 인자가 `'https://monitor.example'` 이다
2. **스냅숏이 읽기에 반영된다** - 위처럼 `settings` 를 넘긴 뒤 `S.loadSettings().hardMode === true`
3. **쓰기가 put 으로 나간다** - `S.saveSettings({hardMode:false,dark:true,colorblind:false})` 뒤
   `sent` 의 마지막이 `op:'put'`, `key:'settings'` 이고 `value` 가 **문자열**이며
   `JSON.parse(value).dark === true`
4. **지우기는 value 가 null** - `S.clearDaily('2026-11-11')` 뒤 마지막 메시지가
   `{op:'put', key:'daily.2026-11-11', value:null}`
5. **딴 데서 온 메시지는 무시한다** - `reply({aimem:'store.v1',op:'snapshot',items:{settings:'{"hardMode":true}'}}, {})`
   처럼 `source` 를 부모가 아닌 것으로 주면 설정이 바뀌지 않는다 (이 검사는 새 `init()` 왕복 안에서 재십시오)
6. **스냅숏이 안 오면 500ms 안에 포기한다** - 답하지 않고 `await init()` 하면 1,500ms 안에 끝나고
   그 뒤 읽기·쓰기가 예외 없이 된다

**검사 안에서 `storage.js` 를 고치지 마십시오.** 검사가 제품 결함을 드러내면 고치지 말고
첫 줄을 `NEEDS-FIX: <무엇이 어디서>` 로 보고하십시오.
