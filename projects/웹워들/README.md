# 웹워들 (Web Wordle)

브라우저에서 도는 워들. 뉴욕 타임즈 워들을 본으로 삼되, **의존성 없이** 표준 웹 기술(정적 HTML/CSS/ESM)과
파이썬 표준 라이브러리만 씁니다. 요청 `Q-261110-0437` (태석, 2026-11-10).

## 해 보기

```bash
python3 projects/웹워들/serve.py          # http://127.0.0.1:18811
python3 projects/웹워들/serve.py --port 9000
```

정적 파일만 내려주는 서버라 `web/` 을 다른 어떤 정적 서버에 올려도 그대로 돕니다. 백엔드가 없습니다 -
정답 판정도 통계도 전부 브라우저 안에서 끝납니다.

### 함대 모니터 웹에서 바로 실행

따로 서버를 띄우지 않아도 됩니다. 모니터의 **프로젝트** 칸에서 `웹워들` 의 **실행** 을 누르면
`projects/웹워들/web/` 이 `/app/웹워들/` 로 그대로 내려와 그 자리에서 돌아갑니다.
무엇을 어디서 내려 줄지는 `app.json` 한 장이 정합니다 (`root` · `entry` · `title`).

미리보기 칸은 **격리된 칸(sandbox)** 이라 `localStorage` 가 막힙니다 - 게임은 그대로 돌지만
통계·설정이 저장되지 않습니다(저장이 막히면 메모리로 넘어갑니다). 기록을 남기며 하려면
같은 패널의 **새 탭에서 열기** 를 쓰십시오.

## 규칙 (NYT 워들과 같게)

- 다섯 글자 영어 단어를 여섯 번 안에 맞춥니다
- 🟩 자리까지 맞음 · 🟨 단어에 있지만 다른 자리 · ⬛ 없음
- **같은 글자가 겹칠 때**: 정답에 있는 개수만큼만 색이 붙습니다. 자리 맞은 것이 먼저 가져가고, 남은 것만
  노랑이 됩니다 (정답 `crane`, 추측 `nanny` → `⬛🟨⬛🟩⬛`)
- 사전에 없는 단어는 받지 않습니다 (흔들림 + 안내)
- **오늘의 단어는 모두에게 같습니다** - 날짜에서 정답을 뽑으므로 서버가 필요 없습니다

### NYT 와 일부러 다르게 한 곳

**칸 안의 글자색.** NYT 는 모든 칸에 흰 글자를 쓰는데 그러면 초록 칸이 2.78:1, 노랑 칸이 2.07:1 로
WCAG 기준(4.5:1)에 크게 못 미칩니다. 여기서는 **칸 색은 NYT 와 똑같이 두고 글자색만** 밝은 칸에서
검게(`#121213`) 바꿔 전부 4.5:1 을 넘겼습니다. 팔레트를 어둡게 바꾸면 워들처럼 보이지 않기 때문입니다.

## 폴더

```
웹워들/
  README.md          이 파일
  PROGRESS.md        목표 체크리스트 + 라운드별 기록 (다음 라운드 관리자가 먼저 읽는 파일)
  package.json       {"type":"module"} 표시만 - 의존성 없음 (node 로 테스트하기 위한 것)
  serve.py           로컬 실행용 정적 서버 (표준 라이브러리)
  web/
    index.html       화면
    css/style.css    테마(밝음/어두움/색약), 타일·키보드 모양, 애니메이션
    js/game.js       순수 로직 - DOM 을 모름 (판정·오늘의 단어·키보드 상태·하드 모드·공유 문구)
    js/words.js      단어 목록 (생성물 - 손으로 고치지 않고 tools/build_words.py 로 다시 만듦)
    js/storage.js    localStorage - 통계와 진행 중인 판
    js/ui.js         DOM·입력·애니메이션. 위 세 파일을 불러 붙이는 진입점
  tools/build_words.py   시스템 사전에서 words.js 를 생성
  tests/
    test_game.mjs          로직 테스트      node --test projects/웹워들/tests/*.mjs
    smoke_integration.mjs  통합 연기 테스트  (위와 같은 명령에 함께 걸림)
    test_words.py          단어 목록 테스트  python3 -m unittest discover -s projects/웹워들/tests
```

## 단어 목록

`/usr/share/dict/american-english` 와 `cracklib-small` 에서 뽑습니다 (네트워크·내려받기 없음).

- **허용 추측** = 두 사전의 합집합 중 소문자 다섯 글자 (약 5,600개)
- **정답 후보** = 두 사전의 교집합에서 `s` 로 끝나는 복수형을 뺀 것 (약 2,500개 - NYT 의 2,309개와 비슷한 규모)

다시 만들려면 `python3 projects/웹워들/tools/build_words.py`.

## 하지 않는 것

프레임워크·CDN·폰트·빌드 단계·백엔드·계정. `node` 는 테스트에서만 쓰고 게임은 브라우저만으로 돕니다.
