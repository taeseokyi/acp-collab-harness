# 낱말 원본

`answers.txt` 는 정답 후보, `allowed.txt` 는 정답은 아니어도 추측으로 받아 줄 낱말입니다.
`tools/build_words.py` 가 두 파일을 읽어 `web/js/words.js` 를 만듭니다.

## 고른 기준

- **기계적으로 같은 첫 음절에 붙인 두 음절 조합은 넣지 않았습니다.** `정*`·`염*`·`역*`처럼
  같은 첫 음절로 대량 생성된 묶음과 사전에 없는 조합을 걷어 냈습니다.
- **표준 국어사전에 있다고 확인한 일상어와 덜 흔한 표준어를 직접 골랐습니다.** 흔한 말을
  우선했고, 일상에서 덜 쓰는 표준어는 추측 허용 목록에만 두었습니다.
- `allowed.txt` 는 **1000개 이상**(현재 1033개)이고, 빌드 뒤 `answers.txt` 와 합친 ALLOWED 도
  **1000개 이상**(현재 1033개)입니다.
- 흔한 6칸 낱말 `아버지 어머니 이야기 무지개 과학 성공 걱정 칭찬 웃음 떡국 짬뽕 아파트
  낮잠 첫눈 왕자 군인 직장 성적 색깔 천둥 칫솔 책장 촛불 손톱 꽃밭 연못 작년 일년
  요리사 사이다` 를 모두 넣었습니다.
- 명사뿐 아니라 동사·형용사 기본형(`읽다`, `없다`, `많다`, `앉다`, `예쁘다`, `기쁘다` 등),
  받침 있는 두 음절(`건강`, `학생`, `낙엽`, `공책`), 받침 없는 세 음절(`코끼리`, `바나나`,
  `고구마`), 겹모음·겹받침이 섞인 꼴(`과학`, `까닭`, `열쇠`)을 함께 골랐습니다.
- 정답 후보는 **380개**이며, 누구나 아는 일상어만 남겼습니다. 민감어(`흑인`, `살인`),
  고유명사(`북한`, `중국`, `한강`, `한글`, `금산`, `금강`), 비속어(`염병`, `강간`),
  성적인 말(`정욕`, `정액`), 신조어(`먹방`), 낱말이 아닌 것(`급강`, `급경`, `멍청`),
  지어낸 말은 정답에서 뺐습니다. 드문 표준어는 정답이 아니라 `allowed.txt` 에만 두었습니다.
- 고유명사·비속어·성적인 말·민감어는 `allowed.txt` 에도 넣지 않았습니다.
- 한 첫 음절로 시작하는 낱말이 40개를 넘지 않게 했습니다.
- 자모로 풀면 **꼭 6칸**이 되는 낱말만 남깁니다. 칸 세기는 한 칸 = 두벌식 자판 한 번 누름이고,
  쌍자음(`ㄲ ㄸ ㅃ ㅆ ㅉ`)과 `ㅐ ㅔ ㅒ ㅖ` 는 한 칸, 겹모음(`ㅘ ㅙ ㅚ ㅝ ㅞ ㅟ ㅢ`)과
  겹받침(`ㄳ ㄵ ㄶ ㄺ ㄻ ㄼ ㄽ ㄾ ㄿ ㅀ ㅄ`)은 두 칸입니다.
- 6칸이 아닌 줄이 섞여 있어도 빌드가 걸러 냅니다. `answers.txt` 를 걸러 낸 뒤 300개 이상,
  `answers.txt ∪ allowed.txt` 를 걸러 낸 뒤 1000개 이상이어야 합니다.

## 금칙어 시험

`tests/test_words.py` 의 `BANNED` 가 위 비속어·성적인 말·고유명사·민감어·지어낸 말을
ALLOWED 에서 찾습니다. 같은 시험이 흔한 낱말(`MUST`)의 존재와 첫 음절 쏠림(40 이하)도
검사합니다. 다시 빌드 시험은 `build_words.py --out <임시 경로>` 로 임시 폴더에 만들고,
진짜 `web/js/words.js` 를 건드리지 않습니다.

## 출처

**함대 작업자가 직접 고름.** 외부 게임(꼬들 등)·사전의 낱말 목록을 복사하거나 내려받지
않았습니다. 낱말 자체는 저작물이 아닙니다.

## 이용 조건

이 목록 파일은 이 저장소와 같은 조건을 따릅니다.

## 다시 만드는 명령

```bash
python3 projects/자모맞히기/tools/build_words.py
```

출력 위치를 바꾸려면 `--out` 을 줍니다.

```bash
python3 projects/자모맞히기/tools/build_words.py --out /tmp/words.js
```

같은 입력이면 매번 바이트 단위로 같은 `web/js/words.js` 가 나옵니다.
정답 후보(ANSWERS)는 `random.Random(20261113)` 으로 섞고, 추측 목록(ALLOWED)은 정렬합니다.

## 검사

```bash
python3 -m unittest discover -s projects/자모맞히기/tests -p 'test_words.py'
```
