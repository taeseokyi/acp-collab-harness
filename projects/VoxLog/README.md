# VoxLog (복스로그)

폰에서 음성 녹음을 쉽게 남기고 쌓아, 크롬 앱(PWA)에서 여러 방식으로 찾아보고 클로드에게 묻는 녹취 기록 앱.
(요청 `Q-261116-fa85`, R33 에서 시작)

## 무엇을 하나

1. **녹음** - 폰의 VoxLog 앱(설치한 PWA)에서 큰 단추 하나로 녹음 시작·멈춤. 멈추면 음성 파일이 생깁니다.
2. **올리기** - 녹음을 시작할 때 **위치정보**(위도·경도·정확도, 설정에서 끌 수 있음)를 함께 얻습니다. 음성 파일과 위치는 기기 안 대기열(IndexedDB)에 먼저 들어가고 백엔드 API 로 올라갑니다.
   네트워크가 끊겼으면 **Background Sync** 로 기다렸다가 연결되면 자동으로 올립니다(지원 안 하는 브라우저는 앱을 열거나
   온라인이 될 때 올림).
3. **받아쓰기** - 서버가 받은 음성을 텍스트로 인식해 `data/transcripts/<날짜>/<id>.txt` 로 쌓습니다.
4. **조회** - 녹취 현황(날짜별 수·글자 수), 검색·날짜 거르기, 녹음 다시 듣기, 받아 적은 글 보기.
5. **이름·태그** - 녹취 상세에서 이름(40자까지)과 태그(쉼표로 나눔, 하나 20자·최대 10개)를 직접 붙이고 고칩니다.
   목록에는 이름과 태그 칩이 보이고 칩을 누르면 그 태그로 거르며, 검색은 글·이름·태그를 함께 찾습니다.
   받아쓰기가 끝나면 **AI가 태그를 자동으로 달아** 바로 저장합니다(AI가 단 칩은 점선). 사람이 태그를 한 번 고친 뒤로는
   다시 받아쓰기해도 자동 태그가 그 녹취의 태그를 바꾸지 않고, 필요하면 상세의 '태그 다시 달기'로 직접 다시 달립니다.
   묻기(LLM)를 쓸 수 없는 설정에서는 자동 태그만 빠지고 나머지는 그대로입니다.
6. **묻기** - 고른 녹취(또는 오늘·이번 주·검색 결과)로 요약·핵심어·할 일 뽑기·직접 묻기를 요청하면 서버가
   **claude CLI** 로 답을 만들고 앱에 보여 줍니다. 답은 쌓여서 다시 볼 수 있습니다.
7. **끊긴 녹음 되살리기** - 녹음 중 페이지가 죽거나 새로 고쳐져도, 기기에 저장해 둔 녹음 조각을 살려 대기열에 넣습니다.
   녹음 탭은 초안마다 웹 잠금(`voxlog-draft-<id>`)을 쥐고, 다른 탭은 그 잠금이 비었는지 바로 보아 죽은 탭의 초안을 거둡니다.
8. **받아쓰기 옵션** - 웹에서 받아쓰기 서버로 보내는 **전처리**(`preprocess`)·**화자 수**(`num_speakers`)·**문맥 글**(`context`)·
   **자동 추정**(`auto`)·**LLM 검토**(`review`)를 고릅니다. 앱 전체 기본값은 설정 칸에서, 한 녹음만의 값은 상세의
   '옵션 바꿔 다시 받아쓰기'에서 고릅니다.

### 받아쓰기 옵션

- **어디서 고르나** - 설정의 '받아쓰기 옵션 (새 녹음과 다시 받아쓰기의 기본값)' 묶음은 새 녹음과 옵션을 고르지 않은
  녹음에 쓰이는 전체 기본값을 저장합니다. 녹취 상세의 '옵션 바꿔 다시 받아쓰기'는 그 녹음만의 옵션을 골라 바로 다시
  받아씁니다. 있는 '다시 받아쓰기'는 지금 옵션 그대로 다시 받아쓰는 단추로 남아 있습니다.
- **기본은 지금과 같습니다** - 아무것도 고르지 않으면 예전과 똑같이 서버로 `language`·`model` 만 보냅니다. 그러면
  받아쓰기 서버의 기본값(전처리 `level`)이 쓰입니다. 전처리 다섯 값은 `none`·`basic`·`level`·`dereverb`·`denoise` 입니다.
- **denoise 는 보장이 아닙니다** - 잡음이 많은 녹음은 `denoise` 로 말소리가 잡힐 수 있지만(이번 안내방송 녹음 실측),
  소음이 너무 큰 녹음은 그래도 내용이 맞지 않을 수 있습니다. 깨끗한 녹음에서는 오히려 받아쓰기를 나쁘게 할 수 있어
  서버 기본은 `level` 입니다.
- **문맥 글 주의** - 용어·이름을 알려 주는 문맥 글은 조용한 구간에 새어 나오거나 낱말이 끌려갈 수 있어 기본은 비워 둡니다.
  서버로 보낼 때 `\r\n`·`\r`·U+2028·U+2029 는 줄바꿈(`\n`)으로 바꾸고, 형식·제어 문자와 외톨이 서로게이트는 빼되
  줄바꿈·탭과 이모지 묶음에 쓰이는 ZWJ(U+200D)·깃발 태그 문자(U+E0020~U+E007F)는 남깁니다.
- **저장** - 전체 기본값은 자료 폴더의 `stt_options.json`, 녹음마다는 그 녹음 메타의 `stt_options` 에 둡니다.
  `settings.json` 은 건드리지 않으므로 받아쓰기 서버 주소·모델·API 키가 웹이나 이 자료 파일로 나가지 않습니다.
- **녹음 옵션은 전체 기본값과 합치지 않습니다** - 녹음에 저장된 옵션이 하나라도 있으면 그 옵션만 쓰고 앱 전체 기본값과
  키 단위로 합치지 않습니다. 녹음 옵션이 없거나 빈 값(`{}`)이면 전체 기본값을 따릅니다. 화면이 다시 받아쓰기에 보내는
  `{"options": {}}` 도 옵션 없음(null)과 같은 뜻이라 전체 기본값을 따릅니다.
- **다시 받아쓰기의 뒤처리** - 성공하면 글은 새 글로 바뀌고 바뀌기 전 글은 '지난 글'에 받아쓴 순서대로 남습니다
  (`prev_transcripts` - 벌마다 `{text, stt_used, at}`, 최근 것이 앞, 최대 `PREV_KEEP=5`벌, 같은 글은 늘리지 않음).
  실패하면 글은 그대로이고 까닭만 남습니다. 받아 적은 글이 비면(소리가 없거나 말소리가 잡히지 않은 경우)도 실패로
  끝나며 까닭에 `받아 적은 글이 비었습니다 - 소리가 없거나 …` 가 남고, 지금 글·지난 글은 그대로입니다. 이름·사람이 직접 고친 태그·묻기 답은
  그대로입니다. AI 태그는 새 글로 다시 달리며, 사람이 태그를 고친 녹취는 자동 태그가 그 태그를 바꾸지 않습니다.
  화면 상세에 '받아쓴 옵션' 한 줄과 '지난 글 N벌' 접어 둔 목록이 보입니다.

### 끊긴 녹음 되살리기의 열화

**웹 잠금(`navigator.locks`)이 없는 브라우저에서는 녹음·올리기는 그대로 되고, 페이지가 죽었을 때의 되살리기만 꺼집니다.**
웹 잠금은 Chrome 69+, Firefox 96+, Safari/iOS 15.4+ 에서 되며 **HTTPS**(또는 localhost)가 필요합니다. 없으면 초안을 만들지 않고,
녹음이 끝날 때 메모리의 조각으로 대기열에 넣습니다. 얼어 있는(frozen) 녹음 탭의 초안은 그 탭이 풀리거나 버려질 때까지
회수되지 않는 맞바꿈이 있습니다.

## 측면(전원) 버튼으로 녹음 시작·멈춤

웹 앱(PWA)은 전원 버튼 누름을 직접 받을 수 없습니다(안드로이드가 어떤 앱에도 주지 않음). 그래서 이렇게 잇습니다.

- 앱은 **열릴 때마다 녹음을 켜고 끄는 신호**를 받습니다: 매니페스트 `launch_handler: focus-existing` + `launchQueue`.
  이미 떠 있는 VoxLog 를 다시 열면 새 창 대신 그 창에 "열림" 이 전달되고, 설정 '앱을 열면 바로 녹음' 이 켜져 있으면
  녹음 중이 아니면 시작, 녹음 중이면 멈춥니다.
- **삼성 갤럭시:** 설정 → 유용한 기능 → 측면 버튼 → **두 번 누르기 → 앱 열기 → VoxLog**. 측면 버튼 두 번 = 녹음 시작,
  다시 두 번 = 멈춤.
- 다른 안드로이드: 아이콘 길게 누르기 → '녹음 시작/멈춤' 바로가기(매니페스트 `shortcuts`)를 홈 화면에 두거나,
  버튼을 앱 실행에 묶는 도구(제조사 설정, Key Mapper 등)로 VoxLog 를 엽니다.
- 녹음 중 화면이 꺼지면 크롬이 녹음을 멈출 수 있어, 녹음 중에는 화면 켜짐 유지(Wake Lock)를 씁니다.
- 다른 앱으로 녹음한 파일은 녹음 탭의 '녹음 파일 올리기'로 올립니다(m4a·mp3·wav·ogg·webm, 50MB 까지. 기록 날짜는 파일 날짜가 아니라 올린 날).

## 실행

```bash
cd projects/VoxLog
python3 serve.py                                   # http://127.0.0.1:8790 (이 컴퓨터에서만)
python3 serve.py --host 0.0.0.0 --token <비밀> --tls-cert cert.pem --tls-key key.pem   # 폰에서 쓸 때
```

- 폰의 크롬에서 마이크·서비스 워커를 쓰려면 **HTTPS**(또는 localhost)여야 합니다. 밖에 열 때는 토큰이 필수입니다
  (루프백이 아닌 주소에 토큰 없이는 시작을 거절).
- 음성인식 백엔드 (`VOXLOG_STT`):
  - `command` - `VOXLOG_STT_CMD="whisper-cli -m model.bin -f {wav} -nt -l ko"` 처럼 받아쓰기 명령(16kHz 모노 wav 를 받음)
  - `api` - `VOXLOG_STT_URL` 의 화자 구분 받아쓰기 서버 작업 API(`…/v1/audio/diarize/jobs`). 모델 `VOXLOG_STT_MODEL`,
    언어 `VOXLOG_STT_LANG`(기본 `ko`), 키 `VOXLOG_STT_API_KEY`. 지금 설정(`settings.json`)은 KISTI 의 `Qwen3-ASR-1.7B`
  - 녹음은 자르지도 다시 압축하지도 않고 원본 그대로 작업으로 맡긴 뒤 10초마다 조회해 결과를 받습니다(한 요청을 오래 붙들지 않아
    긴 녹음도 중간에 끊기지 않음). 서버가 돌려준 `segments`(`speaker`·`text`)를 `화자 1: …` 줄로 적고, 서버가 화자를 정하지 못한
    짧은 소리는 `화자 ?` 로 적습니다. 맡긴 작업 id 를 적어 두어 앱 서버가 다시 떠도 같은 작업을 이어 기다리고, 결과를 받으면
    서버에 남은 것은 바로 지웁니다
  - 없으면 녹음은 쌓이고 상태가 '음성인식 없음' - 나중에 백엔드를 켜고 '다시 받아쓰기'
  - 음성 변환에 `ffmpeg` 가 필요합니다
- 녹취 상세의 받아쓴 글도 '복사'·'공유'로 그대로 내보냅니다(글이 있을 때만 단추가 보임)
- 받은 답은 '복사'·'공유'(기기의 공유 창, 지원하는 기기만)로 마크다운 원문을 내보내고, '지난 답'에서 지울 수 있습니다(묻는 중인 답은 못 지움).
- 묻기는 `claude` CLI(`claude -p`, 도구 없이)를 씁니다. 다른 명령은 `VOXLOG_LLM_CMD`.
  답은 화면에서 마크다운으로 그립니다(`web/md.js` - 제목·목록·표·인용·코드·굵게·링크. HTML 은 글자로 보임).
- 데이터는 `data/`(git 제외) 또는 `VOXLOG_DATA`. 받아쓰기 전체 기본 옵션은 `data/stt_options.json` 에 쌓입니다(없으면 옵션 없음).
- 서버 설정은 `settings.json` 의 `VOXLOG_*` 값 위에 환경 변수를 덮은 것입니다(환경 변수가 이김). `settings.json` 은 git 제외 -
  `settings.example.json` 을 복사해 주소를 채웁니다. 모니터의 '앱 열기'·배포는
  환경을 좁혀 띄우므로 음성인식 주소·모델은 이 파일에 둡니다. 비밀 값은 넣지 않습니다.

### 모니터 '앱 열기'

`app.json` 의 `"server": "serve.py"` 로 모니터가 서버를 띄워 이어 주므로 **녹취 목록·검색·묻기는 모니터에서도 됩니다.**
다만 모니터의 앱 화면은 격리된 출처(sandbox)라 서비스 워커·IndexedDB·마이크가 없고, 모니터의 앱 API 본문 상한이
64KB 라 **녹음과 올리기는 VoxLog 자체 주소에서** 합니다. 화면이 이를 알아보고 안내합니다. 모니터에서는 지우기·이름·태그 편집
단추가 숨고(모니터가 DELETE·PATCH 를 이어 주지 않음), 2MB 가 넘는 음성(64kbps 로 약 4분)은 응답 상한 때문에 자체 주소에서 듣습니다.

## 폴더

```
serve.py            HTTP 서버 (정적 web/ + /api/*)
voxlog/             store.py(저장소) · stt.py(음성인식) · stt_options.py(받아쓰기 옵션) · ask.py(클로드 묻기)
web/                화면(index.html·app.js·api.js·style.css) · 서비스 워커(sw.js)·대기열(queue.js) · 매니페스트·아이콘
tests/              단위 검사(python3 -m unittest discover -s tests) · 끝에서 끝 브라우저 검사(browser_voxlog.py)
docs/INTERFACE.md   모듈·API·전역 객체의 약속
data/               실행 데이터 (git 제외)
```
