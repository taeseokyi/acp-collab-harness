## 2. 결과물은 프로젝트 폴더에, 라운드 폴더에는 기록만
요청마다 프로젝트가 붙어 옵니다(`request list` 의 `[이름]`). 결과물은 **`projects/<프로젝트>/` 한 곳에 여러 라운드에 걸쳐 쌓입니다.**
- **시작할 때** `projects/<프로젝트>/PROGRESS.md` 를 먼저 읽습니다. 폴더가 없으면 새 프로젝트이니 만들고 `README.md`(무엇을 만드는지, 폴더 구조)를 씁니다.
- **목표.** `PROGRESS.md` 맨 위(제목 바로 아래)에 `## 목표` 체크리스트(`- [ ]` / `- [x]`)를 둡니다. 새 프로젝트면 요청과 README 를 보고 **끝까지 가는 데 필요한 목표를 예측해** 5~15개로 씁니다(이번 라운드 몫만이 아님). 이어받은 프로젝트면 끝난 것을 체크하고, 새로 드러난 목표는 덧붙이고, 필요 없어진 것은 지우고 그 사실을 라운드 항목에 한 줄 적습니다. 검증까지 끝난 것만 체크합니다.
- **만들 때** 이미 있는 결과물을 이어서 고칩니다. 라운드 번호가 붙은 사본(`v2`, `R29-…`)을 만들지 않습니다.
- 작업자에게 쓰게 하려면 먼저 `python3 tools/aimem_db.py ownership set --path "projects/<프로젝트>/<하위 경로>/**" --owner S<n> --note "R29"`. 같은 파일을 두 슬롯에 주지 않습니다.
- **끝날 때** `## 목표` 의 체크를 실제 상태에 맞추고, 그 절 바로 아래에 `## R29 (날짜)` - 한 일, 바뀐 파일, 검증한 방법, **남은 일** - 을 덧붙입니다(최신이 위). 다음 관리자가 이것만 읽고 이어받을 수 있어야 합니다.
- 태스크는 `aimem_db.py task set --id T-xxx --request <요청 id> …` 로 요청에 잇고, 그래프 노드에는 `"project": "<프로젝트>"`(폴더 이름 하나)를 적습니다(함대 자체 일이면 생략). 작업 중 생긴 요청은 `aimem_db.py request set --id <id> --title … --project <프로젝트>`.
- **프로젝트가 비어 있는 요청**은 함대 자체의 일입니다(`tools/`, `tests/`, `AIMEM.md`) - 제자리에서 고칩니다.
- **`rounds/R29/` 는 이 라운드의 기록 폴더**입니다: `brief.md`(이 브리프, 고치지 않음)와 `REPORT.md`(종료 보고 전문 - 응답 본문에도 씀. 프로젝트별로 무엇이 어디에 쌓였는지 경로를 적습니다). 결과물은 여기 두지 않습니다.

## 3. 턴 규칙
- **사람이 남긴 말** `rounds/R29/INBOX.md`(`fleet_ctl.py tell`)는 시작할 때, 그래프를 만들기 전, 체크포인트마다 읽습니다. 같은 요청 안에서는 이 말이 요청 본문보다 앞섭니다.
- **기다리기:** `python3 tools/fleet_graph.py run <그래프> --timeout 570` 을 **포그라운드로** 돌리고, rc 1 이고 아직 도는 노드가 있으면 다시 돌립니다(셸 도구가 한 명령을 10분에서 끊습니다). `--poll`·`setsid nohup … &` 는 쓰지 않습니다. rc: 0 다 끝남 · 1 덜 끝남이나 노드 실패·막힘 · 2 검증·잠금 · 3 함대 완전 중지 · 4 `INBOX.md` 에 새 말(읽고 판단한 뒤 다시 `run`). 보고를 본문에 다 쓰기 전에는 턴이 끝나지 않습니다.
- **함대 모드.** 출력에 `함대 모드: paused|ready` 가 찍히면 새 노드가 안 뜨는 것이니 기다립니다. rc 3(완전 중지)이면 우회하지 말고(`AIMEM_FLEET_FORCE` 금지) 체크포인트를 남긴 뒤 `상태: PARTIAL` 로 보고하고 끝내십시오.
- **슬롯을 어떻게 쓸지는 이 라운드의 운영 방식**(브리프 맨 끝 '운영 방식' 절)을 따릅니다. 막힌 노드를 옮길지도 거기 적혀 있습니다.
- **큰 출력은 직접 읽지 않습니다.** 작업자 보고는 첫 줄과 요약만, 테스트·린터는 `| tail -20` 또는 실패 줄만, diff 는 `git diff --stat` 뒤 해당 hunk 만.
- 커밋·푸시·삭제·설치는 하지 않고, 함대 모드를 우회하지 않습니다. 커밋은 라운드가 끝난 뒤 클로드 코드가 합니다.
