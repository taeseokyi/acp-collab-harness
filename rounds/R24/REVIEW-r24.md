## 6. 총평

웹워들을 뼈대로 삼은 덕분에 판 흐름·저장 손상 처리·배치·접근성 바탕은 이미 단단하고, 새로 짠 `jamo.js`(풀기·조합·받침 넘김·겹모음/겹받침)와 칸 단위 판정은 정확하며 단위 시험이 잘 지킨다. 한글 입력기 상태(`Process`)에서도 실물 자판이 실제로 돈다. 1차를 닫지 못하게 하는 것은 두 가지다. 첫째, **낱말 목록**: 추측 목록이 개수 조건을 맞추려고 `정*`·`염*`·`역*` 조합으로 부풀려져 비속어와 지어낸 말이 들어갔고, 정작 `어머니`·`이야기` 같은 말은 거절된다. 정답 후보에도 `흑인`·`살인`·`급강` 같은 것이 섞였다. 이것은 README 의 출처 서술과도 어긋나므로 사람이 보는 손질이 필요하다. 둘째, 웹워들에 없던 **모드 오가기**에서 상태(토스트·타이머·하드 모드)가 판에 묶이지 않고 새며, Enter 가 모드 단추를 누르지 못한다. 어두운 모드의 시스템 설정 따름은 웹워들 때부터 빠져 있던 것이다. 낱말 목록을 다시 고르고(N1~N3), `ui.js` 의 모드 바꿈 정리(N4~N8)와 시험 빈틈(N11·N12)을 메운 다음 2차 검수로 닫는 것을 권한다.
