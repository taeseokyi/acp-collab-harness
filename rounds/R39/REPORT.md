## (7) 개선안 하나

**`fleet_graph.py run` 이 INBOX 를 '이 세션이 읽은 뒤 바뀐 것' 으로 보게 하자.** 지금은 run 이 시작된 뒤 바뀐 것만 rc 4 로 알린다.
이번에는 INBOX 가 관리자 시작(17:42)과 첫 run(17:51) 사이에 와서 rc 4 가 나지 않았다. 관리자도 그래프 전에 다시 읽지 않았다.
`new`(그래프 만들기)가 관리자 세션의 시작 시각 뒤에 INBOX 가 바뀌었으면 "INBOX 에 읽지 않은 말이 있습니다" 를 찍고 멈추면 된다.
더 단순하게는 `run` 의 기준 시각을 첫 run 이 아니라 관리자 세션의 시작으로 잡아도 된다. 그러면 이번 경우 첫 run 이 rc 4 를 냈을 것이다.
